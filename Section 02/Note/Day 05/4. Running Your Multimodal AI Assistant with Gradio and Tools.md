## Running Your Multimodal AI Assistant with Gradio and Tools

একটি **multimodal AI assistant** এমন assistant, যা শুধু text answer দেয় না; বরং image বুঝতে পারে, image generate করতে পারে, audio তৈরি করতে পারে, এবং প্রয়োজন হলে tools call করতে পারে।

এখানে main idea হলো:

```text
User Text / Image
      ↓
Gradio UI
      ↓
AI Model
      ↓
Tool Decision
      ↓
Python Tool Execution
      ↓
Final Text + Image + Audio Output
```

Gradio Blocks custom layout, events, এবং data flow control করার জন্য বেশি flexible। তাই chatbot-style বা multimodal assistant বানাতে `gr.Blocks()` ভালো choice। Gradio-এর `MultimodalTextbox` user-এর text এবং uploaded files একটি dict হিসেবে Python function-এ পাঠাতে পারে। ([gradio.app][1]) ([gradio.app][2])

---

## Assistant কী কী করতে পারবে?

এই assistant তিন ধরনের কাজ করবে:

1. **Text answer**
   User-এর প্রশ্নের উত্তর দেবে।

2. **Image understanding**
   User image upload করলে image দেখে explain করতে পারবে। OpenAI vision models image input URL, base64 image data, বা file ID থেকে image বুঝতে পারে। ([OpenAI Platform][3])

3. **Tool use**
   User চাইলে assistant image generate করবে অথবা text-to-speech audio বানাবে। OpenAI Responses API text/image input নিতে পারে এবং custom tools বা built-in tools ব্যবহার করতে পারে। ([OpenAI Platform][4])

---

## Tool Calling Logic

Tool calling-এর flow সাধারণত এমন:

```text
1. Model-কে available tools জানানো হয়
2. Model decide করে tool দরকার কিনা
3. Model tool call return করে
4. Python code সেই tool execute করে
5. Tool result আবার model-কে দেওয়া হয়
6. Model final response দেয়
```

OpenAI docs অনুযায়ী tool calling হলো multi-step conversation, যেখানে model tool call করে, app-side code tool চালায়, তারপর tool output model-এ ফেরত দেওয়া হয়। ([OpenAI Platform][5])

## Full Example: Multimodal Assistant with Gradio + Tools

```python
import os
import json
import base64
import mimetypes
import tempfile
from pathlib import Path

import gradio as gr
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI()

TEXT_MODEL = os.getenv("OPENAI_TEXT_MODEL", "gpt-4.1-mini")
IMAGE_MODEL = os.getenv("OPENAI_IMAGE_MODEL", "gpt-image-2")
TTS_MODEL = os.getenv("OPENAI_TTS_MODEL", "gpt-4o-mini-tts")


def get_file_path(file_obj):
    if not file_obj:
        return None

    if isinstance(file_obj, str):
        return file_obj

    if isinstance(file_obj, dict):
        return file_obj.get("path") or file_obj.get("name")

    return getattr(file_obj, "path", None) or str(file_obj)


def encode_image_as_data_url(image_path):
    mime_type, _ = mimetypes.guess_type(image_path)
    mime_type = mime_type or "image/jpeg"

    with open(image_path, "rb") as image_file:
        base64_image = base64.b64encode(image_file.read()).decode("utf-8")

    return f"data:{mime_type};base64,{base64_image}"


def generate_image(prompt):
    result = client.images.generate(
        model=IMAGE_MODEL,
        prompt=prompt
    )

    image_base64 = result.data[0].b64_json
    image_bytes = base64.b64decode(image_base64)

    image_path = tempfile.NamedTemporaryFile(
        delete=False,
        suffix=".png"
    ).name

    with open(image_path, "wb") as image_file:
        image_file.write(image_bytes)

    return image_path


def text_to_speech(text, voice="coral"):
    audio_path = Path(tempfile.NamedTemporaryFile(
        delete=False,
        suffix=".mp3"
    ).name)

    with client.audio.speech.with_streaming_response.create(
        model=TTS_MODEL,
        voice=voice,
        input=text,
        instructions="Speak clearly and naturally."
    ) as response:
        response.stream_to_file(audio_path)

    return str(audio_path)


tools = [
    {
        "type": "function",
        "name": "generate_image",
        "description": "Generate an image from a text prompt.",
        "parameters": {
            "type": "object",
            "properties": {
                "prompt": {
                    "type": "string",
                    "description": "A clear visual prompt for image generation."
                }
            },
            "required": ["prompt"]
        }
    },
    {
        "type": "function",
        "name": "text_to_speech",
        "description": "Convert text into spoken audio.",
        "parameters": {
            "type": "object",
            "properties": {
                "text": {
                    "type": "string",
                    "description": "Text that should be converted into speech."
                },
                "voice": {
                    "type": "string",
                    "description": "Voice name, for example coral, alloy, nova, or echo."
                }
            },
            "required": ["text"]
        }
    }
]


def run_assistant(message):
    user_text = message.get("text", "") if message else ""
    uploaded_files = message.get("files", []) if message else []

    content = [
        {
            "type": "input_text",
            "text": user_text or "Please analyze the uploaded file."
        }
    ]

    # Add first uploaded image as vision input
    if uploaded_files:
        first_file_path = get_file_path(uploaded_files[0])

        if first_file_path:
            mime_type, _ = mimetypes.guess_type(first_file_path)

            if mime_type and mime_type.startswith("image"):
                image_data_url = encode_image_as_data_url(first_file_path)
                content.append({
                    "type": "input_image",
                    "image_url": image_data_url
                })

    input_list = [
        {
            "role": "user",
            "content": content
        }
    ]

    image_output = None
    audio_output = None

    response = client.responses.create(
        model=TEXT_MODEL,
        input=input_list,
        tools=tools,
        instructions=(
            "You are a helpful multimodal AI assistant. "
            "If the user asks to generate an image, call generate_image. "
            "If the user asks for audio, narration, or spoken output, call text_to_speech. "
            "If an image is uploaded, analyze it carefully."
        )
    )

    for _ in range(3):
        input_list += response.output

        function_calls = [
            item for item in response.output
            if item.type == "function_call"
        ]

        if not function_calls:
            return response.output_text, image_output, audio_output

        for item in function_calls:
            args = json.loads(item.arguments or "{}")

            if item.name == "generate_image":
                image_output = generate_image(args["prompt"])
                tool_result = {
                    "image_path": image_output
                }

            elif item.name == "text_to_speech":
                audio_output = text_to_speech(
                    text=args["text"],
                    voice=args.get("voice", "coral")
                )
                tool_result = {
                    "audio_path": audio_output
                }

            else:
                tool_result = {
                    "error": f"Unknown tool: {item.name}"
                }

            input_list.append({
                "type": "function_call_output",
                "call_id": item.call_id,
                "output": json.dumps(tool_result)
            })

        response = client.responses.create(
            model=TEXT_MODEL,
            input=input_list,
            tools=tools,
            instructions="Explain the result clearly and briefly."
        )

    return "The assistant reached the tool-call limit.", image_output, audio_output


with gr.Blocks(title="Multimodal AI Assistant") as demo:
    gr.Markdown("# Multimodal AI Assistant")
    gr.Markdown(
        "Ask a question, upload an image, request an image generation, "
        "or ask for an audio narration."
    )

    user_input = gr.MultimodalTextbox(
        label="Message",
        placeholder="Example: Describe this image and make a short audio summary.",
        file_types=["image"],
        file_count="single"
    )

    answer_output = gr.Textbox(
        label="Assistant Response",
        lines=8
    )

    image_output = gr.Image(
        label="Generated Image"
    )

    audio_output = gr.Audio(
        label="Generated Audio"
    )

    user_input.submit(
        fn=run_assistant,
        inputs=user_input,
        outputs=[answer_output, image_output, audio_output]
    )

demo.launch()
```

## Important Notes

Image generation-এর জন্য current OpenAI docs GPT Image models, যেমন `gpt-image-2`, ব্যবহার দেখায়; আপনার course যদি DALL·E 3 ব্যবহার করে, তাহলে image model অংশে আপনার available model বসাতে হবে। OpenAI docs অনুযায়ী Image API text prompt থেকে image generate করতে পারে, আর Responses API image generation-কে multi-step conversational flow-এর অংশ হিসেবে ব্যবহার করতে পারে। ([OpenAI Platform][6])

Text-to-Speech-এর ক্ষেত্রে OpenAI Speech endpoint model, text input, এবং voice—এই তিনটি key input নেয়। Docs-এ আরও বলা আছে, TTS voice AI-generated হলে user-কে পরিষ্কারভাবে জানানো উচিত যে voice human নয়। ([OpenAI Platform][7])

সংক্ষেপে, **Gradio হলো UI layer**, **OpenAI model হলো reasoning layer**, আর **Python functions হলো tools layer**। এই তিনটি একসাথে ব্যবহার করলেই একটি practical multimodal AI assistant তৈরি হয়।
