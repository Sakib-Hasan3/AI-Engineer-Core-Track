## Building Multi-Modal Apps with DALL·E 3, Text-to-Speech, and Gradio Blocks

**Multi-modal app** মানে এমন একটি অ্যাপ যেখানে একাধিক ধরনের data একসাথে কাজ করে। যেমন:

* Text input
* Image generation
* Audio generation
* Web UI
* File output

এই lesson-এ আমরা এমন একটি app বুঝব যেখানে user একটি prompt লিখবে, তারপর app সেই prompt দিয়ে **image generate** করবে এবং একই prompt বা generated story থেকে **spoken audio** তৈরি করবে।

---

## Gradio Blocks কী?

**Gradio Blocks** হলো Gradio-এর flexible UI system। `Interface` দিয়ে simple input-output app বানানো যায়, কিন্তু `Blocks` দিয়ে custom layout, button event, multiple output, tabs, rows, columns, এবং multi-step workflow তৈরি করা যায়। Gradio docs অনুযায়ী, Blocks বেশি control দেয় layout, events, এবং data flow-এর উপর। ([Gradio][1])

সহজভাবে:

> **Gradio Blocks = Python দিয়ে custom web app layout বানানোর পদ্ধতি।**

---

## App Workflow

এই app-এর workflow হবে:

```text
User Prompt
   ↓
Gradio Textbox
   ↓
Python Function
   ↓
DALL·E 3 Image Generation
   ↓
Text-to-Speech Audio Generation
   ↓
Image + Audio Output in Web UI
```

এখানে Gradio frontend হিসেবে কাজ করবে, আর Python backend থেকে OpenAI API call করা হবে।

## DALL·E 3 এবং Image Generation

OpenAI-এর Image API text prompt থেকে image generate করতে পারে। বর্তমান docs-এ নতুন GPT Image models বেশি emphasized, তবে API reference-এ `dall-e-3` এখনও image model হিসেবে listed আছে। ([OpenAI Platform][2]) ([OpenAI Platform][3])

Image generation-এর ক্ষেত্রে সাধারণত input হয়:

```text
Prompt: "A futuristic robot teaching children in a classroom"
```

Output হয়:

```text
Generated image
```

DALL·E 3-এর ক্ষেত্রে API response-এ `revised_prompt` থাকতে পারে, অর্থাৎ model prompt internally refine করে image generate করতে পারে। ([OpenAI Platform][3])

## Text-to-Speech কীভাবে কাজ করে?

Text-to-Speech বা TTS হলো written text-কে spoken audio-তে রূপান্তর করার পদ্ধতি। OpenAI Audio API text থেকে lifelike spoken audio তৈরি করতে পারে এবং narration, multilingual audio, realtime/streaming audio output-এর মতো কাজে ব্যবহার করা যায়। ([OpenAI Platform][4])

OpenAI speech endpoint text input নিয়ে audio file content বা streamed audio events return করতে পারে। API reference অনুযায়ী supported audio formats-এর মধ্যে `mp3`, `opus`, `aac`, `flac`, `wav`, এবং `pcm` আছে। ([OpenAI Platform][5])

## Full Example: DALL·E 3 + TTS + Gradio Blocks

```python
import os
import base64
import tempfile
from dotenv import load_dotenv

import gradio as gr
from openai import OpenAI

load_dotenv()

client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))


def generate_multimodal_content(prompt, voice):
    if not prompt or prompt.strip() == "":
        return None, None, "Please enter a prompt."

    # 1. Generate image with DALL·E 3
    image_response = client.images.generate(
        model="dall-e-3",
        prompt=prompt,
        size="1024x1024",
        response_format="b64_json"
    )

    image_base64 = image_response.data[0].b64_json
    image_bytes = base64.b64decode(image_base64)

    image_path = tempfile.NamedTemporaryFile(
        delete=False,
        suffix=".png"
    ).name

    with open(image_path, "wb") as image_file:
        image_file.write(image_bytes)

    # 2. Generate spoken audio from text
    narration_text = f"Here is your generated scene: {prompt}"

    speech_response = client.audio.speech.create(
        model="gpt-4o-mini-tts",
        voice=voice,
        input=narration_text,
        response_format="mp3"
    )

    audio_path = tempfile.NamedTemporaryFile(
        delete=False,
        suffix=".mp3"
    ).name

    with open(audio_path, "wb") as audio_file:
        audio_file.write(speech_response.read())

    status = "Image and audio generated successfully."

    return image_path, audio_path, status


with gr.Blocks() as demo:
    gr.Markdown("# Multi-Modal AI App")
    gr.Markdown("Generate an image and spoken audio from one text prompt.")

    with gr.Row():
        with gr.Column():
            prompt_input = gr.Textbox(
                label="Enter your prompt",
                placeholder="Example: A futuristic city floating above the clouds",
                lines=4
            )

            voice_input = gr.Dropdown(
                choices=["alloy", "ash", "ballad", "coral", "echo", "fable", "onyx", "nova", "sage", "shimmer"],
                value="alloy",
                label="Choose Voice"
            )

            generate_button = gr.Button("Generate")

        with gr.Column():
            image_output = gr.Image(label="Generated Image")
            audio_output = gr.Audio(label="Generated Audio")
            status_output = gr.Textbox(label="Status")

    generate_button.click(
        fn=generate_multimodal_content,
        inputs=[prompt_input, voice_input],
        outputs=[image_output, audio_output, status_output]
    )

demo.launch()
```

## Code Explanation

এই code-এ প্রথমে user একটি prompt দেয়। তারপর `client.images.generate()` function দিয়ে DALL·E 3 image তৈরি করা হয়। Image output base64 format-এ আসে, তাই সেটিকে decode করে `.png` file হিসেবে save করা হয়।

এরপর একই prompt দিয়ে একটি narration text তৈরি করা হয়। তারপর `client.audio.speech.create()` ব্যবহার করে text থেকে audio তৈরি করা হয়। OpenAI docs অনুযায়ী speech endpoint text থেকে audio generate করে, এবং model, voice, input, response format-এর মতো parameter নেয়। ([OpenAI Platform][5])

Gradio অংশে `gr.Blocks()` দিয়ে custom UI বানানো হয়েছে। Textbox user prompt নেয়, Dropdown voice select করে, Button click করলে Python function run হয়, এবং output হিসেবে image, audio, status দেখায়। Gradio Button docs অনুযায়ী `Button.click()` event listener user interaction হলে function call করতে পারে। ([Gradio][6])

## Safety and Practical Notes

Image generation model সবসময় perfectly accurate text বা layout render করতে পারে না। OpenAI docs-এও বলা হয়েছে image models improved হলেও precise text placement, visual consistency, এবং structured composition-এ limitation থাকতে পারে। ([OpenAI Platform][2])

Production app বানালে আপনাকে অবশ্যই:

* API key frontend-এ expose করা যাবে না
* User input validate করতে হবে
* Cost control রাখতে হবে
* Rate limit handle করতে হবে
* Generated file cleanup করতে হবে
* Harmful prompt filtering রাখতে হবে
