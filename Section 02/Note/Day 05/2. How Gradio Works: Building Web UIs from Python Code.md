## How Gradio Works: Python Code থেকে Web UI তৈরি করা

**Gradio** হলো একটি open-source Python package, যার মাধ্যমে আপনি Python function, machine learning model, API, বা যেকোনো logic-এর জন্য খুব দ্রুত web-based UI বানাতে পারেন। এর বড় সুবিধা হলো JavaScript, CSS, বা আলাদা web hosting না জানলেও Python দিয়েই interactive web app তৈরি করা যায়। ([Gradio][1])

সহজভাবে বললে:

> **আপনি Python function লিখবেন, Gradio সেটাকে web app বানিয়ে দেবে।**

---

## Gradio কীভাবে কাজ করে?

Gradio মূলত তিনটি জিনিসের উপর কাজ করে:

1. **Python Function**
   আপনি যে কাজটি করাতে চান, সেটি একটি Python function হিসেবে লিখবেন।

2. **Input Components**
   User কী ধরনের input দেবে তা নির্ধারণ করবেন। যেমন text, image, audio, slider, file ইত্যাদি।

3. **Output Components**
   Function চালানোর পর result কীভাবে দেখাবে তা নির্ধারণ করবেন। যেমন text, image, label, chart, dataframe ইত্যাদি।

Gradio-এর `Interface` class সাধারণত তিনটি জিনিস চায়: function, input components, এবং output components। Function-এর parameter input component-এর সাথে মিলে যায়, আর function-এর return value output component-এ দেখানো হয়। ([Gradio][2])

---

## Basic Example

```python
import gradio as gr

def greet(name):
    return "Hello, " + name + "!"

demo = gr.Interface(
    fn=greet,
    inputs="text",
    outputs="text"
)

demo.launch()
```

এখানে কী হচ্ছে?

* `greet()` হলো Python function
* `inputs="text"` মানে user একটি text input দেবে
* `outputs="text"` মানে output text আকারে দেখাবে
* `demo.launch()` web UI চালু করবে

যখন user browser-এ নাম লিখে submit করবে, Gradio সেই input Python function-এ পাঠাবে, function result return করবে, তারপর Gradio browser-এ output দেখাবে।

## Gradio-এর Request Flow

Gradio app চলার সময় flow সাধারণত এমন হয়:

```text
User Browser
    ↓
Gradio Web Interface
    ↓
Python Function
    ↓
Function Output
    ↓
Browser Result
```

অর্থাৎ user browser থেকে input দেয়, Gradio সেই input backend Python code-এ পাঠায়, Python function result তৈরি করে, তারপর Gradio সেটি UI-তে দেখায়।

## Example: Simple Calculator

```python
import gradio as gr

def add_numbers(a, b):
    return a + b

demo = gr.Interface(
    fn=add_numbers,
    inputs=[
        gr.Number(label="First Number"),
        gr.Number(label="Second Number")
    ],
    outputs=gr.Number(label="Result")
)

demo.launch()
```

এখানে দুইটি number input নেওয়া হচ্ছে এবং output হিসেবে যোগফল দেখানো হচ্ছে।

## Gradio Interface API

`gr.Interface` হলো Gradio-এর high-level API। এটি দ্রুত demo বা simple app বানানোর জন্য ব্যবহার করা হয়। Official docs অনুযায়ী, Interface দিয়ে কয়েক লাইনের Python code-এই machine learning model বা যেকোনো Python function-এর জন্য web-based GUI তৈরি করা যায়। ([Gradio][2])

এটি সবচেয়ে ভালো যখন:

* simple input-output app বানাতে চান
* model demo তৈরি করতে চান
* দ্রুত prototype বানাতে চান
* client বা team-এর কাছে কাজ দেখাতে চান

## Gradio Blocks API

যখন আপনার UI বেশি custom করতে হবে, তখন `gr.Blocks` ব্যবহার করা হয়। Blocks হলো Gradio-এর low-level API, যা layout, event, data flow, tabs, এবং complex UI-এর উপর বেশি control দেয়। ([Gradio][3])

### Blocks Example

```python
import gradio as gr

def reverse_text(text):
    return text[::-1]

with gr.Blocks() as demo:
    gr.Markdown("# Text Reverser App")

    input_text = gr.Textbox(label="Enter Text")
    output_text = gr.Textbox(label="Reversed Text")

    button = gr.Button("Reverse")
    button.click(
        fn=reverse_text,
        inputs=input_text,
        outputs=output_text
    )

demo.launch()
```

এখানে `button.click()` বলে দেওয়া হয়েছে: button চাপলে কোন function চলবে, কোন input যাবে, এবং output কোথায় দেখাবে।

## Event Listener কী?

Gradio-তে user কোনো action করলে, যেমন button click, slider change, image upload, তখন একটি function trigger করা যায়। Gradio docs অনুযায়ী, event listeners UI component-এর interaction অনুযায়ী function call করতে সাহায্য করে। ([Gradio][4])

উদাহরণ:

```python
button.click(fn=my_function, inputs=input_box, outputs=output_box)
```

মানে:

> Button click করলে `my_function` চলবে।

## Machine Learning Model-এর সাথে Gradio

Gradio সবচেয়ে বেশি ব্যবহৃত হয় ML model demo বানানোর জন্য।

```python
import gradio as gr

def predict_sentiment(text):
    if "good" in text.lower():
        return "Positive"
    elif "bad" in text.lower():
        return "Negative"
    else:
        return "Neutral"

demo = gr.Interface(
    fn=predict_sentiment,
    inputs=gr.Textbox(label="Enter a sentence"),
    outputs=gr.Label(label="Sentiment")
)

demo.launch()
```

এখানে user sentence লিখবে, Python function sentiment predict করবে, এবং result web UI-তে দেখা যাবে।

## Interface vs Blocks

| বিষয়                 | Interface       | Blocks           |
| -------------------- | --------------- | ---------------- |
| ব্যবহার              | Simple app/demo | Custom web app   |
| Control              | কম              | বেশি             |
| Layout customization | সীমিত           | বেশি             |
| Event handling       | basic           | advanced         |
| Best for             | quick prototype | complex workflow |
