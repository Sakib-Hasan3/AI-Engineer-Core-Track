## ১. Gradio কী?

**Gradio** হলো একটি Python লাইব্রেরি যা তোমাকে **দ্রুত ও সহজে ওয়েব ইউজার ইন্টারফেস (Web UI) তৈরি করতে দেয়**।

* তুমি যদি Python-এ কোনো মডেল, ফাংশন বা স্ক্রিপ্ট বানাও, Gradio দিয়ে তা **ক্লিক করে চালানোর মতো ওয়েব অ্যাপ** বানানো যায়।
* তুমি কোনো জটিল HTML/CSS/JavaScript লিখতে হবে না।

### উদাহরণ:

ধরা যাক তোমার কাছে একটা ফাংশন আছে যা সংখ্যার দ্বিগুণ করে দেয়:

```python
def double_number(x):
    return x * 2
```

Gradio দিয়ে তুমি সহজে একটা ওয়েব UI বানাতে পারো যেখানে ইউজার সংখ্যা ইনপুট দিবে এবং ফলাফল দেখাবে।

## ২. Gradio কিভাবে কাজ করে?

Gradio মূলত **Python ফাংশনকে ওয়েব ইন্টারফেসে রূপান্তর করে**।

### ধাপগুলো:

1. **ইনপুট এবং আউটপুট টাইপ নির্ধারণ করা:**

   * Input: `gr.Number()`, `gr.Textbox()`, `gr.Image()` ইত্যাদি
   * Output: `gr.Text()`, `gr.Label()`, `gr.Image()` ইত্যাদি

2. **Python ফাংশন যুক্ত করা:**

   * ইউজারের ইনপুট নিয়ে ফাংশন প্রসেস করবে এবং আউটপুট দেখাবে

3. **Interface তৈরি করা:**

   * `gr.Interface()` দিয়ে ফাংশন, ইনপুট, আউটপুট সংযুক্ত করা

4. **ইন্টারফেস চালানো:**

   * `.launch()` দিয়ে ব্রাউজারে UI চালু করা

## ৩. সহজ উদাহরণ

```python
import gradio as gr

# ১. Python ফাংশন
def double_number(x):
    return x * 2

# ২. Gradio ইন্টারফেস তৈরি
interface = gr.Interface(
    fn=double_number,     # ফাংশন
    inputs=gr.Number(),   # ইনপুট টাইপ
    outputs=gr.Number()   # আউটপুট টাইপ
)

# ৩. UI চালানো
interface.launch()
```

* চালানোর পর ব্রাউজারে একটা ছোট ওয়েবপেজ খোলা হবে
* সেখানে ইউজার সংখ্যা ইনপুট দিবে
* Submit করলে ফাংশনের আউটপুট দেখাবে

## ৪. Gradio এর সুবিধা

1. **সহজ ব্যবহার:** Python কোড থেকেই UI তৈরি
2. **মডেল ডেমো:** Machine Learning বা AI মডেল ডেমো করার জন্য খুব উপযোগী
3. **শেয়ার করা যায়:** `.launch(share=True)` দিলে, অন্যদের জন্যও লিঙ্ক তৈরি হয়
4. **বহু ইনপুট/আউটপুট:** Image, Text, Audio, Video, Dataframe ইত্যাদি সমর্থন করে

### ৫. উদাহরণ: ছবি ক্লাসিফিকেশন

```python
import gradio as gr
from PIL import Image
import numpy as np

# Dummy ফাংশন: ছবির রঙ বের করবে
def average_color(img):
    arr = np.array(img)
    avg_color = arr.mean(axis=(0,1))
    return tuple(avg_color.astype(int))

interface = gr.Interface(
    fn=average_color,
    inputs=gr.Image(type="pil"),
    outputs=gr.Text()
)

interface.launch()
```

* ইউজার ছবি আপলোড করবে
* AI ফাংশন/প্রসেসিং হবে
* আউটপুটে রঙের সংখ্যা দেখাবে
