## Compare Frontier LLMs with OpenRouter: Generate SVG Art in Python

এই lesson-এর goal হলো: **একই SVG art prompt কয়েকটি frontier LLM-এ পাঠিয়ে দেখা—কোন model সবচেয়ে ভালো SVG code generate করে।**

OpenRouter ব্যবহার করলে এক API endpoint দিয়েই অনেক model access করা যায়। OpenRouter নিজেই OpenAI-compatible API দেয়, তাই Python-এ OpenAI SDK ব্যবহার করেও OpenRouter call করা যায়। OpenRouter docs অনুযায়ী এটি hundreds of AI models-এর জন্য unified API এবং fallback/routing support করে। ([OpenRouter][1])

## OpenRouter কেন ব্যবহার করব?

OpenRouter-এর সুবিধা হলো এক জায়গা থেকে অনেক model compare করা যায়। আলাদা আলাদা provider API key, endpoint, SDK manage করার ঝামেলা কমে যায়। OpenRouter Chat Completion endpoint OpenAI-compatible format follow করে, এবং response schema normalize করে। ([OpenRouter][2])

আরেকটি important বিষয় হলো model list fixed ধরে নেওয়া ঠিক নয়। OpenRouter-এর `/api/v1/models` endpoint দিয়ে available models এবং তাদের properties দেখা যায়। ([OpenRouter][3])

## Step 3: Python Script

নিচের code একই prompt কয়েকটি model-এ পাঠাবে এবং প্রতিটি model-এর output আলাদা `.svg` file হিসেবে save করবে।

```python
import os
import re
import time
from pathlib import Path
from xml.etree import ElementTree as ET

from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    base_url="https://openrouter.ai/api/v1",
    api_key=os.getenv("OPENROUTER_API_KEY"),
)

OUTPUT_DIR = Path("svg_outputs")
OUTPUT_DIR.mkdir(exist_ok=True)

# Replace these with current model IDs from OpenRouter's model page/API.
MODELS = [
    "openai/gpt-4o",
    "anthropic/claude-3.5-sonnet",
    "google/gemini-2.5-pro",
    "deepseek/deepseek-r1",
]

SVG_PROMPT = """
Create a clean, professional SVG illustration.

Theme:
A futuristic AI assistant controlling multiple tools: web search, image generation,
calendar, code, and database.

Style:
- modern vector art
- dark background
- neon blue and purple accents
- central robot/AI orb
- connected tool icons around it
- no text inside the image
- 1024 by 1024 viewBox
- valid SVG only

Return only the SVG code.
Do not use markdown.
Do not explain anything.
"""


def extract_svg(text: str) -> str:
    """
    Extract SVG code from model output.
    Handles cases where model accidentally adds explanation or markdown.
    """
    match = re.search(r"<svg[\s\S]*?</svg>", text, re.IGNORECASE)
    if not match:
        raise ValueError("No valid <svg>...</svg> block found.")
    return match.group(0)


def basic_svg_safety_check(svg: str) -> str:
    """
    Basic cleanup: remove risky tags that should not be needed for simple SVG art.
    For production, use a proper SVG sanitizer.
    """
    banned_tags = ["script", "foreignObject", "iframe", "object", "embed"]

    for tag in banned_tags:
        svg = re.sub(
            rf"<{tag}[\s\S]*?</{tag}>",
            "",
            svg,
            flags=re.IGNORECASE
        )

    return svg.strip()


def validate_svg(svg: str) -> bool:
    """
    Check whether SVG is parseable XML.
    """
    try:
        ET.fromstring(svg)
        return True
    except ET.ParseError:
        return False


def generate_svg(model: str, prompt: str) -> dict:
    start_time = time.time()

    response = client.chat.completions.create(
        model=model,
        messages=[
            {
                "role": "system",
                "content": (
                    "You are an expert SVG artist. "
                    "You produce valid SVG code only."
                ),
            },
            {
                "role": "user",
                "content": prompt,
            },
        ],
        temperature=0.7,
    )

    elapsed = round(time.time() - start_time, 2)
    raw_output = response.choices[0].message.content

    svg = extract_svg(raw_output)
    svg = basic_svg_safety_check(svg)

    is_valid = validate_svg(svg)

    safe_model_name = model.replace("/", "__").replace(":", "_")
    svg_path = OUTPUT_DIR / f"{safe_model_name}.svg"

    with open(svg_path, "w", encoding="utf-8") as file:
        file.write(svg)

    return {
        "model": model,
        "file": str(svg_path),
        "valid_svg": is_valid,
        "seconds": elapsed,
        "characters": len(svg),
    }


def main():
    results = []

    for model in MODELS:
        print(f"\nGenerating SVG with: {model}")

        try:
            result = generate_svg(model, SVG_PROMPT)
            results.append(result)
            print(f"Saved: {result['file']}")
            print(f"Valid SVG: {result['valid_svg']}")
            print(f"Time: {result['seconds']}s")

        except Exception as error:
            results.append({
                "model": model,
                "file": None,
                "valid_svg": False,
                "seconds": None,
                "characters": 0,
                "error": str(error),
            })
            print(f"Failed: {error}")

    print("\nComparison Results")
    print("-" * 80)

    for item in results:
        print(item)


if __name__ == "__main__":
    main()
```

## Code কী করছে?

এই code-এ `OpenAI()` client ব্যবহার করা হয়েছে, কিন্তু `base_url` দেওয়া হয়েছে OpenRouter-এর API URL। এটাই OpenRouter-এর বড় সুবিধা: OpenAI-compatible format ব্যবহার করে অন্য provider-এর model call করা যায়। OpenRouter docs বলছে তাদের API OpenAI Chat API schema normalize করে, তাই একই code দিয়ে multiple model compare করা সহজ হয়। ([OpenRouter][2])

`MODELS` list-এ আপনি যেসব model compare করতে চান সেগুলোর OpenRouter model ID দেবেন। Model ID সময়ের সাথে বদলাতে পারে, তাই production code-এ `/api/v1/models` endpoint বা OpenRouter model page থেকে current IDs নেওয়া ভালো। ([OpenRouter][3])

## Optional: SVG থেকে PNG Export

SVG preview করার জন্য browser-এ open করলেই হবে। তবে PNG বানাতে চাইলে:

```python
import cairosvg
from pathlib import Path

svg_folder = Path("svg_outputs")
png_folder = Path("png_outputs")
png_folder.mkdir(exist_ok=True)

for svg_file in svg_folder.glob("*.svg"):
    png_file = png_folder / f"{svg_file.stem}.png"

    cairosvg.svg2png(
        url=str(svg_file),
        write_to=str(png_file),
        output_width=1024,
        output_height=1024
    )

    print(f"Saved PNG: {png_file}")
```

## কীভাবে Compare করবেন?

শুধু “দেখতে সুন্দর” বললে comparison subjective হয়ে যায়। ভালো evaluation criteria হতে পারে:

| Criteria         | কী দেখবেন                          |
| ---------------- | ---------------------------------- |
| Valid SVG        | Browser-এ open হয় কিনা             |
| Prompt following | Text ছাড়া image বানিয়েছে কিনা      |
| Visual quality   | composition, colors, depth         |
| SVG cleanliness  | unnecessary code কম কিনা           |
| File size        | খুব বড় বা messy কিনা               |
| Consistency      | repeated run-এ quality stable কিনা |
| Speed            | response time কত                   |
| Cost             | token cost কত                      |

## Structured Output ব্যবহার করা যায়?

SVG code সরাসরি চাইলে অনেক সময় model extra explanation যোগ করে। OpenRouter structured outputs support করে compatible models-এর জন্য, যেখানে response একটি JSON Schema follow করতে পারে। ([OpenRouter][4])

তখন model থেকে এমন JSON চাইতে পারেন:

```json
{
  "svg": "<svg>...</svg>",
  "description": "short description",
  "quality_notes": "short notes"
}
```

তবে সব model structured output equally ভালো follow করে না, তাই SVG generation-এর ক্ষেত্রে simple “Return only SVG code” prompt অনেক সময় practical হয়।

## Practical Tips

SVG art generation-এর জন্য temperature মাঝারি রাখুন, যেমন `0.6` বা `0.7`। বেশি temperature দিলে creativity বাড়বে, কিন্তু invalid SVG হওয়ার chance বাড়তে পারে।

Prompt-এ সবসময় বলুন:

```text
No markdown.
No explanation.
No JavaScript.
No external links.
Return valid SVG only.
```

Production app হলে SVG sanitize করা জরুরি, কারণ SVG-এর ভিতরে script বা external reference থাকতে পারে। উপরের code basic cleanup করে, কিন্তু production-level security-এর জন্য dedicated sanitizer ব্যবহার করা ভালো।
