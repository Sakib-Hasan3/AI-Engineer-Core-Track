## 🤖 LLM Tool Calling আসলে কীভাবে কাজ করে? (কোনো জাদু না—শুধু Prompt + Rules)

অনেকেই ভাবে ChatGPT বা অন্য LLM “নিজে থেকেই” টুল চালায় বা ইন্টারনেট/ক্যালকুলেটর/ডাটাবেস এক্সেস করে। আসলে ব্যাপারটা অনেক বেশি সিম্পল—এটা **prompt engineering + structured output + external system orchestration**।

চলো সহজভাবে বুঝি।

---

## 🧠 1. LLM নিজে কোনো টুল চালায় না

LLM (যেমন GPT) আসলে:

* শুধু **টেক্সট জেনারেট করে**
* কোনো API কল করতে পারে না নিজে থেকে
* কোনো ডাটাবেস বা ইন্টারনেট সরাসরি অ্যাক্সেস নেই

👉 তাহলে tool calling কী?

👉 এটা হচ্ছে:
**“LLM শুধু বলে কী করতে হবে, কিন্তু কাজটা করে বাইরের সিস্টেম”**

---

## 🧩 2. Tool Calling মানে কী?

Tool calling হলো এমন একটা system যেখানে LLM:

👉 দেখে user কী বলেছে
👉 সিদ্ধান্ত নেয় “আমাকে কি calculator / search / API লাগবে?”
👉 তারপর একটা **structured JSON-like output দেয়**

উদাহরণ:

User বলে:

> “What is 25 * 47?”

LLM আউটপুট দিতে পারে:

```json
{
  "tool": "calculator",
  "input": "25*47"
}
```

তারপর external system সেটা execute করে।

---

## ⚙️ 3. পুরো Process কীভাবে চলে (Step-by-step)

### 🟢 Step 1: User message

User বলে:

> “Dhaka weather কেমন?”

---

### 🟡 Step 2: LLM চিন্তা করে (Prompt instruction অনুযায়ী)

System prompt LLM-কে বলে:

> “যদি weather লাগে → weather tool call করো”

---

### 🔵 Step 3: LLM structured output দেয়

LLM বলে:

```json
{
  "tool": "weather_api",
  "location": "Dhaka"
}
```

---

### 🔴 Step 4: External system কাজ করে

Backend system:

* weather API call করে
* data নেয়

---

### 🟣 Step 5: আবার LLM-কে দেয়

System বলে:

> “এই data user-friendly করে explain করো”

---

### 🟢 Step 6: Final answer

LLM বলে:

> “Dhaka-তে আজ 32°C, আকাশ আংশিক মেঘলা...”

---

## 🧠 4. আসল “জাদু” কোথায়?

কোনো জাদু নেই 😄
সব হচ্ছে 3টা জিনিসের কম্বিনেশন:

### 1️⃣ System Prompt

LLM-কে rules দেওয়া হয়:

* কখন tool call করবে
* কী format এ output দিবে

---

### 2️⃣ Structured Output (JSON/function calling)

LLM কে বাধ্য করা হয় এমনভাবে লিখতে:

* tool name
* parameters

---

### 3️⃣ Orchestrator (Backend logic)

এটাই আসল “controller”:

* tool execute করে
* আবার LLM-কে data পাঠায়

---

## 🔥 5. Simple analogy

ধরো তুমি একজন assistant:

* তুমি (LLM) জানো কোন কাজ লাগবে
* কিন্তু কাজটা তুমি নিজে করো না

👉 তুমি শুধু বলো:

> “ভাই calculator আনো”

👉 তারপর অন্য কেউ calculator চালায়

---

## ⚡ 6. Key insight (সবচেয়ে গুরুত্বপূর্ণ)

👉 LLM = Decision maker + language generator
👉 Tool system = Executor

LLM কখনোই বাস্তবে API call করে না—
সে শুধু **instruction-based output দেয়**
