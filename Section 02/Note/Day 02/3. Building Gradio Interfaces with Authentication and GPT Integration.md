# Building Gradio Interfaces with Authentication and GPT Integration

এই topic-এর meaning হলো:

> **Python দিয়ে একটি simple web app বানানো, যেখানে user login করবে, তারপর GPT/AI model-এর সাথে chat করতে পারবে।**

এখানে ৩টা main part আছে:

1. **Gradio Interface**
2. **Authentication**
3. **GPT Integration**

---

## 1. Gradio Interface কী?

**Gradio** হলো Python-এর একটি library, যেটা দিয়ে খুব সহজে web interface বানানো যায়।

ধরো তোমার কাছে একটা Python function আছে:

```python
def greet(name):
    return "Hello " + name
```

Gradio দিয়ে তুমি এটাকে textbox + output box সহ web app বানাতে পারো।

```python
import gradio as gr

def greet(name):
    return "Hello " + name

demo = gr.Interface(
    fn=greet,
    inputs="textbox",
    outputs="textbox"
)

demo.launch()
```

Gradio-এর `Interface` মূলত কোনো Python function-এর চারপাশে GUI/web interface তৈরি করে। এতে function, input component, output component দিতে হয়। ([Gradio][1])

---

## 2. Chatbot Interface

GPT integration-এর জন্য সাধারণ `Interface` এর চেয়ে `ChatInterface` বেশি useful।

কারণ GPT app সাধারণত chat-based হয়।

```python
import gradio as gr

def reply(message, history):
    return "You said: " + message

demo = gr.ChatInterface(fn=reply)
demo.launch()
```

এখানে:

```python
def reply(message, history):
```

* `message` = user এখন যা লিখেছে
* `history` = আগের conversation history

Gradio-এর `ChatInterface` chatbot UI বানানোর high-level abstraction, যেখানে function সাধারণত `message` এবং `history` নেয়। ([Gradio][2])

---

## 3. Authentication কী?

**Authentication** মানে হলো app-এ ঢোকার আগে username/password দিয়ে login করা।

যেমন:

```python
demo.launch(auth=("admin", "pass1234"))
```

এখন user app open করলে আগে username/password চাইবে।

Gradio-তে `launch(auth=...)` দিয়ে password-protected app বানানো যায়। এখানে single username-password tuple, multiple users-এর list, অথবা custom authentication function দেওয়া যায়। ([Gradio][3])

---

## 4. Multiple User Authentication

```python
demo.launch(
    auth=[
        ("admin", "admin123"),
        ("student", "student123")
    ]
)
```

এখানে দুইজন user login করতে পারবে।

---

## 5. Custom Authentication Function

এটা বেশি flexible.

```python
def check_login(username, password):
    if username == "admin" and password == "1234":
        return True
    return False

demo.launch(auth=check_login)
```

এখানে function `True` return করলে login successful হবে, আর `False` return করলে access denied হবে।

---

## 6. Important Security Note

Gradio-এর built-in authentication simple access control-এর জন্য ভালো, যেমন local demo, class project, prototype. কিন্তু production-level security-এর জন্য এটা enough না, কারণ এতে MFA, rate limiting, automatic lockout policy-এর মতো strong security feature নেই। ([Gradio][3])

Production app হলে ভালো approach:

* FastAPI authentication
* OAuth login
* Google login
* Hugging Face OAuth
* Database-based user system
* JWT/session-based auth

Gradio Hugging Face OAuth support করে, তবে `gr.LoginButton` নিজে access restrict করে না; login না করলেও user app use করতে পারে, শুধু profile/token value `None` হবে। ([Gradio][3])

# 7. GPT Integration কী?

GPT Integration মানে হলো Gradio app-এর ভিতর OpenAI/GPT API connect করা।

Flow:

```text
User message
   ↓
Gradio chatbot
   ↓
Python function
   ↓
OpenAI GPT API
   ↓
GPT response
   ↓
Gradio output
```

OpenAI Python SDK install করতে হয়:

```bash
pip install openai
```

OpenAI-এর Python library Python app থেকে OpenAI REST API access করার সুবিধা দেয়, এবং official docs অনুযায়ী নতুন projects-এর জন্য Responses API primary/recommended API। ([OpenAI Developers][4])

# 8. Full Example: Gradio + Login + GPT Chatbot

প্রথমে install করো:

```bash
pip install gradio openai python-dotenv
```

তারপর `.env` file বানাও:

```env
OPENAI_API_KEY=your_api_key_here
```

তারপর `app.py` file:

```python
import os
import gradio as gr
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY")
)

SYSTEM_PROMPT = """
You are a helpful AI tutor.
Explain answers clearly and simply.
"""

def check_login(username, password):
    valid_users = {
        "admin": "admin123",
        "student": "student123"
    }

    return valid_users.get(username) == password


def chat_with_gpt(message, history):
    messages = []

    for item in history:
        if isinstance(item.get("content"), str):
            messages.append({
                "role": item["role"],
                "content": item["content"]
            })

    messages.append({
        "role": "user",
        "content": message
    })

    response = client.responses.create(
        model="gpt-5.2",
        instructions=SYSTEM_PROMPT,
        input=messages
    )

    return response.output_text


demo = gr.ChatInterface(
    fn=chat_with_gpt,
    title="Authenticated GPT Chatbot",
    description="Login first, then chat with GPT."
)

demo.launch(auth=check_login)
```

তারপর run করো:

```bash
python app.py
```

Browser-এ Gradio app open হবে। প্রথমে login চাইবে। Login successful হলে GPT chatbot use করা যাবে।

# 9. Code Breakdown

## এই অংশ API key load করে

```python
load_dotenv()

client = OpenAI(
```

---

## এই অংশ login check করে

```python
def check_login(username, password):
```

## এই অংশ GPT-কে message পাঠায়

```python
response = client.responses.create(
```

# 10. Simple Version Without Chat History

শুধু simple question-answer app বানাতে চাইলে:

```python
import os
import gradio as gr
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

def ask_gpt(question):
    response = client.responses.create(
        model="gpt-5.2",
        instructions="Answer clearly and simply.",
        input=question
    )
    return response.output_text

demo = gr.Interface(
    fn=ask_gpt,
    inputs=gr.Textbox(label="Ask something"),
    outputs=gr.Textbox(label="GPT Answer"),
    title="Simple GPT App"
)

demo.launch(auth=("admin", "1234"))
```
