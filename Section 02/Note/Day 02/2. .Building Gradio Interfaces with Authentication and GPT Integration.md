
## “Building Gradio Interfaces with Authentication and GPT Integration” — Bangla Explanation

এর মানে হলো: **Python দিয়ে একটি ওয়েব-ভিত্তিক AI chatbot/interface বানানো**, যেখানে—

1. **Gradio** দিয়ে UI বা ওয়েব ইন্টারফেস বানানো হবে
2. **Authentication** দিয়ে login/password protection দেওয়া হবে
3. **GPT/OpenAI API** যুক্ত করে user-এর প্রশ্নের উত্তর AI দিয়ে generate করা হবে

Gradio মূলত Python function-কে খুব সহজে web interface-এ রূপান্তর করে। Gradio-এর `Interface`, `Blocks`, এবং `ChatInterface` ব্যবহার করে text input, chatbot UI, button, file upload ইত্যাদি বানানো যায়। Chatbot বানানোর জন্য Gradio-এর `ChatInterface` বিশেষভাবে তৈরি করা হয়েছে। ([Gradio][1])

---

## 1. Gradio Interface কী?

ধরো তোমার একটি Python function আছে:

```python
def greet(name):
    return "Hello " + name
```

এখন তুমি চাইলে এই function-এর জন্য একটি web app বানাতে পারো, যেখানে user নাম লিখবে, আর output দেখবে। Gradio এই কাজটা কয়েক লাইনের কোডে করে দেয়।

সাধারণভাবে:

```python
import gradio as gr

def greet(name):
    return f"Hello {name}"

app = gr.Interface(
    fn=greet,
    inputs="text",
    outputs="text"
)

app.launch()
```

এটা run করলে browser-এ একটি ছোট ওয়েব অ্যাপ খুলবে।

## 2. Authentication কী?

**Authentication** মানে login system।
যেন সবাই app ব্যবহার করতে না পারে; শুধু যাদের username-password আছে, তারাই ঢুকতে পারে।

Gradio-তে basic authentication খুব সহজ। `launch()`-এর ভিতরে `auth=("username", "password")` দিলে login page আসে। Gradio documentation অনুযায়ী `auth` হিসেবে single username-password tuple, multiple user list, অথবা custom function দেওয়া যায়। ([Gradio][2])

Example:

```python
app.launch(auth=("admin", "1234"))
```

এখন app open করলে আগে username/password চাইবে।

আরও secure system চাইলে custom function ব্যবহার করা যায়:

```python
def check_login(username, password):
    return username == "sayan" and password == "mypassword"

app.launch(auth=check_login)
```

## 3. GPT Integration কী?

**GPT Integration** মানে তোমার Gradio app-এর backend-এ OpenAI API যুক্ত করা।
User Gradio UI-তে প্রশ্ন লিখবে → Python function সেই প্রশ্ন OpenAI model-এ পাঠাবে → GPT answer তৈরি করবে → Gradio UI-তে answer দেখাবে।

OpenAI-এর official Python library-তে modern text generation-এর জন্য Responses API ব্যবহৃত হয়। OpenAI model-গুলো Responses API এবং SDK-এর মাধ্যমে ব্যবহার করা যায়। ([GitHub][3])

## 4. Full Flow সহজভাবে

পুরো system এভাবে কাজ করে:

```text
User opens Gradio app
        ↓
Login page appears
        ↓
User enters username/password
        ↓
If correct, chatbot UI opens
        ↓
User asks a question
        ↓
Python function sends question to GPT/OpenAI API
        ↓
GPT generates answer
        ↓
Answer is shown in Gradio chatbot
```

## 5. Simple Gradio + Authentication + GPT Code

```python
import os
import gradio as gr
from openai import OpenAI

# OpenAI client
client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))

def chat_with_gpt(message, history):
    response = client.responses.create(
        model="gpt-5.5",
        input=message
    )

    return response.output_text

demo = gr.ChatInterface(
    fn=chat_with_gpt,
    title="My GPT Chatbot",
    description="Login করে GPT chatbot ব্যবহার করুন।"
)

demo.launch(
    auth=("admin", "1234"),
    server_name="127.0.0.1",
    server_port=7860
)
```

## 6. Code Explanation

### `import gradio as gr`

এটা Gradio library import করে।
এর মাধ্যমে আমরা UI বানাবো।

### `from openai import OpenAI`

এটা OpenAI Python SDK import করে।
এর মাধ্যমে GPT model call করা হবে।

### `client = OpenAI(api_key=os.getenv("OPENAI_API_KEY"))`

এখানে API key environment variable থেকে নেওয়া হচ্ছে।
API key সরাসরি code-এর মধ্যে লেখা উচিত না, কারণ সেটা security risk।

### `def chat_with_gpt(message, history):`

এটা chatbot-এর main function।
User যখন message পাঠাবে, Gradio এই function call করবে।

### `client.responses.create(...)`

এখানে user-এর message GPT model-এ পাঠানো হচ্ছে।
তারপর model answer তৈরি করে।

### `gr.ChatInterface(...)`

এটা ready-made chatbot UI তৈরি করে।
তুমি নিজে manually textbox, submit button, chat history বানাতে হবে না।

### `demo.launch(auth=("admin", "1234"))`

এটা app run করে এবং login protection দেয়।
Username: `admin`
Password: `1234`
