### ১. Gradio কি?

Gradio হলো একটি **Python লাইব্রেরি**, যা দিয়ে **ডেটা সায়েন্স বা মেশিন লার্নিং মডেলকে ইন্টারেকটিভ ওয়েব ইউআই (UI) এ প্রকাশ** করা যায়।
**ফিচার:**

* কোনো HTML, CSS, বা JavaScript জানা লাগবে না।
* কোড লিখলেই ব্রাউজারে UI তৈরি হয়।
* ইউজার সহজে মডেলের সাথে ইন্টার‍্যাক্ট করতে পারে।

---

### ২. কিভাবে কাজ করে?

1. প্রথমে মডেল বা ফাংশন তৈরি করতে হবে যা ইনপুট নিয়ে আউটপুট দিবে।
2. Gradio দিয়ে এই ফাংশনকে UI এর সাথে সংযুক্ত করতে হবে।
3. এক লাইন কোডে আপনি ব্রাউজারে ওয়েব ইন্টারফেস পাবেন।

**উদাহরণ (Python কোড):**

```python
import gradio as gr

def multiply_by_two(number):
    return number * 2

demo = gr.Interface(fn=multiply_by_two, inputs="number", outputs="number")
demo.launch()
```

**ব্যাখ্যা:**

* `multiply_by_two` হলো ফাংশন যা ইনপুট সংখ্যা ২ দ্বারা গুণ করে।
* `gr.Interface` ফাংশনটি UI বানায়।
* `inputs="number"` ও `outputs="number"` দিয়ে ইনপুট ও আউটপুট টাইপ নির্ধারণ।
* `demo.launch()` দিয়ে ব্রাউজারে UI খোলে।

### ৩. কেন Gradio ব্যবহার করবেন?

* **সহজ:** Front-End জানা লাগবে না।
* **দ্রুত:** মিনিটের মধ্যে মডেল শেয়ার করা যায়।
* **ইন্টারেক্টিভ:** ইউজার রিয়েল টাইমে মডেলের সাথে কাজ করতে পারে।
* **Collaborative:** URL দিয়ে অন্যকে UI দেখানো বা টেস্ট করানো যায়।
