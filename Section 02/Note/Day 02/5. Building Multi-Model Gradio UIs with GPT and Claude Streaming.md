# Building Multi-Model Gradio UIs with GPT and Claude Streaming

এর মানে হলো:

> **একটা Gradio chatbot app বানানো, যেখানে user dropdown থেকে GPT বা Claude select করবে, তারপর selected model অনুযায়ী streaming response পাবে।**

মানে এক UI, কিন্তু ভিতরে multiple AI model.

---

# 1. Basic Idea

একটা normal GPT chatbot-এ flow হয়:

```text
User message → GPT API → GPT response → Gradio UI
```

কিন্তু multi-model chatbot-এ flow হবে:

```text
User message
   ↓
Model selector: GPT or Claude?
   ↓
If GPT → OpenAI API
If Claude → Anthropic API
   ↓
Streaming response
   ↓
Gradio chatbot output
```

এখানে Gradio UI frontend হিসেবে কাজ করবে, আর GPT/Claude backend AI model হিসেবে কাজ করবে। Gradio-এর `ChatInterface` দ্রুত chatbot বানানোর জন্য useful, কিন্তু custom dropdown, model selector, custom buttons, shared state ইত্যাদি দরকার হলে `Blocks` বেশি flexible। ([Gradio][1])

---

# 2. Why Multi-Model UI দরকার?

একই app থেকে different model test করা যায়।

যেমন:

| Use Case             | Better Choice                |
| -------------------- | ---------------------------- |
| Fast answer          | lightweight GPT/Claude model |
| Coding help          | stronger reasoning model     |
| Writing task         | GPT or Claude compare করা    |
| Long explanation     | Claude useful হতে পারে       |
| Tool/API integration | GPT useful হতে পারে          |

এই ধরনের UI model comparison, AI product testing, chatbot benchmark, study assistant, internal company AI tool — এসব ক্ষেত্রে useful.

---

# 3. Streaming কী?

**Streaming** মানে হলো model পুরো answer শেষ করার পর একবারে না পাঠিয়ে, ছোট ছোট অংশে live পাঠাবে।

Without streaming:

```text
Wait...
Then full answer appears.
```

With streaming:

```text
Answer starts appearing immediately...
line by line...
word by word...
```

OpenAI docs অনুযায়ী normal request-এ full output তৈরি হওয়ার পর response আসে, কিন্তু streaming করলে output generate হওয়ার সময়ই partial text process/display করা যায়। ([OpenAI Developers][2])

Claude API-তেও Python SDK দিয়ে sync/async streaming করা যায়। ([Claude][3])

---

# 4. Important Concept: Model Adapter

GPT আর Claude-এর API format same না।

তাই আমরা দুইটার জন্য আলাদা function বানাবো:

```text
stream_gpt()
stream_claude()
```

তারপর main router function decide করবে:

```python
if selected_model == "GPT":
    use stream_gpt()
else:
    use stream_claude()
```

এই pattern-কে বলা যায় **adapter pattern**.

মানে UI same থাকবে, কিন্তু backend model change হবে।

# 6. `.env` File

Project folder-এ `.env` file বানাও:

```env
OPENAI_API_KEY=your_openai_api_key_here
ANTHROPIC_API_KEY=your_anthropic_api_key_here

OPENAI_MODEL=your_openai_model_name_here
ANTHROPIC_MODEL=your_claude_model_name_here
```

Model name hardcode না করে `.env` থেকে নেওয়া ভালো, কারণ available model/version সময়ের সাথে change হতে পারে। Anthropic-এর Models API available models list করতে পারে, আর Claude docs model selection-এ capability, speed, cost বিবেচনা করতে বলে। ([Claude API Docs][5])

# 7. Full Code: Gradio + GPT + Claude + Streaming

```python
import os
import gradio as gr
from dotenv import load_dotenv
from openai import OpenAI
from anthropic import Anthropic

load_dotenv()

OPENAI_API_KEY = os.getenv("OPENAI_API_KEY")
ANTHROPIC_API_KEY = os.getenv("ANTHROPIC_API_KEY")

OPENAI_MODEL = os.getenv("OPENAI_MODEL")
ANTHROPIC_MODEL = os.getenv("ANTHROPIC_MODEL")

openai_client = OpenAI(api_key=OPENAI_API_KEY) if OPENAI_API_KEY else None
anthropic_client = Anthropic(api_key=ANTHROPIC_API_KEY) if ANTHROPIC_API_KEY else None

SYSTEM_PROMPT = """
You are a helpful AI tutor.
Answer clearly in Markdown.
Use headings, bullet points, tables, and code blocks when helpful.
"""


def convert_history_for_openai(history):
    messages = []

    for item in history:
        role = item.get("role")
        content = item.get("content")

        if role in ["user", "assistant"] and isinstance(content, str) and content.strip():
            messages.append({
                "role": role,
                "content": content
            })

    return messages


def convert_history_for_claude(history):
    messages = []

    for item in history:
        role = item.get("role")
        content = item.get("content")

        if role in ["user", "assistant"] and isinstance(content, str) and content.strip():
            messages.append({
                "role": role,
                "content": content
            })

    return messages


def stream_gpt(history):
    if openai_client is None:
        yield "Error: OPENAI_API_KEY is missing."
        return

    if not OPENAI_MODEL:
        yield "Error: OPENAI_MODEL is missing in your .env file."
        return

    input_messages = convert_history_for_openai(history)

    stream = openai_client.responses.create(
        model=OPENAI_MODEL,
        instructions=SYSTEM_PROMPT,
        input=input_messages,
        stream=True
    )

    partial = ""

    for event in stream:
        if event.type == "response.output_text.delta":
            partial += event.delta
            yield partial


def stream_claude(history):
    if anthropic_client is None:
        yield "Error: ANTHROPIC_API_KEY is missing."
        return

    if not ANTHROPIC_MODEL:
        yield "Error: ANTHROPIC_MODEL is missing in your .env file."
        return

    messages = convert_history_for_claude(history)

    with anthropic_client.messages.stream(
        model=ANTHROPIC_MODEL,
        max_tokens=1200,
        system=SYSTEM_PROMPT,
        messages=messages
    ) as stream:
        partial = ""

        for text in stream.text_stream:
            partial += text
            yield partial


def add_user_message(user_message, history):
    if not user_message.strip():
        return "", history

    history = history + [
        {
            "role": "user",
            "content": user_message
        }
    ]

    return "", history


def generate_response(history, selected_model):
    if not history:
        yield history
        return

    history = history + [
        {
            "role": "assistant",
            "content": ""
        }
    ]

    if selected_model == "GPT":
        response_stream = stream_gpt(history[:-1])
    else:
        response_stream = stream_claude(history[:-1])

    for partial_response in response_stream:
        history[-1]["content"] = partial_response
        yield history


with gr.Blocks(title="Multi-Model GPT + Claude Chatbot") as demo:
    gr.Markdown("# Multi-Model GPT + Claude Chatbot")
    gr.Markdown("Choose a model, ask a question, and get a streaming Markdown response.")

    selected_model = gr.Dropdown(
        choices=["GPT", "Claude"],
        value="GPT",
        label="Choose Model"
    )

    chatbot = gr.Chatbot(
        label="Chat",
        type="messages",
        height=500
    )

    user_input = gr.Textbox(
        placeholder="Ask something...",
        label="Your Message"
    )

    clear_button = gr.Button("Clear Chat")

    user_input.submit(
        fn=add_user_message,
        inputs=[user_input, chatbot],
        outputs=[user_input, chatbot],
        queue=False
    ).then(
        fn=generate_response,
        inputs=[chatbot, selected_model],
        outputs=chatbot
    )

    clear_button.click(
        fn=lambda: [],
        inputs=None,
        outputs=chatbot,
        queue=False
    )

demo.queue()
demo.launch()
```

# 8. Code Breakdown

## `selected_model`

```python
selected_model = gr.Dropdown(
    choices=["GPT", "Claude"],
    value="GPT",
    label="Choose Model"
)
```

এটা user-কে model choose করতে দেয়। Gradio-এর `Dropdown` component choices থেকে single বা multiple value select করার জন্য ব্যবহার করা যায়। ([Gradio][6])

---

## `gr.Chatbot(type="messages")`

```python
chatbot = gr.Chatbot(type="messages")
```

এখানে chat history OpenAI-style message format-এ রাখা হচ্ছে:

```python
{"role": "user", "content": "Hello"}
{"role": "assistant", "content": "Hi!"}
```

Gradio `Chatbot` Markdown-এর subset support করে, যেমন bold, italic, code, table ইত্যাদি। তাই GPT/Claude যদি Markdown output দেয়, UI সেটা formattedভাবে দেখাতে পারে। ([Gradio][7])

---

## `yield` দিয়ে Streaming

```python
for partial_response in response_stream:
    history[-1]["content"] = partial_response
    yield history
```

এখানে `yield` হচ্ছে Gradio streaming-এর মূল জিনিস।

`return` দিলে final answer একবারে আসবে।
`yield` দিলে partial answer বারবার UI-তে update হবে।

# 9. GPT Streaming Part

```python
stream = openai_client.responses.create(
    model=OPENAI_MODEL,
    instructions=SYSTEM_PROMPT,
    input=input_messages,
    stream=True
)
```

এখানে `stream=True` দেওয়ায় OpenAI response event আকারে আসে। `response.output_text.delta` event থেকে generated text-এর ছোট ছোট অংশ পাওয়া যায়। OpenAI Responses API বর্তমানে OpenAI Python SDK-এর primary API হিসেবে documented, এবং streaming server-sent events ব্যবহার করে। ([OpenAI Developers][4])

# 10. Claude Streaming Part

```python
with anthropic_client.messages.stream(
    model=ANTHROPIC_MODEL,
    max_tokens=1200,
    system=SYSTEM_PROMPT,
    messages=messages
) as stream:
    for text in stream.text_stream:
        yield text
```

Claude Messages API conversational interaction-এর জন্য ব্যবহৃত হয়, যেখানে developer নিজে conversation state manage করে। Anthropic docs অনুযায়ী Python SDK sync এবং async streaming support করে। ([Claude API Docs][8])

---

# 11. Key Difference: GPT vs Claude API Format

| Topic              | GPT / OpenAI                 | Claude / Anthropic   |
| ------------------ | ---------------------------- | -------------------- |
| Main API           | Responses API                | Messages API         |
| System instruction | `instructions=`              | `system=`            |
| Message history    | `input=`                     | `messages=`          |
| Streaming text     | `response.output_text.delta` | `stream.text_stream` |
| Client             | `OpenAI()`                   | `Anthropic()`        |

# 12. Final Summary

**Multi-model Gradio UI** মানে একটি Gradio app যেখানে user GPT বা Claude select করতে পারে।

Main components:

1. **Gradio Blocks** → custom UI বানানোর জন্য
2. **Dropdown** → model choose করার জন্য
3. **Chatbot** → conversation দেখানোর জন্য
4. **OpenAI client** → GPT response আনার জন্য
5. **Anthropic client** → Claude response আনার জন্য
6. **Streaming generator** → live response দেখানোর জন্য
7. **Adapter functions** → GPT ও Claude API difference handle করার জন্য

সবচেয়ে important idea:

```text
Same UI
Different model backend
Same streaming experience
```

মানে user-এর দিক থেকে experience same, কিন্তু backend-এ GPT বা Claude যেকোনো model কাজ করতে পারে।
