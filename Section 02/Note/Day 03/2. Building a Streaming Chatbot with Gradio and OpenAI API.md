### ৪. স্ট্রিমিং ফাংশন

```python
def stream_chat(user_message, chat_history):
    chat_history = chat_history or []
    chat_history.append(("You", user_message))

    # OpenAI streaming call
    response_text = ""
    for chunk in openai.ChatCompletion.create(
        model="gpt-4",
        messages=[{"role": "system", "content": "You are a helpful assistant."}] +
                 [{"role": "user", "content": user_message}],
        stream=True
    ):
        if "choices" in chunk:
            delta = chunk["choices"][0]["delta"]
            if "content" in delta:
                response_text += delta["content"]
                # Update chat_history live
                yield chat_history + [("AI", response_text)]
```

**বিঃদ্রঃ**

* `stream=True` দিলে মডেল ধাপে ধাপে আউটপুট পাঠায়।
* `yield` ব্যবহার করে Gradio তে লাইভ আপডেট দেখানো যায়।

### ৫. Gradio UI তৈরি

```python
with gr.Blocks() as demo:
    chatbot = gr.Chatbot()
    msg = gr.Textbox(placeholder="Type your message here...")
    send_btn = gr.Button("Send")

    send_btn.click(fn=stream_chat, 
                   inputs=[msg, chatbot], 
                   outputs=chatbot)

demo.launch()
```

* `gr.Blocks()` দিয়ে কাস্টম লেআউট তৈরি করা যায়।
* `Chatbot()` widget দিয়ে চ্যাট বক্স তৈরি হয়।
* Textbox এবং Button দিয়ে ইউজারের ইনপুট নেয়া হয়।
* স্ট্রিমিং রেসপন্স live update করে Chatbot-এ দেখানো হয়।
