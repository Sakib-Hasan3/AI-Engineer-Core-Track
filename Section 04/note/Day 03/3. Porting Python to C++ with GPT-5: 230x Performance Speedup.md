# ১. Porting বলতে কী বোঝায়?

**Porting** হলো একটি সফটওয়্যার বা কোডকে এক প্ল্যাটফর্ম বা প্রোগ্রামিং ভাষা থেকে অন্যটিতে স্থানান্তর করা।

উদাহরণ:

Python:

```python
def sum_numbers(n):
    total = 0
    for i in range(n):
        total += i
    return total
```

C++:

```cpp
long long sumNumbers(int n) {
    long long total = 0;

    for(int i = 0; i < n; i++) {
        total += i;
    }

    return total;
}
```

এখানে Python → C++ রূপান্তর হয়েছে।

# ২. Speedup কী?

Speedup পরিমাপ করে নতুন প্রোগ্রাম কত দ্রুত চলছে।

সূত্র:

Speedup=\frac{Old\ Time}{New\ Time}

উদাহরণ:

Python Execution Time:

```text
230 seconds
```

C++ Execution Time:

```text
1 second
```

তাহলে:

Speedup=\frac{230}{1}=230

অর্থাৎ:

**230× Faster**
