# ৩. Python → C++ Conversion কী?

ধরো Python কোড:

```python
def add(a, b):
    return a + b

print(add(5, 10))
```

C++ Version:

```cpp
#include <iostream>

using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(5, 10);
    return 0;
}
```

AI-এর কাজ:

1. Python Logic বুঝবে
2. C++ Syntax-এ রূপান্তর করবে
3. Data Type যোগ করবে
4. Memory Management বিবেচনা করবে
5. Optimized Code তৈরি করবে

# ৪. Python → C++ Conversion কেন কঠিন?

কারণ Python এবং C++ সম্পূর্ণ ভিন্ন ধরনের ভাষা।

| Python             | C++                      |
| ------------------ | ------------------------ |
| Dynamic Typing     | Static Typing            |
| Garbage Collection | Manual Memory Management |
| Simple Syntax      | Complex Syntax           |
| Slow               | Fast                     |
| Interpreted        | Compiled                 |

উদাহরণ:

Python:

```python
x = 10
```

C++:

```cpp
int x = 10;
```

AI-কে এখানে Type অনুমান করতে হয়।

# ৬. Python থেকে C++ Conversion Workflow

ধাপ ১

Python Code:

```python
numbers = [1,2,3,4,5]

for n in numbers:
    print(n)
```

---

ধাপ ২

Cursor Prompt:

```text
Convert this Python code to modern C++17.
Use vectors and range-based loops.
Explain every change.
```

---

ধাপ ৩

Generated C++:

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main() {
    vector<int> numbers = {1,2,3,4,5};

    for (int n : numbers) {
        cout << n << endl;
    }

    return 0;
}
```
