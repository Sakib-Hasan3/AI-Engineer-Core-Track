# ২. C++ Code Generation কী?

AI-কে নির্দেশ দিলে সে C++ কোড লিখে দেয়।

উদাহরণ:

Prompt:

```text
Write a C++ program to implement Binary Search.
```

AI:

```cpp
#include <iostream>
#include <vector>

int binarySearch(const std::vector<int>& arr, int target) {
    int left = 0;
    int right = arr.size() - 1;

    while(left <= right) {
        int mid = left + (right - left) / 2;

        if(arr[mid] == target)
            return mid;

        if(arr[mid] < target)
            left = mid + 1;
        else
            right = mid - 1;
    }

    return -1;
}
```

# Viva / Interview Answer

**Question:** Why compare GPT-5, Claude, Grok and Gemini for C++ code generation?

**Answer:**

> Different frontier AI models have different strengths. GPT-5 excels at code generation and reasoning, Claude is strong in large codebase analysis, Gemini performs well in algorithmic problem solving, and Grok provides fast debugging assistance. Choosing the right model improves software development efficiency and code quality.

### সংক্ষিপ্ত উপসংহার

* **GPT-5** → Overall Best for C++ Development
* **Claude** → Large Project Analysis & Documentation
* **Gemini** → Algorithms & Competitive Programming
* **Grok** → Fast Debugging & Quick Assistance

একজন CSE ছাত্র বা সফটওয়্যার ডেভেলপারের জন্য **GPT-5 + Claude** কম্বিনেশন সাধারণত সবচেয়ে শক্তিশালী সেটআপ হিসেবে বিবেচিত হয়।
