# ৫. Python → C++ Conversion Function

এটা মূল core logic:

## Option A: GPT-5 / API-based

```python
import openai

def convert_to_cpp(code):
    prompt = f"""
    Convert this Python code to modern C++17:

    {code}

    Requirements:
    - Use STL
    - Optimize performance
    - Add comments
    """

    response = openai.ChatCompletion.create(
        model="gpt-5",
        messages=[{"role": "user", "content": prompt}]
    )

    return response["choices"][0]["message"]["content"]
```

---

## Option B: DeepSeek (Open Source via API)

```python
import requests

def convert_to_cpp(code):
    url = "http://localhost:11434/api/generate"

    prompt = f"""
    Convert Python to C++17:

    {code}
    """

    payload = {
        "model": "deepseek-coder",
        "prompt": prompt,
        "stream": False
    }

    res = requests.post(url, json=payload)
    return res.json()["response"]
```

# ৬. Gradio UI Build

```python
def ui_convert(code):
    return convert_to_cpp(code)

interface = gr.Interface(
    fn=ui_convert,
    inputs=gr.Textbox(lines=10, label="Python Code"),
    outputs=gr.Textbox(lines=10, label="C++ Code"),
    title="Python → C++ Converter",
    description="Test AI models for code translation"
)

interface.launch()
```

# Viva / Interview Answer

**Question:** How can you build a Gradio UI for Python-to-C++ code conversion?

**Answer:**

> We can use Gradio, a Python-based UI framework, to create a simple web interface where users input Python code. The backend sends this code to an LLM like GPT-5, DeepSeek, or Qwen, which converts it into optimized C++ code. The output is then displayed in the UI, allowing real-time testing and comparison of different AI models for code translation tasks.
