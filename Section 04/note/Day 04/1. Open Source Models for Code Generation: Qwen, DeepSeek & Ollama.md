# ১. Open Source Code Models কী?

Open-source code models হলো এমন AI মডেল যেগুলো:

* ফ্রি বা self-host করা যায়
* লোকাল PC-তে চালানো যায়
* Internet ছাড়াও কাজ করতে পারে
* Code generation + debugging করতে পারে

এগুলো closed models (GPT-5, Claude) থেকে আলাদা কারণ:

| Closed Models   | Open Source Models |
| --------------- | ------------------ |
| Cloud-based     | Local run possible |
| Paid API        | Free/self-host     |
| Limited control | Full control       |
| High quality    | Improving fast     |

# ৪. Ollama (Local AI Runtime)

[Ollama](https://ollama.com?utm_source=chatgpt.com)

## কী এটা?

Ollama কোনো model না—এটা হলো:

> **Local AI model runner**

মানে তুমি নিজের laptop/PC-তে AI চালাতে পারো।

---

## কীভাবে কাজ করে?

তুমি install করো:

```bash id="o1"
ollama run qwen2.5-coder
```

বা

```bash id="o2"
ollama run deepseek-coder
```

---

## Ollama-এর সুবিধা

✅ Offline AI coding assistant
✅ No API cost
✅ VS Code / Cursor integration
✅ Privacy full control

---

## Ollama + Code Workflow

1. Install Ollama
2. Download model
3. Run locally
4. Use VS Code extension

---

## Example Use

Prompt:

```text id="o3"
Convert this Python script to optimized C++17.
```

Output:

* Local generated code
* No internet required

# Viva / Interview Answer

**Question:** What are Qwen, DeepSeek and Ollama in code generation?

**Answer:**

> Qwen and DeepSeek are open-source large language models optimized for coding tasks like C++ generation, debugging and algorithm solving. Ollama is a local runtime environment that allows running these models on personal machines without internet. Together they provide a powerful offline alternative to closed AI systems for code generation and software development.
