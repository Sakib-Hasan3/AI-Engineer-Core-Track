# Intelligence Score কী?

Artificial Analysis বিভিন্ন Benchmark-এর ফলাফল একত্র করে একটি **Intelligence Score** তৈরি করে।

এতে সাধারণত অন্তর্ভুক্ত থাকে:

* Knowledge
* Reasoning
* Mathematics
* Coding
* Problem Solving

ধারণাগতভাবে:

```text
Intelligence Score
=
Reasoning
+ Coding
+ Knowledge
+ Math
+ General Capability
```

এটি একটি একক Benchmark নয়; বরং বিভিন্ন Benchmark-এর সমন্বিত মূল্যায়ন।

# Cost Comparison কেন গুরুত্বপূর্ণ?

অনেক মানুষ শুধু "সবচেয়ে শক্তিশালী Model" খোঁজে।

কিন্তু বাস্তবে প্রশ্ন হলো:

> "প্রতি ডলারে আমি কত Performance পাচ্ছি?"

ধরুন:

| Model   | Intelligence | Cost |
| ------- | ------------ | ---- |
| Model A | 95           | $20  |
| Model B | 92           | $2   |

এখানে Model A সামান্য ভালো হলেও Model B অনেক বেশি Cost-Effective হতে পারে।

# Cost-Efficiency কী?

Cost-Efficiency বোঝায়:

> কম খরচে কত Performance পাওয়া যাচ্ছে।

উদাহরণ:

| Model | Intelligence | Cost |
| ----- | ------------ | ---- |
| A     | 95           | $20  |
| B     | 90           | $3   |

অনেক ব্যবসা Model B বেছে নেবে কারণ Performance খুব কাছাকাছি কিন্তু খরচ অনেক কম।
