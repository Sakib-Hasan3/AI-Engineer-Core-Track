## 🔹 Rust

---

## Example Conversion

### Python Code

```python id="p1"
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n-1)
```

---

### Rust Equivalent

```rust id="r1"
fn factorial(n: u64) -> u64 {
    if n == 0 {
        return 1;
    }
    n * factorial(n - 1)
}
```

👉 এখানে AI-কে করতে হয়:

* Type inference
* Memory safety rules
* Ownership model adaptation

# ৬. Common AI Mistakes in Python → Rust

## ❌ 1. Borrowing Errors

AI sometimes writes:

```rust id="r5"
fn foo(s: String) -> String {
    s
}
```

👉 inefficient ownership transfer

---

## ❌ 2. Wrong Type Mapping

Python:

```python id="p3"
list[int]
```

Wrong Rust:

```rust id="r6"
Vec<int>
```

Correct:

```rust id="r7"
Vec<i32>
```

---

## ❌ 3. Overcomplicated code

Python simple:

```python id="p4"
sum(arr)
```

AI sometimes writes long Rust loop instead of:

```rust id="r8"
arr.iter().sum::<i32>()
```

---

# ৭. Best Prompt Strategy (Very Important)

## ❌ Bad Prompt

```text id="b1"
Convert to Rust
```

---

## ✅ Good Prompt

```text id="b2"
Convert this Python code to idiomatic Rust.

Constraints:
- Use iterators
- Use borrowing where possible (&[])
- Avoid cloning unless necessary
- Optimize for performance
- Explain ownership decisions
```

👉 This improves output quality drastically.
