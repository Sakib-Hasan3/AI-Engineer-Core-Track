# ৬. Rust Code Generation Example (Speed Test)

## Task:

“Implement merge sort in Rust”

---

## 🟡 Qwen Output (fast)

```rust id="q1"
fn merge_sort(mut arr: Vec<i32>) -> Vec<i32> {
    if arr.len() <= 1 {
        return arr;
    }
    let mid = arr.len() / 2;
    let left = merge_sort(arr[..mid].to_vec());
    let right = merge_sort(arr[mid..].to_vec());
    merge(left, right)
}
```

👉 দ্রুত output
⚠ slight inefficiency (.to_vec())

---

## 🔵 GPT Output (slower but better)

```rust id="g1"
fn merge_sort(arr: &[i32]) -> Vec<i32> {
    if arr.len() <= 1 {
        return arr.to_vec();
    }
    let mid = arr.len() / 2;
    let left = merge_sort(&arr[..mid]);
    let right = merge_sort(&arr[mid..]);
    merge(left, right)
}
```

👉 more idiomatic Rust
👉 better memory handling
