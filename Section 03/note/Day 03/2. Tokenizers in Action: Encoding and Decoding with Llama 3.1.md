# Tokenizers in Action: Encoding and Decoding with Llama 3.1 — বাংলায়

Meta এর Llama 3.1 model text বুঝার আগে tokenizer ব্যবহার করে text কে token এবং token ID তে convert করে।

এই process এর দুইটি প্রধান অংশ:

1. Encoding → Text → Numbers
2. Decoding → Numbers → Text

---

# ১. Llama 3.1 Tokenizer কী?

Llama 3.1 tokenizer হলো এমন একটি system যা:

```text
Human Text
    ↓
Tokens
    ↓
Token IDs
```

এ convert করে।

LLM model শুধুমাত্র token ID নিয়ে কাজ করে।

# ১২. Padding

সব sentence same length করার জন্য extra token যোগ করা হয়।

```text
[1,2,3]
[1,2,3,4,5]
```

Padding এর পর:

```text
[1,2,3,0,0]
[1,2,3,4,5]
```

# ১৪. Special Tokens

Llama tokenizer কিছু special token ব্যবহার করে।

যেমন:

| Token | কাজ                   |
| ----- | --------------------- |
| BOS   | Beginning of sentence |
| EOS   | End of sentence       |
| PAD   | Padding               |
| UNK   | Unknown token         |

# ২০. Model এ Input পাঠানো

```python
from transformers import AutoModelForCausalLM

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Meta-Llama-3.1-8B-Instruct"
)

inputs = tokenizer(
    "What is AI?",
    return_tensors="pt"
)

output = model.generate(
    **inputs,
    max_new_tokens=20
)

print(
    tokenizer.decode(output[0])
)
```

# ২৫. Complete Practical Example

```python
from transformers import AutoTokenizer

# Load tokenizer
tokenizer = AutoTokenizer.from_pretrained(
    "meta-llama/Meta-Llama-3.1-8B-Instruct"
)

text = "I love studying AI"

# Tokenize
tokens = tokenizer.tokenize(text)
print("Tokens:", tokens)

# Convert to IDs
ids = tokenizer.convert_tokens_to_ids(tokens)
print("IDs:", ids)

# Full encoding
encoded = tokenizer(text)
print("Encoded:", encoded)

# Decode back
decoded = tokenizer.decode(
    encoded["input_ids"]
)

print("Decoded:", decoded)
```
