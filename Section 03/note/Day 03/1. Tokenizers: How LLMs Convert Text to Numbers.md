# Tokenizers: How LLMs Convert Text to Numbers — বাংলায়

LLM (Large Language Model) যেমন OpenAI এর GPT বা [Hugging Face](https://huggingface.co?utm_source=chatgpt.com) এর Transformer model সরাসরি text বুঝতে পারে না।

কম্পিউটার শুধু সংখ্যা (numbers) বুঝে।

তাই text কে number এ convert করার জন্য ব্যবহার করা হয়:

# Tokenizer

---

# ১. Tokenizer কী?

Tokenizer হলো এমন একটি system যা:

```text
Text → Tokens → Token IDs (Numbers)
```

এ convert করে।

উদাহরণ:

```text
"I love AI"
```

Tokenizer এটাকে ভাগ করতে পারে:

```text
["I", "love", "AI"]
```

তারপর প্রতিটি token কে number দেয়:

```text
[40, 1567, 8921]
```

এই সংখ্যাগুলো model এর input হয়।

---

# ২. কেন Tokenization দরকার?

কারণ Neural Network text না, শুধুমাত্র matrix/numbers নিয়ে কাজ করে।

তাই:

```text
Human Language
      ↓
Tokenizer
      ↓
Numbers
      ↓
LLM বুঝতে পারে
```

---

Token সবসময় word না।

* পুরো word

* character
* punctuation

# ৭. Special Tokens

Transformer model কিছু special token ব্যবহার করে।

যেমন:

| Token    | কাজ            |
| -------- | -------------- |
| `[CLS]`  | sentence start |
| `[SEP]`  | separator      |
| `[PAD]`  | padding        |
| `[MASK]` | masked word    |

# ১২. Tokenization Workflow

```text
Input Text
    ↓
Cleaning
    ↓
Split into Tokens
    ↓
Convert to IDs
    ↓
Add Special Tokens
    ↓
Padding/Truncation
    ↓
Tensor তৈরি
```

---

# ১৩. Padding কী?

সব sentence একই length করার জন্য extra token যোগ করা হয়।

উদাহরণ:

```text
[1, 5, 8]
[1, 7, 9, 3, 2]
```

Padding এর পর:

```text
[1, 5, 8, 0, 0]
[1, 7, 9, 3, 2]
```

---

# ১৪. Attention Mask

Model কে বলে কোন token real আর কোনটা padding।

```python
attention_mask = [1,1,1,0,0]
```

* `1` → real token
* `0` → padding

# ২৪. Complete Example

```python
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained(
    "bert-base-uncased"
)

text = "I love AI"

# Tokenize
tokens = tokenizer.tokenize(text)
print(tokens)

# Convert to IDs
ids = tokenizer.convert_tokens_to_ids(tokens)
print(ids)

# Full Encoding
encoded = tokenizer(text)
print(encoded)

# Decode
decoded = tokenizer.decode(encoded["input_ids"])
print(decoded)
```
