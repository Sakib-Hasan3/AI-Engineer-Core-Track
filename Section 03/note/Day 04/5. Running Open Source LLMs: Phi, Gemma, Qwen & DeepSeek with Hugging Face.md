# ৩. Running Microsoft Phi Model

Example: Phi-4 Mini

```python id="os3"
from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

model_name = "microsoft/phi-4"

tokenizer = AutoTokenizer.from_pretrained(model_name)

model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.float16,
    device_map="auto"
)

prompt = "Explain artificial intelligence simply."

inputs = tokenizer(prompt, return_tensors="pt").to(model.device)

outputs = model.generate(
    **inputs,
    max_new_tokens=100
)

print(tokenizer.decode(outputs[0]))
```

# ৭. Text Generation Example

সব model এর জন্য similar:

```python id="os7"
prompt = "What is machine learning?"

inputs = tokenizer(
    prompt,
    return_tensors="pt"
).to(model.device)

outputs = model.generate(
    **inputs,
    max_new_tokens=80,
    temperature=0.7
)

print(
    tokenizer.decode(outputs[0])
)
```

---

# ৮. Temperature Control

p(x)=\text{softmax}\left(\frac{z}{T}\right)

| Temperature | Result   |
| ----------- | -------- |
| 0.2         | factual  |
| 0.7         | balanced |
| 1.2         | creative |

# ৯. Quantization (Very Important)

Large models অনেক RAM নেয়।

তাই quantization ব্যবহার করা হয়।

---

## INT8 Example

```python id="os8"
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    load_in_8bit=True,
    device_map="auto"
)
```

---

## INT4 Example

```python id="os9"
model = AutoModelForCausalLM.from_pretrained(
    model_name,
```
