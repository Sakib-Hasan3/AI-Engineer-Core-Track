# ১. Low-Level API কী?

Hugging Face Transformers-এর low-level API মানে:

* `AutoTokenizer`
* `AutoModelForCausalLM`
* `torch tensors`
* `logits`
* manual generation control

👉 এখানে আপনি পুরো inference pipeline নিজে control করেন।

---

# ২. Full Low-Level Inference Flow

```text id="ll1"
Text
 ↓
Tokenizer
 ↓
Token IDs
 ↓
Model Forward Pass
 ↓
Logits (scores)
 ↓
Sampling / Greedy
 ↓
Next Token
 ↓
Repeat (autoregressive loop)
 ↓
Decode
```

# ৩. Basic Low-Level Setup

```python id="hf1"
from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

model_name = "gpt2"

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name)

model.eval()
```

# ৪. Encoding (Text → Numbers)

```python id="hf2"
text = "AI is changing the world"

inputs = tokenizer(text, return_tensors="pt")

print(inputs)
```

Output:

```text
input_ids
attention_mask
```

# ৫. Forward Pass (Model Inference)

```python id="hf3"
with torch.no_grad():
    outputs = model(**inputs)

logits = outputs.logits

print(logits.shape)
```

👉 Shape:

```text
(batch_size, sequence_length, vocab_size)
```

---

# ৬. Logits কী?

Logits = model-এর raw prediction score

p(x_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}

👉 Softmax দিলে probability পাওয়া যায়।

---

# ৭. Next Token Prediction (Core Idea)

```python id="hf4"
next_token_logits = logits[:, -1, :]
next_token_id = torch.argmax(next_token_logits, dim=-1)

print(next_token_id)
```

---

# ৮. Decode Token

```python id="hf5"
token = tokenizer.decode(next_token_id)

print(token)
```

---

# ৯. Manual Text Generation Loop

```python id="hf6"
generated = inputs["input_ids"]

for _ in range(20):
    with torch.no_grad():
        outputs = model(generated)
    
    logits = outputs.logits[:, -1, :]
    
    next_token = torch.argmax(logits, dim=-1).unsqueeze(0)
    
    generated = torch.cat((generated, next_token), dim=1)

print(tokenizer.decode(generated[0]))
```

---

# ১০. Greedy vs Sampling

## Greedy (default)

```text id="g1"
সবসময় highest probability token
→ deterministic
```

---

## Sampling

```python id="hf7"
probs = torch.softmax(logits[:, -1, :], dim=-1)

next_token = torch.multinomial(probs, num_samples=1)
```

---

# ১১. Temperature Control

p(x) = \text{softmax}\left(\frac{z}{T}\right)

| Temperature | Behavior     |
| ----------- | ------------ |
| 0.2         | strict, safe |
| 0.7         | balanced     |
| 1.2         | creative     |

---

# ১২. Top-k Sampling

```python id="hf8"
top_k = 50
values, indices = torch.topk(logits[:, -1, :], top_k)
```

👉 শুধু top-k tokens consider করা হয়

---

# ১৩. Top-p (Nucleus Sampling)

```python id="hf9"
sorted_probs, sorted_indices = torch.sort(probs, descending=True)
cumulative = torch.cumsum(sorted_probs, dim=-1)
```

👉 probability mass অনুযায়ী dynamic selection

# ১৪. Quantization — Model Compression

Quantization মানে:

> Full precision weights → low precision weights

---

# ১৫. Precision Levels

| Type | Size       | Speed     |
| ---- | ---------- | --------- |
| FP32 | large      | slow      |
| FP16 | medium     | fast      |
| INT8 | small      | very fast |
| INT4 | very small | fastest   |

---

# ১৬. Why Quantization?

Modern LLM খুব বড়:

* billions of parameters
* huge VRAM usage

👉 quantization solves:

✔ memory problem
✔ speed problem
✔ deployment problem

# ২০. Quantization Internals
