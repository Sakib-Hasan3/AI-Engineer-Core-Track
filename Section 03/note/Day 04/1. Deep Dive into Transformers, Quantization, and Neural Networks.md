# ১. Neural Networks (NN) — AI এর ভিত্তি

Neural Network হলো এমন একটি mathematical system যা data থেকে pattern শিখে।

## Basic idea:

```text id="nn1"
Input → Weights → Layers → Output
```

---

## একটি simple neuron:

```text id="nn2"
x1 ----\
x2 ----- → (Weighted Sum) → Activation → Output
x3 ----/
```

---

## Formula:

y = \sigma(w_1x_1 + w_2x_2 + \cdots + w_nx_n + b)

---

## Key parts:

| Component  | কাজ                 |
| ---------- | ------------------- |
| Weights    | importance শেখে     |
| Bias       | adjustment          |
| Activation | non-linearity       |
| Layers     | deep learning power |

---

## Neural Network কী শিখে?

* image pattern
* text meaning
* speech
* code structure

---

# ২. Deep Learning → Neural Network + Depth

Deep Learning মানে:

> অনেক layers যুক্ত neural network

```text id="dl1"
Input → Layer1 → Layer2 → Layer3 → Output
```

---

## Why “deep” matters?

* low layer → simple patterns (edges, words)
* mid layer → structure
* high layer → meaning/context

---

## Transformer Core Idea:

> “Attention is everything”

---

# ৪. Self-Attention Mechanism

Transformer বুঝে কোন word অন্য word-এর সাথে কতটা related।

Example:

```text id="att1"
"I love Bangladesh because it is beautiful"
```

Model বুঝে:

* "it" → Bangladesh
* "love" → emotion
* "beautiful" → Bangladesh

---

## Attention formula:

\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V

---

## সহজভাবে:

```text id="att2"
Word → Compare with all words → Decide importance → Weighted output
```

---

# ৫. Transformer Architecture

```text id="tr1"
Input Tokens
     ↓
Embedding
     ↓
Positional Encoding
     ↓
Multi-Head Attention
     ↓
Feed Forward Network
     ↓
Output
```

---

## Two main blocks:

### 1. Encoder

* input understanding

### 2. Decoder

* output generation

---

# ৬. Why Transformers are powerful?

* parallel processing (fast)
* long context handling
* better memory than RNN/LSTM
* scalable to billions of parameters

---

# ৭. Quantization — Model Optimization Technique

Quantization মানে:

> model weights কে high precision → low precision এ convert করা

---

## Example:

### Before quantization:

```text id="q1"
32-bit float:
0.123456789
```

### After quantization:

```text id="q2"
8-bit:
0.12
```

---

# ৮. Why Quantization needed?

Modern LLM huge:

* 7B parameters → ~14GB+
* 70B → 100GB+

So we reduce size:

---

## Benefits:

| Benefit          | Result      |
| ---------------- | ----------- |
| smaller model    | less RAM    |
| faster inference | low latency |
| cheaper          | low compute |
| mobile usage     | possible    |

---

# ৯. Types of Quantization

## 1. FP32 (Full precision)

* very accurate
* slow

## 2. FP16 / BF16

* balanced
* GPU friendly

## 3. INT8

* fast
* low memory

## 4. INT4 (LLM quantization)

* very small
* used in LLaMA / Qwen / DeepSeek models

---

# ১০. Quantization Flow

```text id="qt1"
Full Model (FP32)
      ↓
Compression
      ↓
FP16 / INT8 / INT4
      ↓
Smaller Fast Model
```

---

# ১১. Tradeoff: Accuracy vs Speed

| Type | Accuracy | Speed     | Size       |
| ---- | -------- | --------- | ---------- |
| FP32 | ⭐⭐⭐⭐⭐    | slow      | big        |
| FP16 | ⭐⭐⭐⭐     | fast      | medium     |
| INT8 | ⭐⭐⭐      | very fast | small      |
| INT4 | ⭐⭐–⭐⭐⭐   | fastest   | very small |
