# Step 5: First Hugging Face Model Run

এখন প্রথম AI model run করবো।

```python id="40jlwm"
from transformers import pipeline

generator = pipeline("text-generation")

result = generator(
    "Artificial Intelligence is",
    max_length=30
)

print(result)
```

---

# এখানে কী হচ্ছে?

## pipeline()

`pipeline()` সহজে pretrained model ব্যবহার করতে সাহায্য করে।

---

## text-generation

এটি text generate করার task।

---

## max_length

Generated text কত বড় হবে।

# Step 6: Specific Model ব্যবহার

# Colab Session সম্পর্কে Important কথা

Colab runtime temporary।

* installed packages চলে যেতে পারে
* downloaded model delete হতে পারে
