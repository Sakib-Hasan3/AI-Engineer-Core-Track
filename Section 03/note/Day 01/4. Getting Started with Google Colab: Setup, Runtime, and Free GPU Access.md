# Getting Started with Google Colab (বাংলায়)

## Google Colab কী?

[Google Colab](https://colab.research.google.com?utm_source=chatgpt.com) হলো একটি free cloud-based Jupyter Notebook platform যেখানে browser দিয়েই Python code run করা যায়।

এটি বিশেষভাবে:

* Machine Learning
* Deep Learning
* Data Science
* AI Development

এর জন্য খুব জনপ্রিয়।

---

# কেন Google Colab ব্যবহার করবো?

## কারণ

### ১. কিছু install করতে হয় না

Browser থেকেই coding করা যায়।

### ২. Free GPU পাওয়া যায়

Deep Learning training fast হয়।

### ৩. Google Drive এর সাথে connected

Notebook auto save হয়।

### ৪. Python pre-installed

অনেক library আগেই installed থাকে।

---

# Step-by-Step Google Colab Setup

---

# Step 1: Google Account লাগবে

প্রথমে একটি Google/Gmail account থাকতে হবে।

---

# Step 2: Colab Open করা

এখানে যাও:

[Open Google Colab](https://colab.research.google.com?utm_source=chatgpt.com)

---

# Step 3: New Notebook Create

## Option 1

File → New Notebook

## Option 2

Google Drive → New → More → Colaboratory

---

# Notebook Interface পরিচিতি

## Main Parts

| Part          | কাজ                 |
| ------------- | ------------------- |
| Code Cell     | Python code run     |
| Text Cell     | Notes/documentation |
| Runtime       | Cloud machine       |
| Files Panel   | Dataset upload      |
| RAM/Disk Info | Resource usage      |

---

# Step 4: Code Run করা

একটি code cell এ লিখো:

```python
print("Hello Colab")
```

তারপর:

* Shift + Enter চাপো
  অথবা
* Run button চাপো

---

# Colab Runtime কী?

Runtime হলো Google এর cloud computer যেখানে তোমার code run হয়।

মানে:

* তোমার নিজের PC তে না
* Google server এ code execute হয়

---

# Runtime Connect হওয়া

Notebook open করলে উপরে:

```text
Connect
```

button থাকবে।

ওটাতে click করলে cloud machine connect হবে।

# Google Drive Connect

```python

drive.mount('/content/drive')
```

এতে Drive files access করতে পারবে।

# Important Runtime Concepts

# Free Version Limitations

| Problem         | Meaning                       |
| --------------- | ----------------------------- |
| Session timeout | কিছু সময় পরে disconnect       |
| GPU limit       | সবসময় GPU নাও পাওয়া যেতে পারে |
| RAM limit       | বড় model train কঠিন           |

---

# Session Disconnect হলে কী হয়?

Temporary files delete হতে পারে।

তাই:

* Drive এ save করো
* model checkpoint রাখো
