# Hugging Face Libraries Explained (বাংলায়)

Hugging Face ecosystem এ অনেক library আছে, কিন্তু সবচেয়ে গুরুত্বপূর্ণ ৩টি হলো:

1. **Transformers**
2. **Datasets**
3. **Hub**

এগুলো একসাথে ব্যবহার করে AI application তৈরি করা হয়।

---

# ১. Transformers Library

## Transformers কী?

[Hugging Face Transformers Documentation](https://huggingface.co/docs/transformers/index?utm_source=chatgpt.com)

Transformers হলো Hugging Face এর সবচেয়ে জনপ্রিয় Python library।

এটি ব্যবহার করে তুমি:

* NLP model
* Speech model
* Vision model

খুব সহজে ব্যবহার করতে পারো।

---

## Transformers কেন ব্যবহার হয়?

আগে AI model ব্যবহার করতে অনেক complex code লাগত।
Transformers library সেটাকে খুব সহজ করে দিয়েছে।

---

## কী কী করা যায়?

### NLP Tasks

* Translation
* Text Summarization
* Question Answering
* Sentiment Analysis
* Chatbot

### Speech Tasks

* Speech-to-Text
* Text-to-Speech

### Vision Tasks

* Image Classification
* Object Detection

---

# সবচেয়ে জনপ্রিয় feature → pipeline()

```python id="wglg7m"
from transformers import pipeline

classifier = pipeline("sentiment-analysis")

result = classifier("I love AI")
print(result)
```

এখানে:

* `pipeline()` automatically model download করে
* prediction দেয়

---

# pipeline কিভাবে কাজ করে?

ভেতরে:

1. Model load করে
2. Tokenizer load করে
3. Input process করে
4. Output দেয়

---

# আরেকটি Example — Translation

```python id="gnfx2m"
from transformers import pipeline

translator = pipeline("translation_en_to_fr")

translator("How are you?")
```

---

# Important Components

| Component | কাজ                     |
| --------- | ----------------------- |
| Model     | AI brain                |
| Tokenizer | Text split/encode       |
| Pipeline  | Easy interface          |
| Trainer   | Model training          |
| AutoModel | Automatic model loading |

# ২. Datasets Library

## Datasets কী?

[Hugging Face Datasets Documentation](https://huggingface.co/docs/datasets/index?utm_source=chatgpt.com)

এটি dataset load ও process করার library।

AI model train করার জন্য data লাগে।
Datasets library সহজে data manage করতে সাহায্য করে।

---

# কী করা যায়?

* Dataset download
* Dataset preprocessing
* Train/test split
* Streaming large datasets
* Audio/Image/Text dataset handling

---

# Example

```python id="e9q2mr"
from datasets import load_dataset

dataset = load_dataset("imdb")

print(dataset)
```

এখানে:

* IMDB movie review dataset download হচ্ছে

# ৩. Hugging Face Hub

## Hub কী?

[Hugging Face Hub](https://huggingface.co/models?utm_source=chatgpt.com)

Hub হলো online platform যেখানে:

* Models
* Datasets
* Spaces

store ও share করা হয়।

---

# GitHub এর মতো কিন্তু AI এর জন্য

যেমন GitHub এ code থাকে,
তেমনি Hugging Face Hub এ AI resources থাকে।

---

# Hub এ কী পাওয়া যায়?

## Models

হাজার হাজার pretrained models।

## Datasets

Public datasets।

## Spaces

Live AI demo apps।

---

# Example

তুমি চাইলে:

* নিজের trained model upload করতে পারো
* dataset publish করতে পারো
* AI app deploy করতে পারো

---
