# Introduction to Google Colab and Cloud GPUs for AI Development (বাংলায়)

## Google Colab কী?

[Google Colab Official Website](https://colab.research.google.com?utm_source=chatgpt.com)

Google Colab (Colaboratory) হলো Google এর একটি cloud-based Jupyter Notebook platform যেখানে browser দিয়েই Python code run করা যায়।

* Machine Learning
* Deep Learning
* Data Science
* AI Research

এর জন্য খুব জনপ্রিয়।

* GPU নাও থাকতে পারে

কিন্তু Google Colab এ:

* Google এর cloud computer ব্যবহার হয়
* Free GPU পাওয়া যায়
* Setup ছাড়াই coding করা যায়

# Colab কেন জনপ্রিয়?

### ১. Browser-based

### ২. Free GPU/TPU

Deep Learning training দ্রুত করা যায়।

### ৩. Jupyter Notebook Support

Notebook style এ code + markdown একসাথে লেখা যায়।

### ৪. Google Drive Integration

Notebook Drive এ save হয়।

### ৫. Easy Sharing

Link দিয়েই notebook share করা যায়।

# Free Colab Limitations

| Limitation         | Meaning                       |
| ------------------ | ----------------------------- |
| Session timeout    | কিছু সময় পর disconnect        |
| Limited GPU access | সবসময় GPU নাও পাওয়া যেতে পারে |
| RAM limit          | বড় model এ সমস্যা হতে পারে    |
