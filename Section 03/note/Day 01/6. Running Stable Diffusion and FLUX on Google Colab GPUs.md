# 5. Stable Diffusion Setup (Colab)

## Step 1: Install dependencies

```python
!pip install diffusers transformers accelerate torch
```

---

## Step 2: Hugging Face login (optional but recommended)

[Hugging Face](https://huggingface.co?utm_source=chatgpt.com)

```python
from huggingface_hub import login

login("YOUR_HF_TOKEN")
```

---

## Step 3: Load Stable Diffusion model

```python
from diffusers import StableDiffusionPipeline
import torch

model_id = "runwayml/stable-diffusion-v1-5"

pipe = StableDiffusionPipeline.from_pretrained(
    model_id,
    torch_dtype=torch.float16
).to("cuda")
```

---

## Step 4: Generate Image

```python
prompt = "a cyberpunk city at night, ultra detailed, 4k"

image = pipe(prompt).images[0]

image.show()
```

# 7. FLUX (Colab Setup)

## Step 1: Install libraries

```python
!pip install diffusers transformers accelerate safetensors torch
```

---

## Step 2: Load FLUX model

(Example pipeline structure)

```python
from diffusers import DiffusionPipeline
import torch

model_id = "black-forest-labs/FLUX.1-dev"

pipe = DiffusionPipeline.from_pretrained(
    model_id,
    torch_dtype=torch.float16
).to("cuda")
```

---

## Step 3: Generate image

```python
prompt = "a cinematic portrait of a robot in rain, ultra realistic"

image = pipe(prompt).images[0]

image.show()
```

# 8. Stable Diffusion vs FLUX

| Feature   | Stable Diffusion | FLUX             |
| --------- | ---------------- | ---------------- |
| Quality   | High             | Very High        |
| Speed     | Fast             | Medium           |
| Detail    | Good             | Excellent        |
| GPU usage | Lower            | Higher           |
| Use case  | General          | Pro-level images |

---

# 9. Important GPU Tips (Colab)

## A. VRAM issue fix

```python
pipe.enable_attention_slicing()
```

---

## B. Memory optimization

```python
pipe.enable_model_cpu_offload()
```

---

## C. Faster generation

Reduce steps:

```python
image = pipe(prompt, num_inference_steps=25).images[0]
```

# 14. Common Errors

## CUDA out of memory

Fix:

* lower image size
* reduce steps
* use smaller model
