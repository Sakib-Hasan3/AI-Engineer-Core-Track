# ৫) Audio Preprocessing

Meeting audio সাধারণত noisy হয়।
Preprocessing accuracy improve করে।

FFmpeg দিয়ে mono + 16kHz conversion:

```bash
ffmpeg -i meeting.mp3 -ac 1 -ar 16000 meeting_clean.wav
```

### কেন এটা দরকার?

| Parameter  | Reason                        |
| ---------- | ----------------------------- |
| mono audio | speech recognition simpler হয় |
| 16kHz      | speech-optimized sampling     |
| WAV        | lossless                      |

# ৬) Whisper দিয়ে transcription

Python script:

```python
import whisper

model = whisper.load_model("medium")

result = model.transcribe(
    "meeting_clean.wav",
    language="bn",
    task="transcribe",
    fp16=False
)

transcript = result["text"]

print(transcript)
```

# ৭) Timestamped transcript

Meeting minutes-এর জন্য timestamp useful।

```python
with open("timestamped_transcript.txt", "w", encoding="utf-8") as f:
    for seg in result["segments"]:
        start = seg["start"]
        end = seg["end"]
        text = seg["text"]

        line = f"[{start:.2f}-{end:.2f}] {text}\n"
        f.write(line)
```

Output example:

```text id="l7c5wm"
[0.00-4.21] সবাইকে স্বাগতম।
[4.21-9.55] আজকের মিটিংয়ের মূল উদ্দেশ্য...
```

# ৮) কেন transcript chunking দরকার?

Long meeting transcript অনেক বড় হয়।

Example:

```text id="78mjlwm"
2-hour meeting
≈ 25,000–40,000 words
```

একবারে পুরো transcript LLaMA-তে পাঠানো inefficient।

তাই chunk করতে হবে।

---

# ৯) Transcript chunking

```python
def chunk_text(text, chunk_size=3000):
    chunks = []

    for i in range(0, len(text), chunk_size):
        chunks.append(text[i:i+chunk_size])

    return chunks
```

Usage:

```python
chunks = chunk_text(transcript)
```

# ১০) LLaMA 3.2 API call (Ollama local)

```python
import requests

def summarize_chunk(chunk):

    prompt = f"""
তুমি একজন professional meeting secretary।

নিচের transcript থেকে বের করো:

1. মূল আলোচনা
2. সিদ্ধান্তসমূহ
3. Action items
4. Risks/issues
5. Deadlines

Transcript:
{chunk}
"""

    response = requests.post(
        "http://localhost:11434/api/generate",
        json={
            "model": "llama3.2:3b",
            "prompt": prompt,
            "stream": False
        }
    )

    return response.json()["response"]
```

# ১১) সব chunk summarize করা

summaries = []

combined_summary = "\n\n".join(summaries)

# ১২) Final Meeting Minutes generation

এখন combined summaries থেকে final polished minutes তৈরি করা হবে।

```python
final_prompt = f"""
নিচের meeting summaries থেকে একটি professional meeting minutes তৈরি করো।

Format:

- মিটিং শিরোনাম
- তারিখ
- উপস্থিত সদস্য

- Action Items Table
- Risks
- Next Steps

Summaries:
{combined_summary}
"""
```

API call:

```python
response = requests.post(
    "http://localhost:11434/api/generate",
    json={
        "model": "llama3.2:3b",
        "prompt": final_prompt,
        "stream": False
    }
)

minutes = response.json()["response"]

print(minutes)
```

# ১৬) Production Engineering Considerations

## Accuracy considerations

সবচেয়ে common failure points:

| Problem               | Impact             |
| --------------------- | ------------------ |
| overlapping speakers  | wrong transcript   |
| noisy audio           | missed words       |
| Bangla-English mixing | terminology errors |
| names/acronyms        | spelling mistakes  |
| poor microphones      | hallucinated words |

---

## Recommended Whisper model

| Model  | Use case         |
| ------ | ---------------- |
| small  | fast rough draft |
| medium | balanced         |
| large  | best accuracy    |

বাংলা corporate meeting-এর জন্য সাধারণত:

```text id="8r1r3g"
Whisper medium বা large
```

ভালো choice।
