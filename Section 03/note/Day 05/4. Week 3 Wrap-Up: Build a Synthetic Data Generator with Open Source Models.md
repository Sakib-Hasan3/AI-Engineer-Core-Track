# Open Source Models দিয়ে Synthetic Data Generator তৈরি

## 1) Target Architecture

```text
Seed data / schema / business rules
        ↓
Prompt template
        ↓
Open-source LLM
        ↓
Structured JSON output
        ↓
Validation
        ↓
Deduplication
        ↓
Quality scoring
        ↓
Synthetic dataset export
```

ভালো production design হলো: **LLM generate করবে, কিন্তু validator accept/reject করবে**।

---

## 2) Recommended Stack

| Layer             | Recommended Tool                  |
| ----------------- | --------------------------------- |
| Local LLM         | LLaMA 3.2, Mistral, Qwen, Gemma   |
| Runtime           | Ollama বা vLLM                    |
| Schema validation | Pydantic                          |
| Output format     | JSONL / CSV / Parquet             |
| Deduplication     | exact hash + embedding similarity |
| QA                | rule checks + model-based review  |

LLaMA 3.2-এর 1B/3B instruct models multilingual text generation এবং summarization-style tasks-এর জন্য তৈরি। ([Hugging Face][1]) Ollama structured outputs দিয়ে JSON schema enforce করা যায়, আর vLLM guided decoding-এ JSON schema, regex, grammar, choice ইত্যাদি constraint support করে। ([Ollama Docs][2])

## 5) Define Schema with Pydantic

```python
from pydantic import BaseModel, Field
from typing import Literal

class SyntheticSupportRecord(BaseModel):
    customer_message: str = Field(min_length=10)
    intent: Literal[
        "delivery_delay",
        "refund_request",
        "payment_issue",
        "product_question",
        "account_problem"
    ]
    urgency: Literal["low", "medium", "high"]
    language: Literal["bn", "en"]
    ideal_response: str = Field(min_length=20)
```

## 6) Prompt Template

```python
def build_prompt(intent: str, language: str = "bn"):
    return f"""
তুমি একটি synthetic customer-support dataset generator.

একটি realistic কিন্তু fabricated customer support example তৈরি করো।

Rules:
- কোনো real person, phone number, address, email ব্যবহার করবে না।
- Output strictly JSON হবে।
- Language: {language}
- Intent: {intent}
- Customer message realistic হবে।
- Ideal response polite, concise, support-agent style হবে।

JSON fields:
customer_message, intent, urgency, language, ideal_response
"""
```

## 7) Generate with Ollama

```python
import requests
import json

def generate_record(intent: str, language: str = "bn"):
    prompt = build_prompt(intent, language)

    response = requests.post(
        "http://localhost:11434/api/generate",
        json={
            "model": "llama3.2:3b",
            "prompt": prompt,
            "format": "json",
            "stream": False,
            "options": {
                "temperature": 0.8
            }
        },
        timeout=120
    )

    response.raise_for_status()
    raw = response.json()["response"]
    return json.loads(raw)
```

## 8) Validate Output

```python
from pydantic import ValidationError

def validate_record(raw_record):
    try:
        return SyntheticSupportRecord.model_validate(raw_record)
    except ValidationError as e:
        return None
```

Generation loop:

```python
intents = [
    "delivery_delay",
    "refund_request",
    "payment_issue",
    "product_question",
    "account_problem"
]

records = []

for intent in intents:
    for _ in range(100):
        raw = generate_record(intent, language="bn")
        valid = validate_record(raw)

        if valid:
            records.append(valid.model_dump())

print(len(records))
```

## 9) Deduplication

```python
import hashlib

def record_hash(record):
    key = record["customer_message"].strip().lower()
    return hashlib.sha256(key.encode("utf-8")).hexdigest()

seen = set()
deduped = []

for r in records:
    h = record_hash(r)
    if h not in seen:
        seen.add(h)
        deduped.append(r)

records = deduped
```

## 11) Quality Checks

Minimum checks রাখা উচিত:

```python
def quality_check(record):
    if len(record["customer_message"]) < 10:
        return False

    if len(record["ideal_response"]) < 20:
        return False

    banned_terms = ["017", "@gmail.com", "বাসা নম্বর", "NID"]
    if any(term in record["customer_message"] for term in banned_terms):
        return False

    return True

records = [r for r in records if quality_check(r)]
```

## 12) Better Production Pattern

```text
Generate 5 candidates
        ↓
Validate schema
        ↓
Apply business rules
        ↓
Check duplicate
        ↓
LLM judge quality
        ↓
Accept best 1–2 records
```

Structured output shape enforce করলেও semantic correctness নিশ্চিত হয় না; তাই validation, rule checks, and sampling review দরকার। ([Logic][3])

