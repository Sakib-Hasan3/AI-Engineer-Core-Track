## GPT মডেলে Token-by-Token Inference কী?

GPT মডেল একবারে পুরো উত্তর তৈরি করে না। এটি **একটি করে token predict করে**, তারপর সেই token-টি আগের context-এর শেষে যোগ করে আবার পরের token predict করে।

সহজভাবে:

```text
Prompt tokens
→ Transformer forward pass
→ next-token logits
→ probability distribution
→ একটি token নির্বাচন
→ token context-এ যোগ
→ repeat
```

---

## ১) মূল ধারণা

ধরা যাক prompt হলো:

```text
The transformer is
```

মডেল প্রথমে পরের token predict করে:

```text
The transformer is → " a"
```

তারপর নতুন context হয়:

```text
The transformer is a
```

এবার মডেল আবার পরের token predict করে:

```text
The transformer is a → " neural"
```

তারপর:

```text
The transformer is a neural → " network"
```

শেষে generated text দাঁড়ায়:

```text
The transformer is a neural network ...
```

Autoregressive GPT মডেলের probability factorization:

P(x_1,x_2,\ldots,x_n)=\prod_{t=1}^{n}P(x_t\mid x_{<t})

অর্থাৎ প্রতিটি token আগের সব token-এর ওপর নির্ভর করে।


মডেল raw text দেখে না; মডেল দেখে **token IDs**।

## ৪) Next-token probability

ধরা যাক context:

```text
GPT models predict text
```

মডেল vocabulary-এর সব possible token-এর জন্য score বা **logit** তৈরি করে। তারপর softmax দিয়ে probability পাওয়া যায়:

```text
Candidate next tokens:

"."          0.31
" by"        0.18
" using"     0.12
","          0.07
" one"       0.04
...
```

এরপর decoding strategy অনুযায়ী একটি token বাছাই করা হয়।

---

## ৫) Greedy decoding বনাম sampling

### Greedy decoding

সবচেয়ে বেশি probability যেটার, সেটাই নেওয়া হয়।

```text
"." probability = 0.31 → choose "."
```

সুবিধা: deterministic, stable
অসুবিধা: অনেক সময় bland বা repetitive output দেয়

---

### Sampling

Probability distribution থেকে random sample নেওয়া হয়।

```text
"."       0.31
" by"     0.18
" using"  0.12
","       0.07
```

এখানে highest probability token না-ও আসতে পারে। ফলে output বেশি diverse হয়।

---

## ৬) Temperature

Temperature probability distribution sharp বা flat করে।

```text
Low temperature  → safer, deterministic, focused
High temperature → diverse, creative, more random
```

Conceptually:

```text
temperature কম হলে:
high-probability tokens আরও dominant হয়

temperature বেশি হলে:
low-probability tokens-এর chance বাড়ে
```

Engineering view:

| Temperature | Behaviour                   |
| ----------: | --------------------------- |
| 0 বা near 0 | deterministic / greedy-like |
|     0.2–0.5 | factual, focused            |
|     0.7–1.0 | balanced creative           |
|        >1.0 | বেশি random, quality risk   |

---

## ৭) Top-k এবং Top-p

### Top-k

শুধু top `k` tokens রাখা হয়।

```text
top_k = 3

Keep:
"."       0.31
" by"     0.18
" using"  0.12

Discard বাকিগুলো
```

### Top-p / nucleus sampling

যতগুলো token মিলে cumulative probability `p` ছাড়ায়, শুধু সেগুলো রাখা হয়।

```text
top_p = 0.90

Keep tokens until cumulative probability ≥ 0.90
```

Top-p সাধারণত top-k থেকে বেশি adaptive, কারণ distribution sharp হলে কম token রাখে, flat হলে বেশি token রাখে।

## ৮) Generation-এ কেন last position গুরুত্বপূর্ণ?

Training-এর সময় model একসাথে অনেক position-এর next token predict করতে পারে।

কিন্তু inference/generation-এর সময় শুধু **শেষ token position** থেকে next-token distribution দরকার।

```text
Input:
["The", " transformer", " is"]

Model outputs:
position 1 → predicts after "The"
position 2 → predicts after "The transformer"
position 3 → predicts after "The transformer is"
```

Generation-এর জন্য ব্যবহার করা হয়:

```text
position 3 → next-token distribution
```

## ৯) Prefill এবং Decode phase

GPT inference সাধারণত দুই ভাগে দেখা হয়।

### Prefill phase

Prompt-এর সব token একসাথে process হয়।

```text
Prompt length = 2,000 tokens
Model processes all 2,000 tokens
Builds KV cache
Produces first next-token distribution
```

এটি compute-heavy, কিন্তু parallelizable।

---

### Decode phase

এরপর model একটি করে token generate করে।

```text
Generate token 1
Generate token 2
Generate token 3
...
```

এই phase sequential, কারণ token `t+1` generate করতে token `t` জানা দরকার।

---

## ১০) KV cache: inference efficient করার মূল কৌশল

Naive পদ্ধতিতে প্রতিবার নতুন token generate করার সময় পুরো context আবার process করতে হতো।

```text
Step 1: process 1000 tokens
Step 2: process 1001 tokens again
Step 3: process 1002 tokens again
```

এটা খুব ব্যয়বহুল।

তাই GPT inference-এ **KV cache** ব্যবহার করা হয়। Attention layer-এর previous **Key** এবং **Value** tensors cache করে রাখা হয়।

```text
Without KV cache:
প্রতি step-এ পুরো context recompute

With KV cache:
পুরনো key/value reuse
শুধু নতুন token-এর computation
```

ফলে streaming generation অনেক দ্রুত হয়।


## ১২) Simplified pseudocode

```python
tokens = tokenize(prompt)

for step in range(max_new_tokens):
    logits = model(tokens)          # forward pass
    next_logits = logits[-1]        # last position only
    probs = softmax(next_logits)

    next_token = sample(
        probs,
        temperature=0.7,
        top_p=0.9
    )

    tokens.append(next_token)

    if next_token == end_of_text_token:
        break

text = detokenize(tokens)
```

KV cache সহ conceptual version:

```python
tokens = tokenize(prompt)
kv_cache = None

# Prefill phase
logits, kv_cache = model(tokens, kv_cache=None)

for step in range(max_new_tokens):
    next_logits = logits[-1]
    next_token = sample(next_logits)

    # Decode phase: only the new token is passed
    logits, kv_cache = model([next_token], kv_cache=kv_cache)

    if next_token == eos_token:
        break
```

## ১৩) ছোট educational simulation

এটি real GPT নয়, কিন্তু token-by-token ধারণা বোঝায়।

```python
import random

vocab_probs = {
    "The transformer is": {
        " a": 0.45,
        " not": 0.10,
        " used": 0.15,
        " based": 0.30,
    },
    "The transformer is a": {
        " neural": 0.70,
        " model": 0.20,
        " system": 0.10,
    },
    "The transformer is a neural": {
        " network": 0.85,
        " architecture": 0.15,
    },
}

def sample_next(context):
    options = vocab_probs.get(context, {".": 1.0})
    tokens = list(options.keys())
    probs = list(options.values())
    return random.choices(tokens, weights=probs, k=1)[0]

text = "The transformer is"

for _ in range(5):
    next_token = sample_next(text)
    text += next_token
    print(text)
```

Possible output:

```text
The transformer is a
The transformer is a neural
The transformer is a neural network
The transformer is a neural network.
```

## ১৪) Practical inference engineering view

Production inference-এ key constraints:

| Factor                    | Practical effect                                  |
| ------------------------- | ------------------------------------------------- |
| Context length            | বড় context হলে attention memory ও KV cache বাড়ে   |
| Model size                | parameter বেশি হলে compute বেশি লাগে              |
| Batch size                | throughput বাড়াতে পারে, latency বাড়াতে পারে       |
| KV cache size             | long generation-এ memory bottleneck হতে পারে      |
| Precision                 | FP16/BF16/INT8/INT4 speed-memory-quality tradeoff |
| Decoding strategy         | quality ও randomness control করে                  |
| Hardware memory bandwidth | decode phase-এ বড় bottleneck হতে পারে             |

Important metrics:

```text
Time to first token = prefill latency
Tokens per second   = decode throughput
End-to-end latency  = prefill + decode time
```
