# Introduction to Hugging Face Pipelines for Quick AI Inference (বাংলায়)

## Pipeline কী?

[Hugging Face Transformers Pipelines](https://huggingface.co/docs/transformers/main/en/main_classes/pipelines?utm_source=chatgpt.com)

**Pipeline** হলো Hugging Face এর সবচেয়ে সহজ interface, যেটা দিয়ে মাত্র ১–৩ লাইনের কোডে AI model ব্যবহার করা যায়।

👉 সহজভাবে:

> Pipeline = “Ready-made AI system in one line”

---

# Pipeline কেন দরকার?

আগে AI model ব্যবহার করতে লাগতো:

* Model load
* Tokenizer load
* Preprocessing
* Postprocessing
* GPU setup

👉 Pipeline এই সব একসাথে করে দেয়।

---

# Pipeline কীভাবে কাজ করে?

```text id="p1"
Input Text/Image/Audio
        ↓
Preprocessing (auto)
        ↓
Model Inference
        ↓
Postprocessing (auto)
        ↓
Output Result
```

---

# Basic Syntax

```python id="p2"
from transformers import pipeline

task = pipeline("task-name")
result = task("input data")
print(result)
```

---

# জনপ্রিয় Pipeline Tasks

## 1. Sentiment Analysis

```python id="p3"
from transformers import pipeline

classifier = pipeline("sentiment-analysis")

result = classifier("I love Bangladesh")
print(result)
```

👉 Output:

* POSITIVE / NEGATIVE

---

## 2. Text Generation

```python id="p4"
generator = pipeline("text-generation")

print(generator("Artificial Intelligence is"))
```

👉 AI নিজে text লিখে দিবে

---

## 3. Translation

```python id="p5"
translator = pipeline("translation_en_to_fr")

print(translator("How are you?"))
```

---

## 4. Question Answering

```python id="p6"
qa = pipeline("question-answering")

result = qa({
    "question": "What is AI?",
    "context": "AI is a field of computer science."
})

print(result)
```

---

## 5. Summarization

```python id="p7"
summarizer = pipeline("summarization")

text = """
Hugging Face is a platform for machine learning models,
datasets, and AI applications.
"""

print(summarizer(text))
```

---

## 6. Image Classification

```python id="p8"
image_classifier = pipeline("image-classification")

image_classifier("image.jpg")
```

---

## 7. Speech-to-Text

```python id="p9"
asr = pipeline("automatic-speech-recognition")

asr("audio.wav")
```

# Colab Example (Full Workflow)

```python id="p12"
from transformers import pipeline

# Load model
classifier = pipeline("sentiment-analysis")

# Run inference
text = "This AI course is amazing"
result = classifier(text)

print(result)
```
