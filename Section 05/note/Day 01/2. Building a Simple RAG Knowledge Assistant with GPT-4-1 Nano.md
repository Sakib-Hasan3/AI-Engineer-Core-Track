## Building a Simple RAG Knowledge Assistant with GPT-4.1 Nano 

এখানে তুমি শিখবে কীভাবে খুব সহজভাবে একটি **RAG (Retrieval Augmented Generation) Knowledge Assistant** বানানো যায়, যেখানে ব্যবহার করা হবে একটি ছোট ও দ্রুত LLM যেমন **GPT-4.1 nano** (বা অনুরূপ lightweight model API)।

---

# 🧠 Project Idea

তোমার assistant হবে এমন:

* তুমি প্রশ্ন করবে
* সিস্টেম তোমার নিজের ডকুমেন্ট/ফাইল থেকে তথ্য খুঁজে আনবে
* তারপর সেই তথ্য ব্যবহার করে GPT উত্তর দেবে

# 📁 Step 1: Data Prepare করা

ধরো তোমার কাছে একটা file আছে:

```txt
college_rules.txt
ai_notes.txt
project_guide.txt
```

এগুলোকে ছোট ছোট chunk এ ভাগ করতে হবে।

```python
def split_text(text, chunk_size=200):
    words = text.split()
    chunks = []

    for i in range(0, len(words), chunk_size):
        chunks.append(" ".join(words[i:i+chunk_size]))

    return chunks
```

---

# 🧬 Step 2: Embedding তৈরি করা

আমরা text কে vector এ convert করবো।

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')

def get_embedding(text):
    return model.encode(text)
```

---

# 📦 Step 3: Vector Database (FAISS)

```python
import faiss
import numpy as np

dimension = 384
index = faiss.IndexFlatL2(dimension)

documents = []
vectors = []
```

Add data:

```python
def add_documents(chunks):
    global documents, vectors

    for chunk in chunks:
        vector = get_embedding(chunk)
        vectors.append(vector)
        documents.append(chunk)

    index.add(np.array(vectors))
```

---

# 🔍 Step 4: Retrieval System

User query থেকে similar document খুঁজে বের করা:

```python
def search(query, k=3):
    query_vector = get_embedding(query).reshape(1, -1)

    distances, indices = index.search(query_vector, k)

    results = []
    for i in indices[0]:
        results.append(documents[i])

    return results
```

---

# 🤖 Step 5: GPT-4.1 Nano দিয়ে Answer Generation

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_API_KEY")

def generate_answer(query, context):
    prompt = f"""
    তুমি একজন AI assistant।

    নিচের তথ্য ব্যবহার করে প্রশ্নের উত্তর দাও:

    Context:
    {context}

    Question:
    {query}
    """

    response = client.chat.completions.create(
        model="gpt-4.1-nano",
        messages=[{"role": "user", "content": prompt}]
    )

    return response.choices[0].message.content
```

---

# 🔗 Step 6: Full RAG Pipeline

```python
def rag_pipeline(query):
    docs = search(query)
    context = "\n".join(docs)

    answer = generate_answer(query, context)
    return answer
```

# 💬 Example Run
