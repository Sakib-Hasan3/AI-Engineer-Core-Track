## Building a Simple RAG System: Dictionary Lookup & Context Retrieval 
এখানে তুমি শিখবে কীভাবে খুবই **simple RAG system** বানানো যায় যেখানে:

* আমরা কোনো বড় AI model ছাড়াই শুরু করবো
* আগে **dictionary lookup**
* তারপর **context retrieval (mini RAG)**

এটা RAG বোঝার সবচেয়ে ভালো foundation।

---

# 🧠 1. Basic Idea

Simple RAG =

> প্রশ্ন → তথ্য খোঁজা (retrieval) → উত্তর তৈরি (generation)

এখানে আমরা দুইটা ধাপে দেখবো:

### 🔹 Level 1: Dictionary Lookup (সবচেয়ে সহজ)

### 🔹 Level 2: Context Retrieval (mini RAG)

---

# 📘 LEVEL 1: Dictionary Lookup System

## 🎯 কী হবে?

আমরা একটা simple dictionary বানাবো:

```python id="d1"
knowledge_base = {
    "rag": "RAG মানে Retrieval Augmented Generation, যেখানে AI বাইরের ডেটা ব্যবহার করে উত্তর দেয়।",
    "ai": "AI বা Artificial Intelligence হলো মেশিনকে মানুষের মতো বুদ্ধিমান করা।",
    "chatbot": "Chatbot হলো এমন সফটওয়্যার যা মানুষের সাথে কথা বলতে পারে।"
}
```

---

## 🔍 Lookup Function

```python id="d2"
def dictionary_lookup(query):
    query = query.lower()

    for key in knowledge_base:
        if key in query:
            return knowledge_base[key]

    return "দুঃখিত, আমি এই তথ্য খুঁজে পাইনি।"
```

---

## 💬 Example

```python id="d3"
print(dictionary_lookup("What is AI?"))
```

Output:

> AI বা Artificial Intelligence হলো মেশিনকে মানুষের মতো বুদ্ধিমান করা।

# 🧠 LEVEL 2: Simple Context Retrieval (Mini RAG)

এখানে আমরা:

* documents split করবো
* similarity based search করবো

---

# 📁 Step 1: Dataset (Mini Knowledge Base)

```python id="r1"
documents = [
    "RAG হলো এমন একটি system যেখানে AI বাইরের তথ্য ব্যবহার করে উত্তর দেয়।",
    "AI chatbot NLP ব্যবহার করে মানুষের প্রশ্ন বুঝে।",
    "Machine learning ডেটা থেকে pattern শিখে সিদ্ধান্ত নেয়।",
    "Python একটি জনপ্রিয় programming language।"
]
```

---

# 🧬 Step 2: Simple Keyword Matching (No ML)

```python id="r2"
def retrieve_context(query):
    query = query.lower()
    results = []

    for doc in documents:
        if any(word in doc.lower() for word in query.split()):
            results.append(doc)

    return results
```

---

## 💬 Example

```python id="r3"
print(retrieve_context("AI chatbot"))
```

Output:

```text
AI chatbot NLP ব্যবহার করে মানুষের প্রশ্ন বুঝে।
RAG হলো এমন একটি system যেখানে AI বাইরের তথ্য ব্যবহার করে উত্তর দেয়।
```

---

# 🤖 Step 3: Generate Answer (Simple RAG Style)

এখন আমরা context ব্যবহার করে উত্তর বানাবো:

```python id="r4"
def generate_answer(query):
    context = retrieve_context(query)

    if not context:
        return "কোনো তথ্য পাওয়া যায়নি।"

    answer = "Context ভিত্তিক উত্তর:\n\n"
    for c in context:
        answer += "- " + c + "\n"

    return answer
```

---

## 💬 Final Output

```python id="r5"
print(generate_answer("AI chatbot কী?"))
```

Output:

```
Context ভিত্তিক উত্তর:

- AI chatbot NLP ব্যবহার করে মানুষের প্রশ্ন বুঝে।
```
