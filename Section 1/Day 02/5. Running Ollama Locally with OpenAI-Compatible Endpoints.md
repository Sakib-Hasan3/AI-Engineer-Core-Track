
## ১. ধাপ ১: Ollama সার্ভার চালু করা এবং মডেল ডাউনলোড করা

প্রথমে, নিশ্চিত করুন আপনার মেশিনে Ollama ইন্সটল করা আছে এবং ব্যাকগ্রাউন্ডে সার্ভার রান করছে।

1.  **Ollama চালু করুন**: সাধারণত `ollama serve` কমান্ড দিয়ে এটি চালু রাখতে হয়। তবে অনেক সময় এটি ইনস্টলের পর থেকেই ব্যাকগ্রাউন্ড সার্ভিস হিসেবে চলে।
2.  **একটি মডেল ডাউনলোড করুন**: টার্মিনালে নিচের কমান্ড দিন। এটি আপনার পছন্দের যেকোনো মডেল হতে পারে (যেমন `llama3.2`, `mistral`, `phi3`)।

    ```bash
    ollama run llama3.2
    ```
    প্রথমবার এই কমান্ড দিলে মডেলটি ডাউনলোড হবে, তারপর সরাসরি চ্যাট শুরু হয়ে যাবে। আপনি `Ctrl+D` বা `/bye` দিয়ে চ্যাট থেকে বের হয়ে আসতে পারেন। সার্ভারটি ব্যাকগ্রাউন্ডে চালু থাকবে।

## ২. ধাপ ২: OpenAI Python ক্লায়েন্ট কনফিগার করা

এখন ম্যাজিকের অংশ। আপনি OpenAI লাইব্রেরি ব্যবহার করবেন, কিন্তু এন্ডপয়েন্ট হিসেবে Ollama-র লোকাল সার্ভারকে চিহ্নিত করবেন।

Ollama-র OpenAI-কম্প্যাটিবল এন্ডপয়েন্ট সাধারণত এই ঠিকানায় চলে: **`http://localhost:11434/v1`** 

নিচের উদাহরণটি দেখুন:

```python
from openai import OpenAI

# এটি গুরুত্বপূর্ণ অংশ: আমরা এখানে লোকাল Ollama সার্ভারকে 'বলছি'
client = OpenAI(
    base_url="http://localhost:11434/v1",  # লোকাল এন্ডপয়েন্ট
    api_key="dummy"  # Ollama API key চায় না, কিন্তু প্যারামিটারটি খালি রাখা যায় না। যেকোনো স্ট্রিং দেওয়া যায়। 
)

# একদম OpenAI-র মতো করেই কল করুন
response = client.chat.completions.create(
    model="llama3.2",  # আপনি যেই মডেল ডাউনলোড করেছেন তার নাম
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain what an API is in one sentence."}
    ],
    temperature=0.7,
)

print(response.choices[0].message.content)
```
**কোডটি ব্যাখ্যা:**
*   **`base_url`**: আমরা OpenAI-র ডিফল্ট URL-এর জায়গায় Ollama-র লোকাল URL বসিয়েছি। 
*   **`api_key`**: OpenAI-র মত করে অথেনটিকেশন বাধ্যতামূলক। যেহেতু Ollama এটা চেক করে না, আমরা `"dummy"` বা খালি স্ট্রিং দিয়ে দিতে পারি। 
*   **`model`**: আপনার লোকাল মেশিনে `ollama list` কমান্ড দিয়ে যেই মডেলগুলোর নাম দেখবেন, সেগুলোই এখানে ব্যবহার করতে পারবেন।

## ৩. অ্যাডভান্সড কৌশল: প্রোক্সি সার্ভার ব্যবহার

মাঝে মাঝে আপনার হাতে পুরোনো কোনো কোড থাকতে পারে যা সরাসরি OpenAI-র জন্য লেখা এবং তার URL বা ক্লায়েন্ট সেটআপ পরিবর্তন করার সুযোগ নেই। অথবা, আপনি চাইছেন একই পোর্টে (`11434`) **Ollama-র নেটিভ API** এবং **OpenAI-কম্প্যাটিবল API** দুটোই যেন একসাথে চলে। 

সেক্ষেত্রে আপনি একটি **প্রোক্সি সার্ভার** ব্যবহার করতে পারেন। এটি একটি মধ্যস্থতাকারী প্রোগ্রাম যা আপনার লোকাল কম্পিউটারে বসে, একটি নির্দিষ্ট পোর্ট শুনতে থাকে, এবং রিকোয়েস্টগুলোর ফরম্যাট দেখে সেগুলো সঠিক জায়গায় ফরোয়ার্ড করে দেয়।

### কেন প্রোক্সি ব্যবহার করবেন?

*   **কোড পরিবর্তনের ঝামেলা এড়ানো:** আপনার অ্যাপ্লিকেশন (যেমন n8n, কিছু GUI টুল) হয়তো `localhost:11434`-এ কল করতেই অভ্যস্ত। প্রোক্সি সেই একই ঠিকানায় বসে, কিন্তু আপনার পছন্দের যেকোনো OpenAI-কম্প্যাটিবল সার্ভার (যেমন OpenAI, Groq, Together AI, লোকাল vLLM) এর সাথে কথা বলতে পারে। 
*   **একাধিক ব্যাকএন্ড ম্যানেজমেন্ট:** একটি প্রোক্সি কনফিগার করে আপনি সিদ্ধান্ত নিতে পারেন কোন মডেলের রিকোয়েস্ট কোন সার্ভারে যাবে।

### `ollama-openai-proxy` ব্যবহার করে দেখুন (উদাহরণ)

`ollama-openai-proxy` একটি পাইথন লাইব্রেরি যা এই কাজটি খুব সহজে করে দেয়। 

1.  **ইনস্টল করুন:**
    ```bash
    pip install ollama-openai-proxy
    ```
2.  **একটি `.env` ফাইল তৈরি করুন:** এখানে আপনি বলবেন আপনার আসল এন্ডপয়েন্ট কোথায়। উদাহরণস্বরূপ, আপনি যদি OpenAI ব্যবহার করতে চান:
    ```bash
    OPENAI_API_BASE_URL=https://api.openai.com/v1
    OPENAI_API_KEY=sk-your-actual-key
    ```
3.  **প্রোক্সি চালু করুন:**
    ```bash
    ollama-openai-proxy
    ```
4.  **আপনার পুরোনো কোডটি `localhost:11434`-এ কল করতে থাকবে**, এবং প্রোক্সি সেটা ধরে নিয়ে OpenAI-তে ফরোয়ার্ড করে দেবে। 

আপনি চাইলে **`ovai`**  বা **`ollama-proxy`**  এর মত আরও টুলস এক্সপ্লোর করতে পারেন, কিন্তু শুরুতে `ollama-openai-proxy` সবচেয়ে সহজ এবং সরল।
