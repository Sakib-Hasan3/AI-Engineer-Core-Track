## ১. এলএলএম আর্কিটেকচারের মূল বিল্ডিং ব্লক

যেকোনো জেনএআই সিস্টেম তৈরির জন্য সাতটি মূল কম্পোনেন্ট প্রয়োজন:

### 1.1 অ্যাপ্লিকেশন ইন্টারফেস (Application Interface)
- **কাজ:** ইউজার এবং এআই-এর মধ্যে সংযোগ স্থাপন করে
- **উদাহরণ:** ওয়েব চ্যাট, REST API, মোবাইল অ্যাপ
- **আপনার প্রোজেক্টে:** Streamlit বা Gradio দিয়ে UI বানাবেন

### 1.2 অ্যাপ্লিকেশন ইঞ্জিন (Application Engine)
- **কাজ:** সিস্টেমের আচরণ ও ওয়ার্কফ্লো পরিচালনা করে
- **উদাহরণ:** ল্যাংচেইন, ল্যামা ইনডেক্স
- **আপনার প্রোজেক্টে:** LangChain দিয়ে মাল্টি-স্টেপ ওয়ার্কফ্লো তৈরি করবেন

### 1.3 মেমরি সিস্টেম (Memory System)
- **কাজ:** কথোপকথনের ইতিহাস ও কনটেক্সট সংরক্ষণ করে
- **প্রকারভেদ:** 
  - **শর্ট-টার্ম মেমরি:** বর্তমান সেশনের ডাটা
  - **লং-টার্ম মেমরি:** ডাটাবেসে সেভ করা ইতিহাস
- **আপনার প্রোজেক্টে:** ConversationBufferMemory ব্যবহার করবেন

### 1.4 এলএলএম গেটওয়ে (LLM Gateway)
- **কাজ:** একাধিক মডেল প্রোভাইডার পরিচালনা ও মনিটর করে
- **উদাহরণ:** LiteLLM (১০০+ মডেল প্রোভাইডার সাপোর্ট)
- **আপনার প্রোজেক্টে:** LiteLLM দিয়ে OpenAI, Anthropic, লোকাল মডেল সুইচ করবেন

### 1.5 নলেজ স্টোর (Knowledge Store)
- **কাজ:** মডেলের ট্রেনিং ডাটার বাইরের তথ্য সংরক্ষণ করে
- **উদাহরণ:** ভেক্টর ডাটাবেস (Pinecone, Milvus, Chroma)
- **আপনার প্রোজেক্টে:** RAG-এর জন্য Chroma ব্যবহার করবেন

### 1.6 টুল গেটওয়ে (Tool Gateway)
- **কাজ:** এআইকে বাস্তব জগতে অ্যাকশন নেওয়ার ক্ষমতা দেয়
- **উদাহরণ:** API কল, ডাটাবেস কোয়েরি, ইমেইল সেন্ড
- **আপনার প্রোজেক্টে:** Function Calling দিয়ে ক্যালকুলেটর, ওয়েদার API কল করবেন

### 1.7 অ্যাপ্লিকেশন অবজার্ভেবিলিটি (Application Observability)
- **কাজ:** অপারেশনাল ভিসিবিলিটি ও কন্টিনিউয়াস ইমপ্রুভমেন্ট নিশ্চিত করে
- **উদাহরণ:** LangSmith, Opik, Ragas
- **আপনার প্রোজেক্টে:** LangSmith দিয়ে এলএলএম কল ট্র্যাক করবেন

## ২. এলএলএম মডেলের মূল কনসেপ্ট

### 2.1 টোকেন (Token)
টোকেন হলো টেক্সটের ক্ষুদ্রতম একক যা মডেল প্রক্রিয়া করে। মডেল অক্ষর বা শব্দ বোঝে না, এটি শুধু সংখ্যা বোঝে—টোকেন হলো সেই টেক্সটের ছোট ছোট টুকরা।

```python
# একটি বাক্যে কত টোকেন আছে?
# "আমি এলএলএম শিখছি" → ৫-৬ টোকেন (মডেল অনুযায়ী পরিবর্তনশীল)
```

**আপনার জানা দরকার:**
- ১ টোকেন ≈ ০.৭৫ ইংরেজি শব্দ
- ১ টোকেন ≈ ০.৫ বাংলা অক্ষর
- GPT-4-এর কনটেক্সট উইন্ডো: ১২৮,০০০ টোকেন

### 2.2 প্যারামিটার (Parameter)
প্যারামিটার হলো নিউরাল নেটওয়ার্কের "ওয়েট" বা "সংযোগের শক্তি"। মডেল যত বড়, প্যারামিটার তত বেশি:

| মডেল | প্যারামিটার | VRAM প্রয়োজন (FP16) | ব্যবহার |
|-------|-------------|---------------------|---------|
| Phi-3-mini | ৩.৮ বিলিয়ন | ~৮ জিবি | দ্রুত, লোকাল ডিভাইসে |
| Llama 3.2 | ৭ বিলিয়ন | ~১৪ জিবি | ব্যালেন্সড |
| Llama 3 | ৭০ বিলিয়ন | ~১৪০ জিবি | ডাটা সেন্টারে |

### 2.3 ট্রান্সফরমার আর্কিটেকচার
ট্রান্সফরমার হলো এলএলএম-এর "হার্ট"। এটি RNN-এর সমস্যা (স্বল্পমেয়াদী মেমরি) সমাধান করেছে।

**কীভাবে কাজ করে:**
1. **এনকোডার:** ইনপুট টেক্সট প্রক্রিয়া করে
2. **ডিকোডার:** আউটপুট জেনারেট করে
3. **অ্যাটেনশন মেকানিজম:** কোন শব্দের দিকে "মনোযোগ" দিতে হবে তা নির্ধারণ করে

### 2.4 কনটেক্সট উইন্ডো (Context Window)
মডেল এক সেশনে যতটুকু টেক্সট "মনে রাখতে" পারে।

```
কনটেক্সট উইন্ডোর সীমাবদ্ধতা:
┌────────────────────────────────────────┐
│ [প্রথম অংশ] [মাঝের অংশ] [শেষের অংশ]     │
│ ←───────── ১২৮,০০০ টোকেন ─────────→   │
└────────────────────────────────────────┘
যখন পূর্ণ হয়ে যায়, পুরনো ডাটা "ফেলে দেওয়া" হয়
```

**সমস্যা ও সমাধান:**
- **সমস্যা:** দীর্ঘ কথোপকথনে আগের অংশ ভুলে যায়
- **সমাধান:** RAG বা মেমরি ম্যানেজমেন্ট সিস্টেম ব্যবহার

## ৩. এলএলএম ট্রেনিং ও ফাইন-টিউনিং টেকনিক

### 3.1 প্রি-ট্রেনিং (Pre-training)
প্রথম ধাপে মডেলকে ইন্টারনেটের বিশাল ডাটা থেকে ভাষার প্যাটার্ন শেখানো হয়। এটি সবচেয়ে খরচবহুল ধাপ।

**ইনপুট:** টেরাবাইট পরিমাণ টেক্সট
**আউটপুট:** বেস মডেল (যে শুধু "টেক্সট কমপ্লিশন" জানে)

### 3.2 সাপারভাইজড ফাইন-টিউনিং (SFT - Supervised Fine-Tuning)
বেস মডেলকে "ইন্সট্রাকশন" ফরম্যাটে শেখানো হয়। "প্রশ্ন-উত্তর" পেয়ারে ট্রেনিং দেওয়া হয়।

```python
# SFT ডাটা ফরম্যাটের উদাহরণ
{
    "instruction": "বাংলায় 'Hello' কী বলে?",
    "response": "'Hello'-এর বাংলা হলো 'হ্যালো' বা 'নমস্কার'।"
}
```

### 3.3 RLHF (Reinforcement Learning from Human Feedback)
মানুষের ফিডব্যাক দিয়ে মডেলকে "ভালো" উত্তর দিতে শেখানো হয়。

**ধাপসমূহ:**
1. মডেল একই প্রশ্নের একাধিক উত্তর জেনারেট করে
2. মানুষ উত্তরগুলোর মান অনুযায়ী র‍্যাংক দেয়
3. এই ডাটা দিয়ে একটি "রিওয়ার্ড মডেল" ট্রেন করা হয়
4. রিওয়ার্ড মডেল মূল মডেলকে গাইড করে

### 3.4 LoRA (Low-Rank Adaptation)
মডেলের সব প্যারামিটার পরিবর্তন না করে শুধু ছোট "অ্যাডাপ্টার" যোগ করা হয়। এটি খুবই কম খরচে মডেল কাস্টমাইজ করার কৌশল।

```
পূর্ণ ফাইন-টিউনিং:     LoRA ফাইন-টিউনিং:
┌─────────────┐         ┌─────────────┐
│█████████████│         │█████████████│ ← মূল মডেল (ফ্রোজেন)
│█████████████│         │█████████████│
│█████████████│         │▓▓▓▓░░░░░░░░░│ ← LoRA (ট্রেনেবল)
└─────────────┘         └─────────────┘
৭০B প্যারামিটার ট্রেন    ~৮M প্যারামিটার ট্রেন
```

**LoRA-র সুবিধা:**
- ১০০ গুণ কম মেমরি লাগে
- একটি বেস মডেলে একাধিক LoRA অ্যাডাপ্টার রাখা যায়
- ট্রেনিং সময় অনেক কম

### 3.5 DPO (Direct Preference Optimization)
RLHF-এর উন্নত ভার্সন। জটিল রিওয়ার্ড মডেলের প্রয়োজন হয় না।

**RLHF vs DPO:**
- **RLHF:** রিওয়ার্ড মডেল ট্রেন → পলিসি ট্রেন (২ স্টেপ)
- **DPO:** সরাসরি প্রেফারেন্স ডাটা থেকে পলিসি ট্রেন (১ স্টেপ)

## ৪. এলএলএম ডেপ্লয়মেন্ট অপটিমাইজেশন

### 4.1 কোয়ান্টাইজেশন (Quantization)
মডেলের সংখ্যার যথার্থতা কমানো। FP16 (উচ্চ যথার্থতা) থেকে INT8 বা INT4-এ রূপান্তর।

| ফরম্যাট | বিট | সাইজ রিডাকশন | যথার্থতা ক্ষতি |
|---------|-----|--------------|---------------|
| FP16 | ১৬ বিট | ০% (বেসলাইন) | - |
| INT8 | ৮ বিট | ~৫০% | নগণ্য |
| INT4 | ৪ বিট | ~৭৫% | সামান্য |
| INT2 | ২ বিট | ~৮৭% | লক্ষণীয় |

### 4.2 জনপ্রিয় কোয়ান্টাইজেশন ফরম্যাট

| ফরম্যাট | বিশেষত্ব | ব্যবহার |
|---------|----------|---------|
| **GGUF** | CPU-তে চালানোর জন্য অপটিমাইজড | llama.cpp, Ollama |
| **GPTQ** | GPU-র জন্য, ভালো যথার্থতা | vLLM, ExLlama |
| **AWQ** | GPU-র জন্য, দ্রুত ইনফারেন্স | আধুনিক NVIDIA GPU |
| **QLoRA** | ৪-বিট বেস মডেল + LoRA ট্রেনিং | লো-মেমরি ফাইন-টিউনিং |

### 4.3 vLLM ও PagedAttention
একাধিক ইউজার একসাথে মডেল ব্যবহার করলে VRAM ম্যানেজমেন্ট সমস্যা হয়। vLLM-এর PagedAttention এই সমস্যা সমাধান করে।

```
ঐতিহ্যবাহী পদ্ধতি:        PagedAttention:
┌───┬───┬───┬───┐         ┌───┬───┬───┬───┐
│KV1│KV1│KV2│KV2│         │KV1│KV3│KV2│KV1│ (নন-কন্টিগুয়াস)
└───┴───┴───┴───┘         └───┴───┴───┴───┘
(কন্টিগুয়াস মেমরি)       (পেজড মেমরি, OS-এর মতো)
```

**ফলাফল:** vLLM ২৪ গুণ বেশি থ্রুপুট দিতে পারে।

## ৫. এলএলএম অ্যাপ্লিকেশন টুলস ও ফ্রেমওয়ার্ক

### 5.1 ল্যাংচেইন (LangChain)
বর্তমানে সবচেয়ে জনপ্রিয় এলএলএম অ্যাপ্লিকেশন ফ্রেমওয়ার্ক।

**ক্ষমতা:**
- চেইন: একাধিক এলএলএম কল সিকোয়েন্সিয়ালি চালানো
- RAG: ভেক্টর ডাটাবেস কানেক্ট করা
- এজেন্ট: টুলসহ LLM ব্যবহার
- মেমরি: কথোপকথন ইতিহাস রাখা

**সুবিধা:** সর্বাধিক ডকুমেন্টেশন, ১০০+ ইন্টিগ্রেশন
**অসুবিধা:** কিছুটা জটিল, "ব্লোটেড" মনে হতে পারে

### 5.2 ল্যামা ইনডেক্স (LlamaIndex)
RAG এবং ডাটা সংযোগের জন্য বিশেষায়িত ফ্রেমওয়ার্ক।

**ক্ষমতা:**
- ডাটা কানেক্টর: ১০০+ ডাটা সোর্স
- ইনডেক্সিং: বিভিন্ন ইনডেক্স স্ট্রাকচার
- কোয়েরি ইঞ্জিন: জটিল কোয়েরি প্রসেসিং

**সুবিধা:** RAG-এর জন্য সবচেয়ে ভালো
**অসুবিধা:** এজেন্ট বিল্ডিং ল্যাংচেইনের চেয়ে কম ফিচার

### 5.3 DSPy
"প্রম্পটিং না করে প্রোগ্রামিং" করার ফ্রেমওয়ার্ক। মডেল থেকে স্বয়ংক্রিয়ভাবে ভালো প্রম্পট শিখে নেয়।

### 5.4 LiteLLM
১০০+ মডেল প্রোভাইডারকে একই OpenAI API ফরম্যাটে কল করার গেটওয়ে।

```python
# LiteLLM-এর ম্যাজিক: একই কোডে মডেল সুইচ করুন
response = completion(
    model="openai/gpt-4o",  # OpenAI
    messages=[{"role": "user", "content": "হ্যালো"}]
)

response = completion(
    model="anthropic/claude-3",  # Anthropic
    messages=[{"role": "user", "content": "হ্যালো"}]
)

response = completion(
    model="ollama/llama3.2",  # লোকাল মডেল
    messages=[{"role": "user", "content": "হ্যালো"}]
)
```

### 5.5 Ollama ও llama.cpp

## ৭. হ্যান্ডস-অন: LangChain দিয়ে প্রথম এলএলএম চেইন তৈরি

এখন আমরা LangChain ব্যবহার করে একটি সিম্পল চেইন তৈরি করব:

### 7.1 ইনস্টলেশন
```bash
pip install langchain langchain-openai
```

### 7.2 বেসিক চেইন
```python
from langchain_openai import ChatOpenAI
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser

# ১. মডেল তৈরি
llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0.7)

# ২. প্রম্পট টেমপ্লেট
prompt = ChatPromptTemplate.from_messages([
    ("system", "তুমি একজন বাংলা সাহিত্যিক। তুমি খুব সুন্দর বাংলায় উত্তর দাও।"),
    ("user", "{input}")
])

# ৩. আউটপুট পার্সার
output_parser = StrOutputParser()

# ৪. চেইন তৈরি (Pipe অপারেটর ব্যবহার করে)
chain = prompt | llm | output_parser

# ৫. চেইন রান
result = chain.invoke({"input": "বাংলা সাহিত্যের একটি বিখ্যাত উক্তি বলো।"})
print(result)
```
