
## ১. কেন মাল্টিপল প্রোভাইডার ব্যবহার করবেন?

একাধিক এলএলএম প্রোভাইডার ব্যবহার করার কিছু গুরুত্বপূর্ণ কারণ:

| কারণ | ব্যাখ্যা |
|-------|----------|
| **কোস্ট অপটিমাইজেশন** | ভিন্ন ভিন্ন কাজের জন্য ভিন্ন মূল্যের মডেল ব্যবহার |
| **ফলব্যাক রেজিলিয়েন্সি** | একটি প্রোভাইডার ডাউন থাকলে অন্যটি ব্যবহার |
| **পারফরম্যান্স** | কিছু কাজে নির্দিষ্ট মডেল ভালো ফলাফল দেয় |
| **প্রাইভেসি** | সংবেদনশীল ডাটার জন্য লোকাল মডেল (Ollama) ব্যবহার  |
| **ফিচার অ্যাক্সেস** | ভিন্ন প্রোভাইডারের ভিন্ন ক্ষমতা (যেমন: Claude-এর বড় কনটেক্সট) |

ভালো খবর হলো, **OpenAI Python লাইব্রেরি একাই বিভিন্ন প্রোভাইডারের সাথে কাজ করার জন্য যথেষ্ট নমনীয়**। শুধু `base_url` এবং `api_key` প্যারামিটার পরিবর্তন করেই আপনি প্রোভাইডার সুইচ করতে পারবেন ।


## ২. OpenAI ক্লায়েন্ট কনফিগারেশন বেসিকস

প্রথমে বেসিক OpenAI ক্লায়েন্ট কনফিগারেশন বুঝি:

```python
from openai import OpenAI

# স্ট্যান্ডার্ড OpenAI ক্লায়েন্ট
client = OpenAI(
    api_key="your-openai-api-key"  # অথবা env variable থেকে
)
```

OpenAI ক্লায়েন্টের সবচেয়ে গুরুত্বপূর্ণ দুটি কনফিগারেশন প্যারামিটার:

1. **`api_key`** : প্রোভাইডারের অথেনটিকেশন কী
2. **`base_url`** : API এন্ডপয়েন্টের URL (ডিফল্ট: `https://api.openai.com/v1`)

অন্য প্রোভাইডার ব্যবহার করতে শুধু এই দুটি প্যারামিটার পরিবর্তন করলেই হয়। কারণ অধিকাংশ আধুনিক এলএলএম প্রোভাইডার OpenAI-র API স্পেসিফিকেশন ফলো করে ।


## ৩. বিভিন্ন প্রোভাইডারের সাথে সংযোগ স্থাপন

### 3.1 Groq (দ্রুততম ইনফারেন্স)

Groq তাদের বিশেষায়িত হার্ডওয়্যারের জন্য অত্যন্ত দ্রুত ইনফারেন্স অফার করে। এটি Llama, Mixtral মডেল চালায় ।

```python
from openai import OpenAI

groq_client = OpenAI(
    api_key="your-groq-api-key",
    base_url="https://api.groq.com/openai/v1"
)

response = groq_client.chat.completions.create(
    model="llama-3.3-70b-versatile",  # Groq-তে উপলব্ধ মডেল
    messages=[
        {"role": "user", "content": "Explain quantum computing in simple terms"}
    ]
)
print(response.choices[0].message.content)
```

### 3.2 Together AI (ওপেন-সোর্স মডেলের বিশাল কালেকশন)

Together AI ৬০+ ওপেন-সোর্স মডেল একসাথে অ্যাক্সেস করার সুযোগ দেয় ।

```python
from openai import OpenAI

together_client = OpenAI(

    base_url="https://api.together.xyz/v1"
)

response = together_client.chat.completions.create(

print(response.choices[0].message.content)
```

### 3.3 Azure OpenAI (এন্টারপ্রাইজ গ্রেড)

Azure OpenAI এর জন্য আলাদা `base_url` এবং `api_key` প্রয়োজন। এখানে `model` প্যারামিটারে **ডিপ্লয়মেন্ট নাম** ব্যবহার করতে হয়, মডেল নাম না ।

```python
from openai import OpenAI

azure_client = OpenAI(
    api_key="your-azure-api-key",
    base_url="https://your-resource.openai.azure.com/openai/v1/"
)

# গুরুত্বপূর্ণ: model প্যারামিটারে ডিপ্লয়মেন্ট নাম দিতে হবে, মডেল নাম নয়
response = azure_client.chat.completions.create(
    model="gpt-4o-deployment",  # এটি আপনার ডিপ্লয়মেন্টের নাম
    messages=[
        {"role": "user", "content": "What is Azure OpenAI?"}
    ]
)
```

> **Azure OpenAI-র বিশেষ নিয়ম:** এখানে মডেল ডিপ্লয়মেন্টের নাম ব্যবহার করতে হয়। আপনার ডিপ্লয়মেন্টের নাম যদি "gpt-4o" হয়, তাহলে `model="gpt-4o"` লিখবেন। মডেলের আসল নাম (যেমন "gpt-4o") ডিপ্লয়মেন্টের নামের সাথে মিল নাও থাকতে পারে ।

### 3.4 Ollama (লোকাল মডেল)

Ollama আপনার নিজের কম্পিউটারে মডেল চালায়। এটি লোকালি LLAMA, Mistral, Phi ইত্যাদি মডেল রান করতে পারে ।

```python
from openai import OpenAI

# Ollama লোকাল সার্ভার ডিফল্টভাবে 11434 পোর্টে চলে
ollama_client = OpenAI(
    base_url="http://localhost:11434/v1",
    api_key="ollama"  # API key প্রয়োজন না, কিন্তু খালি রাখা যায় না
)

response = ollama_client.chat.completions.create(
    model="llama3.2",  # আপনার ডাউনলোড করা মডেলের নাম
    messages=[
        {"role": "user", "content": "What is the capital of Bangladesh?"}
    ]
)
print(response.choices[0].message.content)
```

> **Ollama চালানোর পূর্বশর্ত:** প্রথমে টার্মিনালে `ollama serve` দিয়ে সার্ভার চালু করতে হবে। তারপর `ollama run llama3.2` দিয়ে মডেল ডাউনলোড ও রান করতে হবে ।


## ৪. প্র্যাকটিক্যাল: একাধিক প্রোভাইডার হ্যান্ডলিং

এখন একটি ব্যবহারিক উদাহরণ দেখি যেখানে আমরা একাধিক প্রোভাইডার সাপোর্ট করব এবং ফলব্যাক মেকানিজম ইমপ্লিমেন্ট করব:

```python
import os
from openai import OpenAI
from typing import Optional, Dict, Any

class MultiProviderLLM:
    """একাধিক এলএলএম প্রোভাইডার সাপোর্ট করে এমন ক্লাস"""
    
    def __init__(self):
        self.clients = {}
        self._initialize_clients()
    
    def _initialize_clients(self):
        """এনভায়রনমেন্ট ভেরিয়েবল থেকে সব ক্লায়েন্ট ইনিশিয়ালাইজ করে"""
        
        # OpenAI (যদি API key থাকে)
        if os.getenv("OPENAI_API_KEY"):
            self.clients["openai"] = OpenAI(
                api_key=os.getenv("OPENAI_API_KEY")
            )
        
        # Groq (যদি API key থাকে)
        if os.getenv("GROQ_API_KEY"):
            self.clients["groq"] = OpenAI(
                api_key=os.getenv("GROQ_API_KEY"),
                base_url="https://api.groq.com/openai/v1"
            )
        
        # Together AI
        if os.getenv("TOGETHER_API_KEY"):
            self.clients["together"] = OpenAI(
                api_key=os.getenv("TOGETHER_API_KEY"),
                base_url="https://api.together.xyz/v1"
            )
        
        # Ollama (লোকাল, সবসময় চেষ্টা করে)
        self.clients["ollama"] = OpenAI(
            base_url="http://localhost:11434/v1",
            api_key="ollama"
        )
    
    def generate(self, prompt: str, provider: str = "openai", 
                 model: Optional[str] = None, **kwargs) -> str:
        """
        নির্দিষ্ট প্রোভাইডার থেকে রেসপন্স জেনারেট করে
        
        Args:
            prompt: ইউজারের প্রশ্ন
            provider: প্রোভাইডারের নাম ('openai', 'groq', 'together', 'ollama')
            model: মডেলের নাম (ঐচ্ছিক)
            **kwargs: অতিরিক্ত প্যারামিটার (temperature, max_tokens ইত্যাদি)
        """
        
        if provider not in self.clients:
            raise ValueError(f"Provider '{provider}' not available")
        
        client = self.clients[provider]
        
        # প্রোভাইডার অনুযায়ী ডিফল্ট মডেল
        default_models = {
            "openai": "gpt-3.5-turbo",
            "groq": "llama-3.3-70b-versatile",
            "together": "meta-llama/Llama-3.3-70B-Instruct-Turbo",
            "ollama": "llama3.2"
        }
        
        model = model or default_models.get(provider, "gpt-3.5-turbo")
        
        try:
            response = client.chat.completions.create(
                model=model,
                messages=[{"role": "user", "content": prompt}],
                **kwargs
            )
            return response.choices[0].message.content
        
        except Exception as e:
            return f"Error with {provider}: {str(e)}"
    
    def generate_with_fallback(self, prompt: str, 
                               providers: list = ["openai", "groq", "together"],
                               **kwargs) -> str:
        """একাধিক প্রোভাইডার চেষ্টা করে - প্রথম সফলটি রিটার্ন করে"""
        
        for provider in providers:
            try:
                result = self.generate(prompt, provider=provider, **kwargs)
                if not result.startswith("Error"):
                    print(f"✓ Successfully used {provider}")
                    return result
            except Exception as e:
                print(f"✗ {provider} failed: {e}")
                continue
        
        return "All providers failed. Please check your API keys and connections."


# ব্যবহারের উদাহরণ
if __name__ == "__main__":
    llm = MultiProviderLLM()
    
    # নির্দিষ্ট প্রোভাইডার ব্যবহার
    print("=== Using OpenAI ===")
    response = llm.generate("What is Python?", provider="openai")
    print(response)
    
    print("\n=== Using Groq (Faster) ===")
    response = llm.generate("Explain async programming briefly", provider="groq")
    print(response)
    
    print("\n=== Using Ollama (Local) ===")
    response = llm.generate("What is 2+2?", provider="ollama")
    print(response)
    
    # ফলব্যাক মেকানিজম
    print("\n=== Fallback Mode ===")
    response = llm.generate_with_fallback(
        "Tell me a short joke",
        providers=["openai", "groq", "together"]
    )
    print(response)
```

## ৬. অ্যাডভান্সড টেকনিক: একাধিক প্রোভাইডার ম্যানেজ করার টুলস

হাতে-কলমে মাল্টিপল প্রোভাইডার ম্যানেজ করা ছোট প্রজেক্টের জন্য ঠিক আছে। কিন্তু বড় প্রজেক্টের জন্য কিছু ডেডিকেটেড লাইব্রেরি আছে:

### 6.1 OneLLM (Drop-in Replacement)

OneLLM OpenAI ক্লায়েন্টের একটি **ড্রপ-ইন রিপ্লেসমেন্ট** যা ২২+ প্রোভাইডার এবং ৩০০+ মডেল সাপোর্ট করে ।

```python
from onellm import OpenAI  # শুধু ইম্পোর্ট পরিবর্তন!

client = OpenAI(
    api_key="your-api-key",
    base_url="..."  # যেকোনো প্রোভাইডার
)
```

**বিশেষ ফিচারস:**
- অটোমেটিক ফলব্যাক মেকানিজম
- স্মার্ট ক্যাশিং (৪২,০০০-১,৪৩,০০০ গুণ দ্রুত রেসপন্স)
- কানেকশন পুলিং 

### 6.2 JustLLMs (প্রোডাকশন-রেডি)

JustLLMs একটি প্রোডাকশন-রেডি লাইব্রেরি যা একাধিক প্রোভাইডার ম্যানেজ করার জন্য তৈরি ।

```python
from justllms import JustLLM

client = JustLLM({
    "providers": {
        "openai": {"api_key": "your-openai-key"},
        "google": {"api_key": "your-google-key"},
        "anthropic": {"api_key": "your-anthropic-key"},
        "ollama": {"base_url": "http://localhost:11434"}
    },
    "routing": {
        "fallback_provider": "anthropic",
        "fallback_model": "claude-3-5-sonnet-20241022"
    }
})

# নির্দিষ্ট প্রোভাইডার এবং মডেল ব্যবহার
response = client.completion.create(
    messages=[{"role": "user", "content": "Hello"}],
    model="openai/gpt-4o"  # ফরম্যাট: "provider/model"
)
```


## ৭. বেস্ট প্র্যাকটিস ও টিপস

### 7.1 API Keys নিরাপদে রাখুন
- কখনো কোডে হার্ডকোড করবেন না
- এনভায়রনমেন্ট ভেরিয়েবল ব্যবহার করুন
- প্রোডাকশনে Azure Key Vault বা AWS Secrets Manager ব্যবহার করুন 

### 7.2 টাইমআউট ও রেট্রি সেট করুন
```python
client = OpenAI(
    api_key="your-key",
    timeout=60.0,  # 60 সেকেন্ড টাইমআউট
    max_retries=3   # ব্যর্থ হলে ৩ বার রিট্রাই
)
```

### 7.3 স্ট্রিমিং রেসপন্স ব্যবহার করুন (ইউজার এক্সপেরিয়েন্সের জন্য)
```python
stream = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Tell me a story"}],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="")
```

### 7.4 খরচ ট্র্যাক রাখুন
```python
response = client.chat.completions.create(...)

print(f"Output tokens: {response.usage.completion_tokens}")

```

|--------|---------------|---------|
| `AuthenticationError` | ভুল API key | এনভায়রনমেন্ট ভেরিয়েবল চেক করুন |
| `NotFoundError` | ভুল `base_url` | প্রোভাইডারের ডকুমেন্টেশন চেক করুন |
| `Connection error` | Ollama চলছে না | `ollama serve` দিয়ে সার্ভার চালান  |
| মডেল খুঁজে পাচ্ছে না | Azure-এ ডিপ্লয়মেন্ট নাম ভুল | Azure পোর্টালে ডিপ্লয়মেন্ট নাম চেক করুন  |
| খুব ধীর রেসপন্স | নেটওয়ার্ক ইস্যু বা বড় মডেল | Groq ব্যবহার করুন (দ্রুততম)  |
