## Sales Brochure Generator কী?

**Sales Brochure Generator** হলো এমন একটি অ্যাপ যেখানে ইউজার product/service-এর তথ্য দিবে, আর OpenAI Chat Completions API সেই তথ্য থেকে সুন্দর **marketing brochure copy** তৈরি করবে। যেমন: headline, intro, features, benefits, pricing, call-to-action ইত্যাদি।

OpenAI-এর Chat Completions API একটি conversation-style `messages` list থেকে model response তৈরি করে, এবং endpoint হলো `POST /chat/completions`। OpenAI বর্তমানে নতুন প্রজেক্টের জন্য Responses API ট্রাই করতে বলে, কিন্তু Chat Completions API এখনো ব্যবহার করা যায়। ([OpenAI Developers][1])

```text

      ↓
```

## Node.js Backend Example

প্রথমে install করো:

```bash
npm init -y
npm install express cors dotenv
```

`.env` file:

```env
OPENAI_API_KEY=your_openai_api_key_here
OPENAI_MODEL=gpt-5.4
```

OpenAI docs অনুযায়ী model identifier API endpoint-এ reference করা যায়, আর available model list দেখতে `GET /models` ব্যবহার করা যায়। তাই model name future-এ change হলে `.env` থেকে update করা ভালো। ([OpenAI Developers][2])

`server.js`:

```js
const express = require("express");
const cors = require("cors");
require("dotenv").config();

const app = express();

app.use(cors());
app.use(express.json());

app.post("/generate-brochure", async (req, res) => {
  try {
    const {
      productName,
      targetAudience,
      features,
      benefits,
      tone,
      price,
      callToAction,
      language
    } = req.body;

    if (!productName || !targetAudience) {
      return res.status(400).json({
        error: "Product name and target audience are required."
      });
    }

    const userPrompt = `
Create a professional sales brochure.

Product Name: ${productName}
Target Audience: ${targetAudience}
Features: ${features || "Not provided"}
Benefits: ${benefits || "Not provided"}
Tone: ${tone || "Professional"}
Price: ${price || "Not provided"}
Call To Action: ${callToAction || "Contact us today"}
Language: ${language || "English"}

Brochure format:
1. Catchy Headline
2. Short Introduction
3. Key Features
4. Customer Benefits
5. Why Choose This Product
6. Final Call To Action

Make it persuasive, clear, and easy to read.
`;

    const response = await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": `Bearer ${process.env.OPENAI_API_KEY}`
      },
      body: JSON.stringify({
        model: process.env.OPENAI_MODEL || "gpt-5.4",
        messages: [
          {
            role: "developer",
            content:
              "You are an expert sales copywriter. Generate clean, persuasive, brochure-style marketing content."
          },
          {
            role: "user",
            content: userPrompt
          }
        ]
      })
    });

    const data = await response.json();

    if (!response.ok) {
      return res.status(response.status).json({
        error: data.error?.message || "OpenAI API request failed."
      });
    }

    const brochure = data.choices?.[0]?.message?.content || "";

    res.json({ brochure });
  } catch (error) {
    res.status(500).json({
      error: "Server error. Please try again."
    });
  }
});

app.listen(3000, () => {
  console.log("Server running on http://localhost:3000");
});
```

Chat Completions API-তে `messages` array ব্যবহার করা হয়; সেখানে `developer` message দিয়ে model-কে instruction দেওয়া যায়, আর `user` message-এ actual user input দেওয়া হয়। ([OpenAI Developers][1])

## Flutter App Idea

Flutter app-এ তুমি একটা form বানাতে পারো:

```text
TextField: Product Name
TextField: Target Audience
TextField: Features
TextField: Benefits
Dropdown: Tone
TextField: Price
TextField: CTA
Button: Generate Brochure
Result Box: Generated Brochure
```

Flutter থেকে backend call:

```dart
import 'dart:convert';
import 'package:http/http.dart' as http;

Future<String> generateBrochure() async {
  final response = await http.post(
    Uri.parse("http://localhost:3000/generate-brochure"),
    headers: {
      "Content-Type": "application/json",
    },
    body: jsonEncode({
      "productName": "Smart Water Bottle",
      "targetAudience": "Fitness lovers",
      "features": "Tracks water intake, temperature display",
      "benefits": "Keeps users hydrated",
      "tone": "Friendly",
      "price": "\$29",
      "callToAction": "Order now",
      "language": "English"
    }),
  );

  if (response.statusCode == 200) {
    final data = jsonDecode(response.body);
    return data["brochure"];
  } else {
    throw Exception("Failed to generate brochure");
  }
}
```
