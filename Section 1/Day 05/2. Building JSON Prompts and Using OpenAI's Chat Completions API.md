## Building JSON Prompts and Using OpenAI Chat Completions API


1. **API request body JSON** — OpenAI API-তে যেটা পাঠাও।
2. **Model output JSON** — model যেন fixed JSON format-এ answer দেয়।

Chat Completions API-তে request পাঠানো হয় `POST /chat/completions` endpoint-এ, এবং conversation পাঠাতে `messages` array ব্যবহার করা হয়। OpenAI নতুন project-এর জন্য Responses API recommend করে, কিন্তু Chat Completions API এখনো supported। ([OpenAI Developers][1])

---

## 1. Basic Chat Completions JSON Body

```json
{
  "model": "gpt-4o-mini",
  "messages": [
    {
      "role": "developer",
      "content": "You are a professional sales copywriter."
    },
    {
      "role": "user",
      "content": "Create a sales brochure for a Smart Water Bottle."
    }
  ]
}
```

এখানে:

```text
model = কোন AI model ব্যবহার করবে
messages = conversation list
developer = model-কে instruction দেওয়ার জন্য
user = user-এর actual request
```

OpenAI docs অনুযায়ী `developer` message model-কে instruction দেওয়ার জন্য ব্যবহার করা যায়, আর newer models-এ এটি previous `system` instruction-এর জায়গায় ব্যবহৃত হয়। ([OpenAI Developers][1])

## 2. JSON Prompt Example

ধরো user sales brochure বানাতে এই data দিয়েছে:

```json
{
  "productName": "Smart Water Bottle",
  "targetAudience": "Fitness lovers",
  "features": [
    "Tracks water intake",
    "Shows water temperature",
    "Sends mobile reminders"
  ],
  "tone": "Friendly and modern",
  "language": "English"
}
```

এখন এই JSON data prompt হিসেবে পাঠানো যায়:

```js
const productData = {
  productName: "Smart Water Bottle",
  targetAudience: "Fitness lovers",
  features: [
    "Tracks water intake",
    "Shows water temperature",
    "Sends mobile reminders"
  ],
  tone: "Friendly and modern",
  language: "English"
};

const userPrompt = `
Create a sales brochure using this product data:

${JSON.stringify(productData, null, 2)}

Return the brochure in a clean and persuasive style.
`;
```

`JSON.stringify()` ব্যবহার করলে object সুন্দরভাবে string prompt-এ convert হয়। এতে prompt clean থাকে এবং বড় data manage করা সহজ হয়।

## 3. Better Way: Ask Output as JSON

শুধু “Return JSON” বললে model valid JSON দিতে পারে, কিন্তু exact structure সবসময় guarantee নাও করতে পারে। OpenAI-এর Structured Outputs `response_format: { type: "json_schema", ... }` ব্যবহার করলে model নির্দিষ্ট JSON Schema follow করতে পারে; OpenAI docs অনুযায়ী Structured Outputs JSON mode-এর চেয়ে better, কারণ JSON mode valid JSON দেয়, কিন্তু schema follow guarantee করে না। ([OpenAI Developers][2])

## 4. Full Node.js Example

Install:

```bash
npm init -y
npm install express cors dotenv
```

`.env` file:

```env
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=gpt-4o-mini
```

`server.js`:

```js
const express = require("express");
const cors = require("cors");
require("dotenv").config();

const app = express();

app.use(cors());
app.use(express.json());

app.post("/generate-brochure-json", async (req, res) => {
  try {
    const {
      productName,
      targetAudience,
      features,
      benefits,
      tone,
      price,
      callToAction,
      language
    } = req.body;

    if (!productName || !targetAudience) {
      return res.status(400).json({
        error: "Product name and target audience are required."
      });
    }

    const productData = {
      productName,
      targetAudience,
      features: features || [],
      benefits: benefits || [],
      tone: tone || "Professional",
      price: price || "Not provided",
      callToAction: callToAction || "Contact us today",
      language: language || "English"
    };

    const response = await fetch("https://api.openai.com/v1/chat/completions", {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": `Bearer ${process.env.OPENAI_API_KEY}`
      },
      body: JSON.stringify({
        model: process.env.OPENAI_MODEL || "gpt-4o-mini",
        messages: [
          {
            role: "developer",
            content:
              "You are an expert marketing copywriter. Generate persuasive sales brochure content."
          },
          {
            role: "user",
            content: `
Create a sales brochure from this JSON product data:

${JSON.stringify(productData, null, 2)}

Make the content clear, attractive, and suitable for customers.
`
          }
        ],
        response_format: {
          type: "json_schema",
          json_schema: {
            name: "sales_brochure",
            strict: true,
            schema: {
              type: "object",
              additionalProperties: false,
              properties: {
                headline: {
                  type: "string"
                },
                shortIntro: {
                  type: "string"
                },
                keyFeatures: {
                  type: "array",
                  items: {
                    type: "string"
                  }
                },
                customerBenefits: {
                  type: "array",
                  items: {
                    type: "string"
                  }
                },
                whyChooseUs: {
                  type: "string"
                },
                priceNote: {
                  type: "string"
                },
                callToAction: {
                  type: "string"
                }
              },
              required: [
                "headline",
                "shortIntro",
                "keyFeatures",
                "customerBenefits",
                "whyChooseUs",
                "priceNote",
                "callToAction"
              ]
            }
          }
        }
      })
    });

    const data = await response.json();

    if (!response.ok) {
      return res.status(response.status).json({
        error: data.error?.message || "OpenAI API request failed."
      });
    }

    const jsonText = data.choices[0].message.content;
    const brochureJson = JSON.parse(jsonText);

    res.json({
      success: true,
      brochure: brochureJson
    });
  } catch (error) {
    res.status(500).json({
      error: "Server error. Please try again."
    });
  }
});

app.listen(3000, () => {
  console.log("Server running on http://localhost:3000");
});
```

## Important Tips

API key কখনো Flutter app বা frontend-এ রাখবে না। Backend server-এ `.env` file-এ রাখবে।

Prompt-এর ভিতরে raw object না দিয়ে `JSON.stringify()` ব্যবহার করো।

Output JSON দরকার হলে শুধু prompt-এ “give JSON” না লিখে `response_format` ব্যবহার করো।

Schema ছোট ও clear রাখো। বেশি complex schema দিলে debugging কঠিন হতে পারে।
