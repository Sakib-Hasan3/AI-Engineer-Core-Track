## 🤖 Agentic AI কী?

**Agentic AI** মানে এমন AI যা:

* নিজে সিদ্ধান্ত নিতে পারে
* step-by-step কাজ plan করতে পারে
* একাধিক টাস্ক execute করতে পারে
* goal পূরণ না হওয়া পর্যন্ত কাজ চালিয়ে যেতে পারে

👉 মানে এটা শুধু “chatbot” না, বরং “digital assistant + worker” একসাথে।

---

## 🔍 এই টপিকের ৩টা মূল অংশ

### 1. 🧠 ChatGPT – Deep Research

* Deep Research হলো advanced feature
* AI নিজে:

  * তথ্য খুঁজে
  * analyse করে
  * compare করে
  * report তৈরি করে

👉 এটা অনেকটা “AI researcher” এর মতো কাজ করে

---

### 2. 💻 Claude Code

* Claude Code হলো coding-focused AI tool
* এটা:

  * কোড লিখতে পারে
  * project structure বুঝতে পারে
  * bug fix করতে পারে
  * large codebase handle করতে পারে

👉 এটা অনেকটা “AI software developer”

---

### 3. ⚙️ Agent Mode (AI Agent behavior)

* Agent Mode-এ AI:

  * goal পায় (যেমন: “website বানাও”)
  * plan তৈরি করে
  * multiple steps execute করে
  * মাঝে মাঝে নিজেই decision নেয়

👉 উদাহরণ:

> “একটা blog website বানাও”

AI তখন:

1. design plan করবে
2. code লিখবে
3. error ঠিক করবে
4. final output দিবে

---

## 🚀 “In Action” মানে কী?

“In Action” মানে real-life ব্যবহার।

👉 অর্থাৎ:
এই তিনটা জিনিস (Deep Research + Claude Code + Agent Mode) কিভাবে বাস্তবে কাজ করে সেটা দেখানো।

---

## 🧪 Example (বাস্তব scenario)

ধরো তুমি বললে:

> “AI দিয়ে একটা career guidance website বানাও”

তখন Agentic AI করবে:

1. 🔍 Research (Deep Research)

   * কী features দরকার
   * কীভাবে কাজ করবে

2. 🧠 Planning (Agent Mode)

   * UI design
   * database structure
   * backend logic

3. 💻 Development (Claude Code)

   * PHP/JS code লিখবে
   * login system বানাবে
   * chatbot integrate করবে

4. 🔄 Iteration

   * bug fix
   * improve

Agentic AI খুব powerful, কিন্তু:

* ভুল সিদ্ধান্ত নিতে পারে
* ভুল তথ্য ব্যবহার করতে পারে
* সবসময় human supervision দরকার
