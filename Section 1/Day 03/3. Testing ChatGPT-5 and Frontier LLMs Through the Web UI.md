## 🔍 মূল ধারণা

এখানে তিনটা জিনিস আছে:

### 1. ChatGPT-5 এবং Frontier LLMs

* **ChatGPT-5** বলতে বোঝায় OpenAI-এর নতুন বা উন্নত ভাষা মডেল (LLM = Large Language Model)।
* **Frontier LLMs** মানে হলো সবচেয়ে আধুনিক, শক্তিশালী এবং cutting-edge AI মডেলগুলো (যেমন GPT-5, Claude, Gemini ইত্যাদি)।

👉 এগুলো মানুষের মতো টেক্সট বুঝতে, লিখতে, কোড করতে, সমস্যা সমাধান করতে পারে।

---

### 2. Testing (পরীক্ষা করা)

* এখানে “testing” মানে হলো এই AI মডেলগুলো কতটা ভালো কাজ করছে সেটা যাচাই করা।
* যেমন:

  * প্রশ্নের উত্তর ঠিক দিচ্ছে কিনা
  * কোড ঠিকভাবে লিখছে কিনা
  * reasoning বা logic ঠিক আছে কিনা
  * ভুল বা hallucination করছে কিনা

---

### 3. Web UI (Web User Interface)

* Web UI মানে হলো ব্রাউজারের মাধ্যমে ব্যবহার করা ইন্টারফেস (যেমন ChatGPT ওয়েবসাইট)।
* এখানে কোনো কোডিং না করেই তুমি AI-এর সাথে চ্যাট করতে পারো।
