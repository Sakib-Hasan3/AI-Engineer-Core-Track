
## ১. Git এবং Cursor কী? কেন এগুলো দরকার?

### Git কী?
Git একটি **ভার্সন কন্ট্রোল সিস্টেম**। এটি আপনার কোডের সব পরিবর্তনের ইতিহাস সংরক্ষণ করে, যাতে আপনি:
- পুরনো ভার্সনে ফিরে যেতে পারেন 
- টিমের সাথে সহযোগিতা করতে পারেন
- বিভিন্ন ফিচার আলাদা ব্রাঞ্চে ডেভেলপ করতে পারেন
- GitHub-এ কোড ব্যাকআপ রাখতে পারেন

### Cursor কী?
Cursor একটি **AI-পাওয়ার্ড কোড এডিটর** যা VS Code-এর ওপর বিল্ট। এতে বিল্ট-ইন AI ক্যাপাবিলিটি আছে যেমন :
- কোড লেখার সময় AI সাজেশন (`Tab`)
- চ্যাটের মাধ্যমে প্রশ্ন করা (`Cmd+L` / `Ctrl+L`)
- ইনলাইন এডিট (`Cmd+K` / `Ctrl+K`)
- এজেন্ট মোডে জটিল টাস্ক করা (`Cmd+I` / `Ctrl+I`)

এই দুটি টুল একসাথে ব্যবহার করলে আপনি একটি **মডার্ন, এআই-সক্ষম ডেভেলপমেন্ট এনভায়রনমেন্ট** পাবেন।

## ২. ধাপ ১: Git ইনস্টল করা (সব প্ল্যাটফর্মের জন্য)

### Windows-এ Git ইনস্টল

**ধাপ 1:** Git-এর অফিসিয়াল ওয়েবসাইট থেকে ডাউনলোড করুন 
- যান: https://git-scm.com/download/win
- ডাউনলোড স্বয়ংক্রিয়ভাবে শুরু হবে

**ধাপ 2:** ইনস্টলার রান করুন (রাইট-ক্লিক → "Run as Administrator") 

**ধাপ 3:** ইন্সটলেশনের সময় গুরুত্বপূর্ণ অপশনগুলো:

| স্ক্রিন | কী করবেন |
|---------|-----------|
| **Select Components** | ডিফল্ট সবকিছু রেখে দিন। "Add a Git Bash Profile to Windows Terminal" চেক করুন  |
| **Choosing the default editor** | "Use Visual Studio Code as Git's default editor" সিলেক্ট করুন। VS Code না থাকলে "Use Notepad" নিন  |
| **Adjusting your PATH** | **দ্বিতীয় অপশনটি সিলেক্ট করুন:** "Git from the command line and also from 3rd-party software"  |
| **HTTPS transport backend** | প্রথম অপশন "Use the OpenSSL library" রাখুন |
| **Line ending conversions** | প্রথম অপশন নিন (Checkout Windows-style, commit Unix-style)  |

**ধাপ 4:** বাকি সব জায়গায় `Next` দিয়ে Install করুন।

### macOS-এ Git ইনস্টল

**পদ্ধতি 1 (সহজ):** Homebrew দিয়ে
```bash
brew install git
```

**পদ্ধতি 2:** Xcode Command Line Tools দিয়ে
```bash
xcode-select --install
```

### Linux-এ Git ইনস্টল (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install git
```

### ইনস্টল ভেরিফাই করা
```bash
git --version
```
ভার্সন নম্বর দেখালে ইনস্টল সফল হয়েছে ।

## ৩. ধাপ ২: Git কনফিগার করা (প্রথমবারের জন্য বাধ্যতামূলক)

Git ইনস্টলের পর সবচেয়ে গুরুত্বপূর্ণ কাজ হলো **ইউজারনেম এবং ইমেইল কনফিগার করা**। এটা না করলে commit করা যাবে না ।

```bash
git config --global user.name "আপনার ইউজারনেম"
git config --global user.email "আপনার-ইমেইল@example.com"
```

### অপশনাল কিন্তু দরকারি কনফিগারেশন

```bash
# ডিফল্ট ব্রাঞ্চের নাম 'main' সেট করা
git config --global init.defaultBranch main

# কমান্ডের আউটপুট রঙিন করা
git config --global color.ui auto

# লাইন এন্ডিং কনফিগারেশন (Windows-এর জন্য)
git config --global core.autocrlf true
```

### কনফিগারেশন চেক করা
```bash
git config --list
```

## ৪. ধাপ ৩: GitHub অ্যাকাউন্ট তৈরি ও SSH Key সেটআপ

### GitHub অ্যাকাউন্ট তৈরি
1. https://github.com-এ যান
2. "Sign up" বাটনে ক্লিক করুন
3. ইউজারনেম, ইমেইল ও পাসওয়ার্ড দিয়ে অ্যাকাউন্ট তৈরি করুন

### SSH Key তৈরি করা (পাসওয়ার্ড ছাড়া GitHub-এ সংযোগের জন্য)

SSH Key ব্যবহার করলে প্রতিবার GitHub-এ পুশ করার সময় ইউজারনেম-পাসওয়ার্ড দিতে হয় না ।

**ধাপ 1:** SSH Key জেনারেট করুন
```bash
ssh-keygen -t rsa -b 4096 -C "আপনার-ইমেইল@example.com"
```
এন্টার চাপলে ডিফল্ট লোকেশনেই সেভ হবে।

**ধাপ 2:** পাবলিক কী কপি করুন
```bash
# Windows
cat ~/.ssh/id_rsa.pub

# macOS/Linux
cat ~/.ssh/id_rsa.pub
```

**ধাপ 3:** GitHub-এ কী যোগ করুন 
1. GitHub সেটিংস → SSH and GPG keys-এ যান
2. "New SSH Key" ক্লিক করুন
3. টাইটেল দিন (যেমন "My PC")
4. কপি করা পাবলিক কী পেস্ট করুন
5. "Add SSH Key" ক্লিক করুন

**ধাপ 4:** কানেকশন টেস্ট করুন
```bash
ssh -T git@github.com
```
"Hi username! You've successfully authenticated..." মেসেজ দেখলে কাজ হয়েছে।

### Personal Access Token (PAT) তৈরি (SSH না চাইলে)

SSH ব্যবহার না করলে PAT লাগবে। GitHub-এ পাসওয়ার্ডের বদলে PAT ব্যবহার করতে হয় ।

1. GitHub Settings → Developer settings → Personal access tokens → Tokens (classic)
2. "Generate new token (classic)" ক্লিক করুন
3. `repo` এবং `workflow` স্কোপ সিলেক্ট করুন
4. টোকন জেনারেট করে কপি করে রাখুন (পরে আর দেখা যাবে না)

### সাইন ইন করুন (প্রয়োজনীয়)

1. Welcome স্ক্রিনে "Sign In" ক্লিক করুন

## ৮. ধাপ ৭: প্রথম Git রিপোজিটরি তৈরি করা

এবার আমরা একটি প্রজেক্ট তৈরি করে Git দিয়ে ট্র্যাক করব এবং GitHub-এ পুশ করব।

### লোকাল রিপোজিটরি তৈরি
```bash
# প্রজেক্ট ফোল্ডার তৈরি
mkdir my-first-project
cd my-first-project

# Git রিপোজিটরি ইনিশিয়ালাইজ
git init

# প্রথম ফাইল তৈরি
echo "# My First Project" > README.md

# ফাইলগুলো স্টেজিং
git add README.md

# প্রথম commit
git commit -m "Initial commit: add README"
```

### GitHub-এ রিমোট রিপোজিটরি তৈরি
1. GitHub ওয়েবসাইটে "New repository" ক্লিক করুন
2. রিপোজিটরির নাম দিন (যেমন `my-first-project`)
3. "Create repository" ক্লিক করুন

### লোকালকে রিমোটের সাথে কানেক্ট করা 

**SSH দিয়ে (recommended):**
```bash
git remote add origin git@github.com:YOUR_USERNAME/my-first-project.git
git branch -M main
git push -u origin main
```

**HTTPS দিয়ে (PAT লাগবে):**
```bash
git remote add origin https://github.com/YOUR_USERNAME/my-first-project.git
git branch -M main
git push -u origin main
```
পাসওয়ার্ড চাইলে PAT ব্যবহার করুন ।

## ৯. দরকারি Git কমান্ডের চিটশিট

| কাজ | কমান্ড |
|------|---------|
| রিপোজিটরি স্ট্যাটাস দেখা | `git status`  |
| সব পরিবর্তন স্টেজ করা | `git add -A`  |
| স্টেজ করা পরিবর্তন কমিট করা | `git commit -m "message"` |
| সব পরিবর্তন একসাথে add + commit | `git commit -a -m "message"` |
| GitHub-এ পুশ করা | `git push origin main`  |
| GitHub থেকে ডাউনলোড করা | `git pull origin main` |
| ব্রাঞ্চের হিস্ট্রি দেখা | `git log --oneline` |
| পার্থক্য দেখা (unstaged changes) | `git diff` |
| পার্থক্য দেখা (staged changes) | `git diff --staged` |

### Git Aliases (টাইম সেভার)
```bash
git config --global alias.st status
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.ci commit
git config --global alias.lg "log --oneline --graph"
```

এখন `git st` লিখলেই `git status` রান হবে।

## ১১. কমন সমস্যা ও সমাধান

### সমস্যা 1: "git command not found" বা Git চিনছে না
**সমাধান:** Windows-এ PATH চেক করুন। Git ইনস্টলার রান করে "Git from command line" অপশন সিলেক্ট করুন ।

### সমস্যা 2: push করতে গেলে authentication error
**সমাধান:** 
- SSH ব্যবহার করলে `ssh -T git@github.com` দিয়ে কানেকশন চেক করুন 
- HTTPS ব্যবহার করলে Personal Access Token ব্যবহার করুন 

### সমস্যা 3: "Please tell me who you are" error
**সমাধান:** Git config করা হয়নি। রান করুন:
```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

### সমস্যা 4: Cursor-এ Python খুঁজে পাচ্ছে না
**সমাধান:** 
- Windows: Python রিইনস্টল করে "Add to PATH" চেক করুন
- macOS/Linux: `python3` ব্যবহার করুন
- Cursor রিস্টার্ট দিন

### সমস্যা 5: Cursor-এর AI ফিচার কাজ করছে না
**সমাধান:** 
- সাইন ইন করা আছে কিনা চেক করুন (নিচের বাম কোণে)
- ইন্টারনেট কানেকশন চেক করুন
