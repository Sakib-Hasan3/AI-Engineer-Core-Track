
## প্রথম দিন: আপনার কম্পিউটারে প্রথম এলএলএম চালানো (Ollama ও ওপেন সোর্স মডেল দিয়ে)

### ১. বিষয়টা কী? (What is this about?)

সাধারণত বড় ভাষার মডেল (LLM) যেমন ChatGPT ব্যবহার করতে ইন্টারনেট ও API প্রয়োজন হয়। কিন্তু আপনি চাইলে আপনার নিজের কম্পিউটারে **অফলাইনে** ও **বিনামূল্যে** একটি এলএলএম চালাতে পারেন। এর জন্য দরকার **Ollama** নামক টুল এবং কিছু **ওপেন সোর্স মডেল** (যেমন Llama, Mistral, Phi)।

### ২. কেন এটি শেখা দরকার? (Why learn this?)

- **গোপনীয়তা:** আপনার ডাটা বাইরের সার্ভারে যায় না।
- **ফ্রি:** কোনো API খরচ নেই।
- **অফলাইন:** ইন্টারনেট ছাড়াই চলে।
- **কাস্টমাইজেশন:** নিজের মতো করে মডেল বানাতে পারেন।

### ৩. কী কী লাগবে? (Requirements)

- একটি কম্পিউটার (Windows/macOS/Linux)
- কমপক্ষে ৮ জিবি র্যাম (১৬ জিবি ভালো)
- কিছু জিবি ফাঁকা জায়গা (মডেল সাইজ ভেদে ৪-৭ জিবি)
- মৌলিক কমান্ড লাইন জানা থাকলে সুবিধা

### ৪. Ollama কী? (What is Ollama?)

Ollama একটি ফ্রি ওপেন সোর্স টুল। এটি লোকাল মেশিনে এলএলএম ডাউনলোড, চালানো ও ম্যানেজ করা সহজ করে দেয়। এটি Docker-এর মতো কাজ করে – একটি কমান্ড দিলেই মডেল রান করে।

### ৫. ধাপে ধাপে কী করবেন? (Step-by-step guide)

#### ধাপ ১: Ollama ইনস্টল করা
- ওয়েবসাইট: [ollama.com](https://ollama.com) থেকে আপনার OS অনুযায়ী ভার্সন ডাউনলোড করুন।
- ইনস্টল করে দিন (Windows হলে .exe ফাইল রান করুন)।

#### ধাপ ২: কমান্ড লাইন খোলা
- Windows: Command Prompt বা PowerShell
- Mac/Linux: Terminal

#### ধাপ ৩: প্রথম মডেল রান করা
নিচের কমান্ড লিখুন:
```bash
ollama run llama3.2
```
(এখানে `llama3.2` হলো মেটার ওপেন সোর্স মডেল)

- প্রথমবার কমান্ড দিলে মডেলটি ডাউনলোড হবে (~৪-৭ জিবি)।
- তারপর সরাসরি চ্যাট শুরু হয়ে যাবে।

#### ধাপ ৪: চ্যাট করা
যেমন লিখুন:
```
>>> তুমি কে?
>>> বাংলায় একটি কবিতা লেখো।
```
মডেল উত্তর দেবে।

#### ধাপ ৫: বের হওয়া
`/bye` বা `Ctrl+D` চাপুন।

### ৬. কিছু সহজ ওপেন সোর্স মডেলের নাম (Easy Open Source Models)

| মডেল | সাইজ | বিশেষত্ব |
|------|------|-----------|
| `llama3.2` | ৩ বিলিয়ন প্যারামিটার | দ্রুত, সাধারণ কাজের জন্য |
| `mistral` | ৭ বিলিয়ন | ভালো রিজনিং |
| `phi3` | ৩.৮ বিলিয়ন | ছোট, দ্রুত, মাইক্রোসফটের |
| `gemma2` | ৯ বিলিয়ন | গুগলের, নির্ভুল |

নোট: বড় প্যারামিটার মানে বেশি স্মৃতি ও ধীরগতি, কিন্তু ভালো উত্তর।

### ৭. বাংলা ভাষায় কাজ করবে? (Bengali support?)

- বেশিরভাগ ইংরেজি মডেল বাংলায় ভালো কাজ করে না। তবে কিছু ফাইন-টিউন করা মডেল আছে।
- আপনি `llama3.2`-এ বাংলায় প্রশ্ন করলে মিশ্র উত্তর পেতে পারেন।
- সম্পূর্ণ বাংলার জন্য বিশেষায়িত মডেল (যেমন `bangla-llama`) আলাদা করে খুঁজে নিতে হবে।

### ৮. একটি উদাহরণ রান (Example run)

```bash
C:\> ollama run llama3.2
>>> বাংলায় "হ্যালো ওয়ার্ল্ড" অনুবাদ করো
উত্তর: "হ্যালো ওয়ার্ল্ড" বাংলায় হয় "ওহে বিশ্ব" বা "হ্যালো দুনিয়া"
>>> /bye
```

### ১০. পরবর্তী ধাপ (Next steps)
