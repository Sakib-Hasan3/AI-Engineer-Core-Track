
## ১. UV কী এবং কেন এটি ব্যবহার করবেন?

UV হল একটি **Rust-এ লেখা অত্যন্ত দ্রুতগতির পাইথন প্যাকেজ ও প্রজেক্ট ম্যানেজার**। এটি একাই `pip`, `pip-tools`, `pipx`, `poetry`, `pyenv`, `virtualenv`, `twine`-এর মতো একাধিক টুলের কাজ করে ।

### UV-এর বিশেষ সুবিধাসমূহ:

| ফিচার | বর্ণনা |
|--------|---------|
| 🚀 **অতি দ্রুত** | pip থেকে ১০-১০০ গুণ দ্রুত  |
| 🗂️ **প্রজেক্ট ম্যানেজমেন্ট** | লকফাইল দিয়ে ডিপেন্ডেন্সি রিপ্রোডিউসিবল রাখে  |
| 🐍 **পাইথন ভার্সন ম্যানেজ** | প্রয়োজন অনুযায়ী পাইথন ইনস্টল ও পিন করে  |
| 🛠️ **টুল রানার (uvx)** | CLI টুল আইসোলেটেড এনভায়রনমেন্টে রান করে  |
| 💾 **ডিস্ক-এফিশিয়েন্ট** | গ্লোবাল ক্যাশে ডিপেন্ডেন্সি ডিডুপ্লিকেশন করে  |
| 🔩 **pip-কম্প্যাটিবল** | পরিচিত CLI, কিন্তু অনেক বেশি পারফরম্যান্স  |

### কখন UV ব্যবহার করবেন?
- নতুন পাইথন প্রজেক্ট শুরু করলে
- দ্রুত ডিপেন্ডেন্সি ইনস্টল করতে চাইলে
- একাধিক প্রজেক্টের পাইথন ভার্সন ম্যানেজ করতে চাইলে
- Cursor-এর সাথে MCP সার্ভার কানেক্ট করতে চাইলে

## ২. UV ইনস্টল করা (সব প্ল্যাটফর্মের জন্য)

UV ইনস্টলের একাধিক পদ্ধতি আছে। আপনার OS অনুযায়ী যেকোনো একটি ফলো করুন:

### পদ্ধতি A: স্ট্যান্ডেলোন ইনস্টলার (সহজ ও প্রস্তাবিত) 

**macOS/Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows (PowerShell):**
```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### পদ্ধতি B: pip দিয়ে ইনস্টল (যদি ইতিমধ্যে পাইথন থাকে)
```bash
pip install uv
```

### পদ্ধতি C: pipx দিয়ে ইনস্টল (গ্লোবাল টুল হিসেবে)
```bash
pipx install uv
```

### পদ্ধতি D: Homebrew দিয়ে (macOS)
```bash
brew install uv
```

### ইনস্টল ভেরিফাই করা:
```bash
uv --version
```
ভার্সন নম্বর দেখালে ইনস্টল সফল হয়েছে।

### UV আপডেট করা (স্ট্যান্ডেলোন ইনস্টলের জন্য):
```bash
uv self update
```

## ৩. UV দিয়ে প্রথম পাইথন প্রজেক্ট তৈরি করা

UV ইনস্টল করার পর একটি প্রজেক্ট তৈরি করে দেখি:

### 3.1 প্রজেক্ট ফোল্ডার তৈরি ও ইনিশিয়ালাইজ 
```bash
# প্রজেক্ট ফোল্ডার তৈরি করুন
mkdir my-llm-project
cd my-llm-project

# UV প্রজেক্ট ইনিশিয়ালাইজ করুন
uv init .
```

এই কমান্ডটি স্বয়ংক্রিয়ভাবে নিচের ফোল্ডার স্ট্রাকচার তৈরি করবে:
```
my-llm-project/
├── .venv/              # ভার্চুয়াল এনভায়রনমেন্ট
├── .python-version     # পাইথন ভার্সন ফিক্স করে
├── pyproject.toml      # প্রজেক্ট মেটাডাটা ও ডিপেন্ডেন্সি
├── uv.lock             # লকড ডিপেন্ডেন্সি লিস্ট
├── README.md           # প্রজেক্ট ডকুমেন্টেশন
└── main.py             # স্যাম্পল পাইথন ফাইল
```

### 3.2 পাইথন ভার্সন সেট করা (প্রয়োজন হলে)
```bash
# নির্দিষ্ট পাইথন ভার্সন পিন করতে
uv python pin 3.12

# সব ডিপেন্ডেন্সি সিঙ্ক করতে
uv sync
```

### 3.3 ডিপেন্ডেন্সি যোগ করা
```bash
# প্রোডাকশন ডিপেন্ডেন্সি
uv add requests
uv add fastapi uvicorn

# ডেভেলপমেন্ট ডিপেন্ডেন্সি
uv add --dev pytest black

# নির্দিষ্ট গ্রুপে ডিপেন্ডেন্সি
uv add --group test pytest pytest-cov
```

### 3.4 প্রজেক্ট রান করা
```bash
# main.py রান করতে
uv run python main.py

# অথবা সরাসরি
uv run main.py
```

## ৪. Cursor-এ UV প্রজেক্ট খোলা ও কনফিগার করা

### 4.1 Cursor-এ প্রজেক্ট ওপেন করা
1. **Cursor ওপেন করুন**
2. **File → Open Folder** → আপনার `my-llm-project` ফোল্ডার সিলেক্ট করুন
3. টার্মিনাল খুলুন (`Ctrl+`` ` বা View → Terminal)

### 4.2 Cursor-এ পাইথন ইন্টারপ্রেটার সিলেক্ট করা 

Cursor-কে UV-র ভার্চুয়াল এনভায়রনমেন্ট চিনিয়ে দেওয়া জরুরি:

**পদ্ধতি 1: কমান্ড প্যালেট থেকে**
1. `Ctrl+Shift+P` (Windows/Linux) বা `Cmd+Shift+P` (Mac) চাপুন
2. টাইপ করুন: **"Python: Select Interpreter"**
3. লিস্ট থেকে `.venv/bin/python` (Mac/Linux) বা `.venv\Scripts\python.exe` (Windows) সিলেক্ট করুন

**পদ্ধতি 2: স্ট্যাটাস বার থেকে**
- Cursor-এর নিচের বাম কোণে পাইথন ভার্সন দেখাবে
- সেখানে ক্লিক করে ইন্টারপ্রেটার পরিবর্তন করুন

### 4.3 টার্মিনালে ভার্চুয়াল এনভায়রনমেন্ট অ্যাক্টিভেট করা

Cursor-এর টার্মিনালে UV-র `.venv` অ্যাক্টিভেট করুন:

**Windows (CMD/PowerShell):**
```bash
.venv\Scripts\activate
```

**macOS/Linux:**
```bash
source .venv/bin/activate
```

অ্যাক্টিভেট করার পর টার্মিনালের প্রম্পটে `(.venv)` দেখাবে।

### 4.4 প্রজেক্ট-নির্দিষ্ট সেটিংস তৈরি করা (অপশনাল)

Cursor-এর জন্য প্রজেক্ট-লেভেল সেটিংস তৈরি করতে :

```bash
# .vscode ফোল্ডার তৈরি করুন (Cursor VS Code-ভিত্তিক)
mkdir -p .vscode

# settings.json তৈরি করুন
cat > .vscode/settings.json << EOF
{
    "python.defaultInterpreterPath": "\${workspaceFolder}/.venv/bin/python",
    "python.terminal.activateEnvironment": true,
    "[python]": {
        "editor.defaultFormatter": "charliermarsh.ruff",
        "editor.formatOnSave": true
    }
}
EOF
```

## ৫. UV-এর সাথে Cursor-এর MCP সার্ভার কনফিগার করা (অ্যাডভান্সড)

MCP (Model Context Protocol) সার্ভার Cursor-কে বাইরের টুল ও API-র সাথে সংযোগ করতে দেয়। UV (`uvx` কমান্ড) দিয়ে MCP সার্ভার চালানো যায় ।

### MCP কনফিগারেশন ফাইল তৈরি করা

**পদ্ধতি 1: গ্লোবাল কনফিগারেশন (সব প্রজেক্টের জন্য)**
```bash
# Home ডিরেক্টরিতে .cursor ফোল্ডার তৈরি করুন
mkdir -p ~/.cursor

# mcp.json ফাইল তৈরি করুন
nano ~/.cursor/mcp.json
```

**পদ্ধতি 2: প্রজেক্ট-লেভেল কনফিগারেশন**
```bash
# প্রজেক্টের .cursor ফোল্ডারে
mkdir -p .cursor
nano .cursor/mcp.json
```

### mcp.json-এর উদাহরণ কনফিগারেশন 

```json
{
  "mcpServers": {
    "agentmode": {
      "command": "uvx",
      "args": ["agentmode"],
      "env": {}
    },
    "stock-images": {
      "command": "uvx",
      "args": ["git+https://github.com/Zulelee/stock-images-mcp"],
      "env": {
        "UNSPLASH_API_KEY": "your_key_here"
      }
    }
  }
}
```

### MCP সার্ভার অ্যাক্টিভেট করা
1. Cursor রিস্টার্ট করুন
2. সেটিংসে গিয়ে MCP সার্ভারের টগল অন করুন

| পাইথন স্ক্রিপ্ট রান | `uv run python script.py` |

| ডিপেন্ডেন্সি ট্রি দেখা | `uv tree` |

## ৭. সাধারণ সমস্যা ও সমাধান

### সমস্যা 1: `uv: command not found` বা UV চিনছে না
**কারণ:** PATH সঠিকভাবে সেট হয়নি।
**সমাধান:** 
- টার্মিনাল রিস্টার্ট করুন
- Windows: System Environment Variables-এ `%USERPROFILE%\.local\bin` যোগ করুন
- macOS/Linux: শেল কনফিগ ফাইলে যোগ করুন: `export PATH="$HOME/.local/bin:$PATH"`

### সমস্যা 2: Cursor-এ পাইথন ইন্টারপ্রেটার খুঁজে পাচ্ছে না
**কারণ:** `.venv` সঠিকভাবে তৈরি হয়নি।
**সমাধান:**
```bash
# প্রজেক্ট ডিরেক্টরিতে
uv sync  # এটি .venv তৈরি করবে
# তারপর Cursor রিলোড করুন
```

### সমস্যা 3: MCP সার্ভার কানেক্ট হচ্ছে না
**কারণ:** `uvx` কমান্ড PATH-এ নেই।
**সমাধান:**
- `which uvx` দিয়ে পাথ চেক করুন
- mcp.json-এ পূর্ণ পাথ ব্যবহার করুন: `"command": "/home/user/.local/bin/uvx"`

### সমস্যা 4: ডিপেন্ডেন্সি কনফ্লিক্ট
**সমাধান:**
```bash
# লকফাইল রিজেনারেট করুন
uv lock --upgrade
uv sync
```
