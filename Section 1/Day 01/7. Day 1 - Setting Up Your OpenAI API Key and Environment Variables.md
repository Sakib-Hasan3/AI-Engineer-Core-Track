
## ১. OpenAI API Key কী এবং কেন এটি দরকার?

**API Key** হলো একটি ইউনিক কোড যা OpenAI-কে বলে দেয়, "আমি একজন অনুমোদিত ব্যবহারকারী, এবং আমি আপনার মডেলগুলো ব্যবহার করতে চাই।" 

আপনি যখন আপনার কোডে OpenAI মডেল কল করবেন, তখন এই Key-টি ব্যবহার করবেন। কিন্তু প্রশ্ন হলো, এই Key-টি আপনি সরাসরি আপনার কোডের ভেতরে লিখে রাখবেন?

**একদমই না।**

এখানেই আসে **এনভায়রনমেন্ট ভেরিয়েবল**-এর ধারণা। এনভায়রনমেন্ট ভেরিয়েবল হলো আপনার অপারেটিং সিস্টেমের ভেতরে সংরক্ষিত কিছু নির্দেশনা (যেমন: `OPENAI_API_KEY = "sk-..."`) যা আপনার কোড চালানোর সময় সিস্টেম থেকে পড়ে নেয়। এতে আপনার সোর্স কোড পাবলিক হলেও আপনার গোপন Key সুরক্ষিত থাকে ।


## ২. ধাপ ১: আপনার OpenAI API Key তৈরি করা

সবচেয়ে প্রথমে, একটি API Key তৈরি করে নিতে হবে।

1.  **লগইন করুন:** OpenAI প্ল্যাটফর্মে যান এবং আপনার অ্যাকাউন্টে লগইন করুন।
2.  **API Keys পেজে যান:** আপনার প্রোফাইল পিকচারে ক্লিক করে **"View API Keys"** অপশনে যান ।
3.  **নতুন Key তৈরি করুন:** **"Create new secret key"** বাটনে ক্লিক করুন।
4.  **নাম দিন ও পারমিশন সেট করুন:** Key-টির একটি নাম দিন (যেমন: `My-LLM-Project`) এবং এটি কোন কাজে ব্যবহার করবেন তা সিলেক্ট করুন। সাধারণত শুরুতে **"All"** সিলেক্ট করলেই চলে।
5.  **কপি করে রাখুন:** Key তৈরি হলে সেটি একটি ডায়ালগ বক্সে দেখাবে। **এখনই এটি কপি করে একটি নিরাপদ জায়গায় (যেমন পাসওয়ার্ড ম্যানেজার) সেভ করে নিন।** পেজ রিফ্রেশ করলে এটি আর দেখা যাবে না। 


## ৩. ধাপ ২: এনভায়রনমেন্ট ভেরিয়েবল সেট করা

এখন আমরা আমাদের সিস্টেমকে বলব, "এইমাত্র যে Key-টি পেলাম, সেটি `OPENAI_API_KEY` নামে মনে রেখো।" আপনার অপারেটিং সিস্টেম অনুযায়ী নিচের পদ্ধতি অনুসরণ করুন।

### Windows-এর জন্য গাইড

**পদ্ধতি ১: কমান্ড প্রম্পট বা PowerShell ব্যবহার করে (সহজ ও দ্রুত)**

আপনার PowerShell বা কমান্ড প্রম্পট অ্যাডমিনিস্ট্রেটর মোডে খুলুন। তারপর নিচের কমান্ডটি লিখুন। `<yourkey>`-এর জায়গায় আপনার আসল API Key বসান।

```powershell
setx OPENAI_API_KEY "<yourkey>"
```

এন্টার চাপার পর এটি সেভ হয়ে যাবে। **মনে রাখবেন:** এই কমান্ড দেওয়ার পর আপনার Terminal বা Cursor রিস্টার্ট দিতে হবে, তবেই এটি কাজ করবে ।

**পদ্ধতি ২: কন্ট্রোল প্যানেল থেকে (গ্রাফিক্যাল পদ্ধতি)**

আপনি যদি কমান্ড লাইন পছন্দ না করেন, তাহলে:

1.  **সিস্টেম প্রপার্টিজ** খুলুন (মাই কম্পিউটারে রাইট-ক্লিক করে Properties-এ গেলেও পাওয়া যায়)।
2.  **Advanced system settings** ক্লিক করুন।
3.  **Environment Variables...** বাটনে ক্লিক করুন।
4.  ইউজার ভেরিয়েবল সেকশনে **New...** ক্লিক করুন।
5.  Variable Name লিখুন: `OPENAI_API_KEY` এবং Variable Value লিখুন: আপনার Key ।

### Mac বা Linux-এর জন্য গাইড

Mac বা Linux ব্যবহার করলে টার্মিনাল খুলে নিচের কমান্ডগুলো দিন। এখানে `.zshrc` ফাইলটি এডিট করা হচ্ছে। আপনি যদি Bash ব্যবহার করেন, তাহলে `.zshrc`-এর জায়গায় `.bashrc` বা `.bash_profile` লিখবেন ।

```bash
# 1. ফাইলে লাইনটি যোগ করুন (yourkey-এর জায়গায় আসল Key দিন)
echo "export OPENAI_API_KEY='yourkey'" >> ~/.zshrc

# 2. পরিবর্তনগুলি সক্রিয় করতে শেল রিলোড করুন
source ~/.zshrc
```

**ভেরিফিকেশন (Verification):**
আপনি সঠিকভাবে সেট করেছেন কিনা, তা টেস্ট করতে টার্মিনালে লিখুন:
```bash
echo $OPENAI_API_KEY
```
যদি আপনার API Key প্রিন্ট হয়, তাহলে কাজ সফল হয়েছে।


## ৪. ধাপ ৩: আপনার কোডে এনভায়রনমেন্ট ভেরিয়েবল ব্যবহার করা

আপনি যদি সঠিকভাবে উপরের ধাপগুলো ফলো করে থাকেন, তাহলে আপনার পাইথন কোড এতক্ষণে জানে কোথায় Key খুঁজতে হবে। নিচের কোডটি রান করলেই এটি কাজ করবে:

```python
import os
from openai import OpenAI

# এনভায়রনমেন্ট থেকে Key তুলে আনা
client = OpenAI(
    api_key=os.environ.get("OPENAI_API_KEY")
)

# টেস্ট কল (ঐচ্ছিক)
response = client.chat.completions.create(
    model="gpt-3.5-turbo",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)
```
এই পদ্ধতিতে আপনার কোডে Key লেখার প্রয়োজন নেই। `os.environ.get()` ফাংশনটি সিস্টেম থেকে ভেরিয়েবলটি তুলে আনে ।


## ৫. বোনাস: Cursor-এ কীভাবে API Key সেট করবেন?

আপনি যদি Cursor-এর বিল্ট-ইন AI ফিচার চালানোর জন্য আলাদা ভাবে OpenAI Key ব্যবহার করতে চান, তবে Cursor-এর ভেতরেও এটি সেট করার সুযোগ আছে।

1.  Cursor খুলে **Settings** এ যান (শর্টকাট: `Cmd + ,` অথবা `Ctrl + ,`)।
2.  সাইডবার থেকে **Models** সেকশনে ক্লিক করুন।
3.  এখানে **OpenAI API Key** ফিল্ডে আপনার Key পেস্ট করুন ।
4.  প্রয়োজনে **Override OpenAI Base URL** দিয়ে অন্য প্রোভাইডার (যেমন OpenRouter বা Alibaba Cloud) সেট করতে পারেন ।
