
## ১. System Prompt আর User Prompt আসলে কী?

আমরা যখন ChatGPT বা অন্য কোনো এলএলএম-এর সাথে কথা বলি, তখন আমরা যা লিখি, সেটি মূলত একটি "Prompt"। কিন্তু OpenAI-র API-তে এই প্রম্পটকে ভাগ করা হয় দুটি ভিন্ন ভূমিকায়।

### System Prompt (সিস্টেম প্রম্পট)
এটি হলো মডেলের **চরিত্র বা নির্দেশনা**। আপনি এখানে মডেলটিকে বলে দেন সে কীভাবে আচরণ করবে, কোন স্টাইলে কথা বলবে, বা তার কোন সীমাবদ্ধতা থাকবে। **এটি অদৃশ্য**, অর্থাৎ ব্যবহারকারী এটি দেখতে পায় না, কিন্তু মডেল এটি পুরো কথোপকথন জুড়ে মনে রাখে।

### User Prompt (ইউজার প্রম্পট)
এটি হলো **ব্যবহারকারীর সরাসরি ইনপুট** বা প্রশ্ন। সাধারণ মানুষ যা টাইপ করে, সেটি এখানে যায়।

একটি উদাহরণ দেখি:
- **System Prompt:** "তুমি একজন হাস্যরসাত্মক বাংলা কবি। তুমি সব সময় ছন্দে উত্তর দেবে।"
- **User Prompt:** "আমার মন খারাপ, একটা মজার কবিতা শোনাও।"

মডেলটি তখন 'User Prompt'-এর উত্তর দেবে, কিন্তু 'System Prompt'-এ বাঁধা দেওয়া নিয়ম মেনে।

এক নজরে পার্থক্যঃ

| ফিচার | System Prompt | User Prompt |
| :--- | :--- | :--- |
| **উদ্দেশ্য** | মডেলের আচরণ নির্ধারণ করা | সরাসরি প্রশ্ন বা কাজ জানানো |
| **কার কাছ থেকে আসে?** | ডেভেলপার (আপনি) | এন্ড ইউজার |
| **দৃশ্যমানতা** | সাধারণত ইউজারের কাছে লুকানো | পুরোপুরি দৃশ্যমান |
| **অধ্যবসায়** | পুরো সেশনের জন্য স্থির থাকে | প্রতিটি মেসেজে পরিবর্তন হতে পারে |


## ২. আপনার প্রথম API Call: Hello, World!

আমরা এখন হাতেকলমে শিখব। ধরে নিচ্ছি আপনি ইতিমধ্যেই আপনার এনভায়রনমেন্টে OpenAI API Key সেট করে রেখেছেন (Day 1-এর আগের সেশন অনুযায়ী)।

### ২.১। প্রয়োজনীয় লাইব্রেরি ইনস্টল করা

Cursor-এর টার্মিনাল খুলে নিচের কমান্ডটি দিন। এটি আমাদের পাইথন কোড থেকে OpenAI-কে কল করার সেতুবন্ধন তৈরি করবে।

```bash
pip install openai
```

### ২.২। বেসিক কল লেখা (শুধু User Prompt)

প্রথমে একটি `test_openai.py` ফাইল তৈরি করে নিচের কোডটি লিখুন। এটি সবচেয়ে সাধারণ একটি কল, যেখানে শুধু `user` প্রম্পট আছে।

```python
# test_openai.py
from openai import OpenAI

# ক্লায়েন্ট ইনিশিয়ালাইজ করুন (API Key এনভায়রনমেন্ট থেকে নিবে)
client = OpenAI()

# API-তে কল করুন
response = client.chat.completions.create(
    model="gpt-3.5-turbo",  # আমরা ছোট ও দ্রুত মডেল দিয়ে শুরু করছি
    messages=[
        {"role": "user", "content": "বাংলায় 'Hello, World!' কী বলে?"}
    ]
)

# উত্তর প্রিন্ট করুন
print(response.choices[0].message.content)
```

**কোডটি রান করান:** টার্মিনালে লিখুন `python test_openai.py`।

আপনি যদি সঠিকভাবে সবকিছু করে থাকেন, তাহলে আউটপুট আসবে এমন কিছু: *"হ্যালো, ওয়ার্ল্ড!" অথবা "ওহে বিশ্ব"*। অভিনন্দন! আপনার প্রথম API কল সফল হয়েছে!

### ২.৩। System Prompt যোগ করে পার্থক্য দেখা

এবার একই প্রশ্ন করি, কিন্তু মডেলটিকে একটি **System Prompt** দিয়ে বাধা দিয়ে দেই।

```python
# test_system_prompt.py
from openai import OpenAI

client = OpenAI()

response = client.chat.completions.create(
    model="gpt-3.5-turbo",
    messages=[
        {"role": "system", "content": "তুমি খুব খিটখিটে স্বভাবের। তুমি সব প্রশ্নের উত্তর রাগের সাথে দেবে এবং 'হুমফ!' বলে শেষ করবে।"},
        {"role": "user", "content": "বাংলায় 'Hello, World!' কী বলে?"}
    ]
)

print(response.choices[0].message.content)
```

এবার আউটপুট দেখুন। এটি হয়তো বলবে: *"আবার সেই হ্যালো ওয়ার্ল্ড! এর মানে 'ওহে বিশ্ব'। হুমফ!"*

দেখুন, একই প্রশ্ন (User Prompt) থাকা সত্ত্বেও, System Prompt পরিবর্তন করার কারণে উত্তর সম্পূর্ণ ভিন্ন আচরণে এলো। **এটাই System Prompt-এর শক্তি।**


## ৩. ভিজুয়াল উদাহরণ: কথোপকথন বোঝা

ব্যাপারটি আরও পরিষ্কার করার জন্য নিচের ছকটি দেখুন। মনে করুন আপনি একটি রেস্টুরেন্ট বট বানাচ্ছেন।

**আপনার কোড (API Request):**
```json
[
  {"role": "system", "content": "তুমি একটি পিৎজা রেস্তোরাঁর ওয়েটার। তুমি খুব ভদ্র ও সাহায্যকারী।"},
  {"role": "user", "content": "তোমার কাছে কি ভেজ পিৎজা আছে?"},
  {"role": "assistant", "content": "জ্বি, আমাদের কাছে সুস্বাদু মার্গেরিটা আছে।"},
  {"role": "user", "content": "দাম কত?"}
]
```

এই ক্ষেত্রে:
- **System Prompt** ওয়েটারকে ভদ্র হতে বলছে।
- **User Prompt** প্রথমে জিজ্ঞেস করছে ভেজ পিৎজা আছে কিনা, পরে দাম জানতে চাইছে।
- **Assistant Message** (API থেকে আসা) হলো মডেলের উত্তর।


## ৪. সাধারণ ভুল ও তার সমাধান

শুরুতে এই ভুলগুলো হয়তো আপনারও হবে, তাই আগেই জেনে রাখা ভালো।

### সমস্যা ১: `openai.OpenAIError: The api_key client option must be set`
**সমাধান:** আপনার এনভায়রনমেন্ট ভেরিয়েবল সঠিকভাবে সেট নেই। টার্মিনালে `echo $OPENAI_API_KEY` (Mac/Linux) বা `echo %OPENAI_API_KEY%` (Windows) দিয়ে চেক করুন।

### সমস্যা ২: API কল করতে অনেক সময় লাগে বা হ্যাং করে
**সমাধান:** নেটওয়ার্ক কানেকশন চেক করুন। বাংলাদেশ থেকে কানেক্ট করতে কখনো কখনো একটু বেশি সময় লাগতে পারে। কোডে `timeout` প্যারামিটার যোগ করতে পারেন:
```python
client = OpenAI(timeout=60.0)
```

### সমস্যা ৩: System Prompt কাজ করছে না মনে হচ্ছে
**সমাধান:** GPT-3.5-turbo কখনও কখনও ছোট মডেল হওয়ায় জটিল System Prompt এড়িয়ে যেতে পারে। `gpt-4o-mini` বা `gpt-4` ব্যবহার করলে নির্ভরযোগ্যতা বাড়ে।
