# Day 1 - Setting Up Your LLM Development Environment with Cursor and UV

আজকের সেশনে আমরা শিখব কীভাবে **Cursor** (এআই-পাওয়ার্ড কোড এডিটর) এবং **UV** (আধুনিক পাইথন প্যাকেজ ম্যানেজার) ব্যবহার করে একটি এলএলএম ডেভেলপমেন্ট এনভায়রনমেন্ট সেটআপ করতে হয়। এই পরিবেশে আপনি লোকাল মডেল চালাতে পারবেন, কোডিংয়ের জন্য এআই অ্যাসিস্ট্যান্ট ব্যবহার করতে পারবেন, এবং প্রোডাকশন-রেডি প্রজেক্ট তৈরি করতে পারবেন।

## ১. কেন Cursor এবং UV? (Why Cursor and UV?)

### Cursor কী?
Cursor একটি **AI-native কোড এডিটর** যা VS Code-এর মতো কাজ করে, তবে এতে বিল্ট-ইন এআই ক্যাপাবিলিটি আছে। আপনি ChatGPT-এর মতো মডেলকে সরাসরি এডিটরের মধ্যে দিয়ে কোড লিখতে, ডিবাগ করতে এবং রিফ্যাক্টর করতে পারেন ।

### UV কী?
UV একটি **অতি-দ্রুত পাইথন প্যাকেজ ম্যানেজার** যা Rust এ লেখা। এটি pip, virtualenv, pipx, poetry, এবং pyenv-এর মতো টুলসকে প্রতিস্থাপন করে । UV-এর বিশেষত্ব:
- **১০-১০০ গুণ দ্রুত** pip-এর চেয়ে
- **ভার্চুয়াল এনভায়রনমেন্ট** ম্যানেজ করে
- **পাইথন ভার্সন** ম্যানেজ করে
- **লক ফাইল** দিয়ে ডিপেন্ডেন্সি ফ্রিজ করে

এই দুটি টুল একসাথে ব্যবহার করলে আপনি একটি **মডার্ন, দ্রুত এবং এআই-সক্ষম** ডেভেলপমেন্ট এনভায়রনমেন্ট পাবেন।

## ৩. ধাপ ১: UV ইনস্টল করা (Installing UV)

UV ইনস্টলের তিনটি সহজ উপায় আছে। যেকোনো একটি ফলো করুন:

### পদ্ধতি A: এক-লাইন স্ক্রিপ্ট (সব OS-এর জন্য সহজ)

**macOS/Linux:**
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

**Windows (PowerShell):**
```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### পদ্ধতি B: pip দিয়ে ইনস্টল
```bash
pip install uv
```

### পদ্ধতি C: Homebrew দিয়ে (macOS)
```bash
brew install uv
```

### ইনস্টল ভেরিফাই করা:
```bash
uv --version
```
যদি ভার্সন নম্বর দেখায়, তাহলে ইনস্টল সফল হয়েছে ।

## ৪. ধাপ ২: Cursor ইনস্টল ও কনফিগার (Installing Cursor)

1. **Cursor ডাউনলোড করুন** [cursor.com](https://cursor.com) থেকে
2. **ইনস্টল করুন** (সাধারণ সফটওয়্যার ইনস্টলের মতো)
3. **সাইন ইন করুন** (GitHub অ্যাকাউন্ট দিয়ে সহজে লগইন করা যায়)

## ৫. ধাপ ৩: প্রথম Python প্রজেক্ট তৈরি করা (Creating a Python Project with UV)

এবার আমরা UV দিয়ে একটি নতুন পাইথন প্রজেক্ট তৈরি করব:

### 3.1 প্রজেক্ট ফোল্ডার তৈরি ও ইনিশিয়ালাইজ
```bash
# প্রজেক্টের জন্য ফোল্ডার তৈরি করুন
mkdir my-llm-project
cd my-llm-project

# UV প্রজেক্ট ইনিশিয়ালাইজ করুন
uv init .
```

এই কমান্ডটি স্বয়ংক্রিয়ভাবে নিচের ফাইলগুলো তৈরি করবে :
```
my-llm-project/
├── .venv/              # ভার্চুয়াল এনভায়রনমেন্ট
├── .python-version     # পাইথন ভার্সন ফিক্স করে
├── pyproject.toml      # প্রজেক্ট মেটাডাটা ও ডিপেন্ডেন্সি
├── uv.lock            # লকড ডিপেন্ডেন্সি লিস্ট
├── main.py            # স্যাম্পল পাইথন ফাইল
└── README.md
```

### 3.2 পাইথন ভার্সন সেট করা (Optional)
```bash
# নির্দিষ্ট পাইথন ভার্সন সেট করতে (যেমন 3.12)
uv python pin 3.12

# সব ডিপেন্ডেন্সি সিঙ্ক করতে
uv sync
```

## ৬. ধাপ ৪: ডিপেন্ডেন্সি ম্যানেজমেন্ট (Managing Dependencies)

UV দিয়ে প্যাকেজ ইনস্টল করা খুব সহজ:

### প্রোডাকশন ডিপেন্ডেন্সি (Runtime)
```bash
# সাধারণ ইনস্টল (প্রোডাকশন ডিপেন্ডেন্সি হিসেবে)
uv add requests
uv add fastapi uvicorn
```

### ডেভেলপমেন্ট ডিপেন্ডেন্সি (Development)
```bash
# শুধু ডেভেলপমেন্টের জন্য (টেস্টিং, লিন্টিং)
uv add --dev pytest black mypy
```

### নির্দিষ্ট গ্রুপে ডিপেন্ডেন্সি
```bash
# টেস্ট গ্রুপে প্যাকেজ
uv add --group test pytest pytest-cov

# ডকুমেন্টেশন গ্রুপে
uv add --group docs mkdocs mkdocstrings
```

### ডিপেন্ডেন্সি সিঙ্ক করা
```bash
# সব ডিপেন্ডেন্সি ইনস্টল করতে (প্রোডাকশন + ডেভ)
uv sync

# শুধু প্রোডাকশন ডিপেন্ডেন্সি চাইলে
uv sync --no-dev

# নির্দিষ্ট গ্রুপ সহ
uv sync --with dev,test
```

### ডিপেন্ডেন্সি রিমুভ করা
```bash
uv remove requests
```

## ৭. ধাপ ৫: Cursor-এ UV প্রজেক্ট খোলা (Opening UV Project in Cursor)

1. **Cursor ওপেন করুন**
2. **File → Open Folder** → আপনার `my-llm-project` ফোল্ডার সিলেক্ট করুন
3. **Terminal খুলুন** (`Ctrl + `` ` বা View → Terminal)
4. ভার্চুয়াল এনভায়রনমেন্ট অ্যাক্টিভেট করুন:
   - **Windows:** `.venv\Scripts\activate`
   - **macOS/Linux:** `source .venv/bin/activate`

Cursor স্বয়ংক্রিয়ভাবে `.venv` শনাক্ত করবে এবং AI অ্যাসিস্ট্যান্ট সঠিক কনটেক্সট পাবে ।

## ৮. ধাপ ৬: লোকাল এলএলএম মডেল কানেক্ট করা (Connecting Local LLM to Cursor)

আপনার লোকাল মডেলকে Cursor-এর AI অ্যাসিস্ট্যান্ট হিসেবে ব্যবহার করতে চান? এটা সম্ভব! 

### Step 1: Ollama বা LM Studio দিয়ে মডেল রান করুন
```bash
# Ollama দিয়ে মডেল রান করুন (পূর্বের দিনে শিখেছি)
ollama run llama3.2
# এটি লোকাল সার্ভার চালু করবে: http://localhost:11434
```

### Step 2: Cursor-এর LLM কনফিগারেশন এডিট করুন
1. Cursor-এ কমান্ড প্যালেট খুলুন: `Cmd+Shift+P` (Mac) বা `Ctrl+Shift+P` (Windows)
2. টাইপ করুন: **"Cursor: Edit LLM Configuration"**
3. ওপেন হওয়া ফাইলে নিচের কনফিগারেশন যোগ করুন:

```json
{
  "defaultProvider": "openai",
  "providers": {
    "openai": {
      "apiKey": "dummy-key",
      "baseURL": "http://localhost:11434/v1"
    }
  }
}
```

### Step 3: Cursor রিলোড করুন
কমান্ড প্যালেট থেকে **"Developer: Reload Window"** দিন।

এখন আপনার Cursor AI অ্যাসিস্ট্যান্ট আপনার লোকাল মডেল ব্যবহার করবে! 

## ৯. ধাপ ৭: UV-এর সাথে Cursor টার্মিনাল ব্যবহার (Using Cursor Terminal with UV)

কখনও কখনও Cursor-এর টার্মিনাল `uv` খুঁজে পায় না, বিশেষ করে Snap বা user-local ইনস্টলের ক্ষেত্রে । সমাধান:

### Solution A: সিমলিংক তৈরি করা (macOS/Linux)
```bash
# uv এবং uvx-এর লোকেশন খুঁজুন
which uv
which uvx

# সিমলিংক তৈরি করুন (পাথ আপনার মতো করে দিন)
sudo ln -sf "$(which uv)" /usr/local/bin/uv
sudo ln -sf "$(which uvx)" /usr/local/bin/uvx
```

### Solution B: Cursor রিস্টার্ট করুন
কখনও কখনও শুধু Cursor রিস্টার্ট দিলেই কাজ হয়।

### Solution C: পূর্ণ পাথ ব্যবহার করুন (Windows)
`mcp.json` ফাইলে পূর্ণ পাথ দিন :
```json
{
  "mcpServers": {
    "my-server": {
      "command": "C:\\Users\\YourName\\AppData\\Roaming\\Python\\Python311\\Scripts\\uvx.exe",
      "args": ["run", "my-script"]
    }
  }
}
```

## ১০. দরকারি UV কমান্ডের চিটশিট (UV Command Cheatsheet)

| কাজ | কমান্ড |
|------|---------|
| নতুন প্রজেক্ট তৈরি | `uv init .` |
| পাইথন ভার্সন পিন | `uv python pin 3.12` |
| প্যাকেজ ইনস্টল | `uv add package_name` |
| ডেভ প্যাকেজ ইনস্টল | `uv add --dev package_name` |
| সব ডিপেন্ডেন্সি সিঙ্ক | `uv sync` |
| প্যাকেজ রিমুভ | `uv remove package_name` |
| গ্লোবাল টুল ইনস্টল | `uv tool install ruff` |
| টুল রান (টেম্পরারি) | `uvx black --check .` |
| ইনস্টল করা প্যাকেজ লিস্ট | `uv pip list` |
| ডিপেন্ডেন্সি ট্রি দেখা | `uv tree` |
